## 正文

There was a flurry of activity during the week of October 19th, 2026, highlighting: first release candidates of: Spring Boot, Spring Framework, Spring Data, Spring Cloud, Spring Security, Spring for GraphQL, Spring Session, Spring Integration, Spring HATEOS, Spring Modulith, Spring REST Docs, Spring AI, Spring Batch, Spring AMQP, Spring for Apache Kafka, Spring LDAP and Spring Web Services.

#### Spring Boot

The [first release candidate](https://spring.io/blog/2026/10/23/spring-boot-4-2-0-RC1-available-now) of [Spring Boot](https://spring.io/projects/spring-boot) 4.2.0 delivers bug fixes, documentation improvements, dependency upgrades and new features such as: a migration to the [Ubuntu Resolute](https://discourse.ubuntu.com/t/ubuntu-26-04-resolute-raccoon-lts-released/80833) builder replacing the [Noble Java Tiny Builder](https://github.com/paketo-buildpacks/builder-noble-java-tiny/blob/main/README.md); and improved Uber-Jar performance using direct lookup of classes and resources in nested jars. More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-boot/releases/tag/v4.2.0-RC1) and this [wiki page](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.2.0-RC1-Release-Notes).

#### Spring Framework

The *first release candidate* of [Spring Framework](https://spring.io/projects/spring-framework) 7.1.0 ships with bug fixes, dependency upgrades and new features such as: improved nullability in the **`[DataAccessUtils](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/dao/support/DataAccessUtils.html)`** and **`[LinkedCaseInsensitiveMap](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/util/LinkedCaseInsensitiveMap.html)`** classes; and new overloaded methods, **`onRetrySuccess()`** and **`onRetryFailure()`**, defined in the **`[RetryListener](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/core/retry/RetryListener.html)`** interface, that add an instance of the **`[RetryState](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/core/retry/RetryState.html)`** class in the parameter list such that listeners can access the retry state directly upon failure. Further details on this release, including removal of deprecated APIs, may be found in the [release notes](https://github.com/spring-projects/spring-framework/releases/tag/v7.1.0-RC1).

#### Spring Data

The [first release candidate](https://spring.io/blog/2026/10/22/spring-data-2026-1-0-RC1-released) of [Spring Data](https://spring.io/projects/spring-data) 2026.1.0 provides bug fixes, dependency upgrades, RC1 upgrades to all of the subprojects and a notable new feature in [Spring Data Redis](https://spring.io/projects/spring-data-redis) that now forwards subscription notifications related to annotated listener methods if a bean implements the **`[SubscriptionListener](https://docs.spring.io/spring-data/redis/reference/4.2/api/java/org/springframework/data/redis/connection/SubscriptionListener.html)`** interface.

#### Spring Cloud

The [first release candidate](https://spring.io/blog/2026/10/23/spring-cloud-2026-0-0-RC1-has-been-released) of [Spring Cloud](https://spring.io/projects/spring-cloud) 2026.0.0, codenamed Paddington, delivers dependency upgrades, RC1 upgrades to all of the subprojects and a notable change where [Spring Cloud Bus](https://spring.io/projects/spring-cloud-bus) is no longer its own project and has been incorporated into [Spring Cloud Stream](https://spring.io/projects/spring-cloud-stream). This release is based on Spring Boot 4.2.0-RC1. More details on this release may be found in this [release notes](https://github.com/spring-cloud/spring-cloud-release/releases/tag/v2026.0.0-RC1).

#### Spring Security

The [first release candidate](https://spring.io/blog/2026/10/23/spring-security-7) of [Spring Security](https://spring.io/projects/spring-security) 7.2.0 ships with bug fixes, dependency upgrades and two new features: an instance of the **`[StrictServerWebExchangeFirewall](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/web/server/firewall/StrictServerWebExchangeFirewall.html)`** class no longer detects a non-canonical-case HTTP method as a distinct value due to a change in the **`valueOf()`** method, defined in the Spring Framework **`[HttpMethod](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/http/HttpMethod.html)`** class, that now normalizes casing; and **`[RestClientOpaqueTokenIntrospector](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/oauth2/server/resource/introspection/RestClientOpaqueTokenIntrospector.html)`** and **`[SpringOpaqueTokenIntrospector](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/oauth2/server/resource/introspection/SpringOpaqueTokenIntrospector.html)`** classes now set the **`Content-Type`** header to **`application/x-www-form-urlencoded`**. Further details on this release may be found in the [release notes](https://github.com/spring-projects/spring-security/releases/tag/7.2.0-RC1) and this [what's new](https://docs.spring.io/spring-security/reference/7.2/whats-new.html) page.

#### Spring for GraphQL

More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-graphql/releases/tag/v2.1.0-RC1).

Further details on this release may be found in the r[elease notes](https://github.com/spring-projects/spring-session/releases/tag/4.2.0-RC1).

#### Spring Integration

The *first release candidate* of [Spring Integration](https://spring.io/projects/spring-integration) 7.2.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: a deprecation of the default constructor in the **`[SerializingHttpMessageConverter](https://docs.spring.io/spring-integration/docs/7.2.0-SNAPSHOT/api/org/springframework/integration/http/converter/SerializingHttpMessageConverter.html)`** class to define a new constructor that contains the **`allowedPatterns`** attribute for improved security; and the ability to allow the **`[DefaultJmsHeaderMapper](https://docs.spring.io/spring-integration/docs/7.2.0-SNAPSHOT/api/org/springframework/integration/jms/DefaultJmsHeaderMapper.html)`** class to set the **`outboundHeaderNames`**, **`inboundHeaderNames`** and **`excludedOutboundStandardRequestHeaderNames`** and **`excludedInboundStandardResponseHeaderNames`** to align with the **`[DefaultHttpHeaderMapper](https://docs.spring.io/spring-integration/docs/7.2.0-SNAPSHOT/api/org/springframework/integration/http/support/DefaultHttpHeaderMapper.html)`** class. More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-integration/releases/tag/v7.2.0-RC1).

#### Spring Modulith

The [first release candidate](https://spring.io/blog/2026/10/23/spring-modulith-2-2-rc1-2-1-2-2-0-9-and-1-4-14-released) of [Spring Modulith](https://spring.io/projects/spring-modulith) 2.2.0 delivers bug fixes, dependency upgrades and new features such as: new **`ABANDONED`** and **`RESUBMITTED`** enumerations, added to the **`[EventPublication.Status](https://github.com/spring-projects/spring-modulith/blob/main/spring-modulith-events/spring-modulith-events-api/src/main/java/org/springframework/modulith/events/EventPublication.java#L140)`** interface, to distinguish between failed and abandoned event publications; and event publications are now completed, by default, using the Spring Framework **`[TransactionSynchronization](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/transaction/support/TransactionSynchronization.html)`** interface within a listener's transaction to avoid the possibility of a listener committing and the completion to fail. More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-modulith/releases/tag/2.2.0-RC1).

#### Spring Batch

The [first release candidate](https://spring.io/blog/2026/10/22/spring-batch-6) of [Spring Batch](https://spring.io/projects/spring-batch) 6.1.0 delivers bug fixes, documentation improvements, dependency upgrades and new features such as: a new **`[@JobParameter](https://docs.spring.io/spring-batch/reference/6.1/api/org/springframework/batch/core/configuration/annotation/JobParameter.html)`** annotation that injects a job parameter into a job or step scoped bean used to require a Spring Expression Language (SpEL) expression; and a new **`[PageableItemReader](https://docs.spring.io/spring-batch/reference/6.1/api/org/springframework/batch/infrastructure/item/data/PageableItemReader.html)`** class that serves as a type-safe alternative to **`[RepositoryItemReader](https://docs.spring.io/spring-batch/reference/6.1/api/org/springframework/batch/infrastructure/item/data/RepositoryItemReader.html)`** class to take a function from the Spring Data **`[Pageable](https://docs.spring.io/spring-data/commons/reference/4.2/api/java/org/springframework/data/domain/Pageable.html)`** interface to a **`[Slice](https://docs.spring.io/spring-data/commons/reference/4.2/api/java/org/springframework/data/domain/Slice.html)`** interface. #### Spring AMQP

The *first release candidate* of [Spring AMQP](https://spring.io/projects/spring-amqp) 4.2.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: removal of the use of the **`noNullElements()`** method, defined in the Spring Framework **`[Assert](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/util/Assert.html)`** class, to allow the **`[RabbitAdmin](https://docs.spring.io/spring-amqp/docs/4.2.0-SNAPSHOT/api/org/springframework/amqp/rabbit/core/RabbitAdmin.html)`** class and **`[AmqpAdmin](https://docs.spring.io/spring-amqp/docs/4.2.0-SNAPSHOT/api/org/springframework/amqp/core/AmqpAdmin.html)`** interface to accept **`null`** or empty arrays when declaring exchanges, queues, and bindings; and a simplification of the buildMessage() method, defined in both the **`[AbstractAdaptableMessageListener](https://docs.spring.io/spring-amqp/docs/4.2.0-SNAPSHOT/api/org/springframework/amqp/rabbit/listener/adapter/AbstractAdaptableMessageListener.html)`** and **`[MessagingMessageListenerAdapter](https://docs.spring.io/spring-amqp/docs/4.2.0-SNAPSHOT/api/org/springframework/amqp/rabbit/listener/adapter/MessagingMessageListenerAdapter.html)`** classes, to avoid unnecessary nesting when handling existing instances of the **`[Message](https://docs.spring.io/spring-amqp/docs/4.2.0-SNAPSHOT/api/org/springframework/amqp/core/Message.html)`** class and message conversion. More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-amqp/releases/tag/v4.2.0-RC1).

#### Spring LDAP
