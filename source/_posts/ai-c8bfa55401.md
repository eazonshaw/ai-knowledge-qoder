华为推出的 DevEco CLI 正是为此而生，它定位于统一集成开发工具链和 HarmonyOS 知识库，是专为 AI Agent 打造的原子化能力调度枢纽。

今天我们直接从实操入手，教你如何将 HarmonyOS 能力接本地 AI 工作流。它本质上是将 DevEco Studio 工具链统一封装为一个 CLI，内置 ohpm、hvigor、hdc、emulator、hilog，同时集成 HarmonyOS 技能安装、项目脚手架、本地 HarmonyOS 文档检索和 MCP 服务。

详细操作如下：

**1、DevEco CLI 环境依赖与配置要求说明**

DevEco CLI 是基于 DevEco Studio 工具链封装的命令行工具。它依赖于已安装并配置好环境的 DevEco Studio（包含 ohpm、hvigor 等工具），通过命令行接口提供项目构建、设备调试等功能，旨在提升自动化脚本和 CI/CD 流程的效率。

**前置要求**

• 操作系统为 macOS 或 Windows

• Node.js >= 18，推荐使用 22 及以上版本

• [DevEco Studio](https://developer.huawei.com/consumer/cn/download/) \>= 6.1.0

• macOS：必须安装在 ~/Applications 或 /Applications 目录下。

**安装**

请在终端中执行以下命令安装：

稳定版：**npm install -g @deveco/deveco-cli@stable**

尝鲜版：**npm install -g @deveco/deveco-cli**

**2、一键集成现有 AI Agent（以 OpenCode 为例）**

如果你正在使用本地 AI Agent 工具（例如基于 OpenCode 开发应用），将 DevEco CLI 接入你的工作流非常简单。它能为 AI Agent 专门提供结构化（如 JSON）的数据流，完美兼容 Agent 驱动开发的范式。

实操命令： 只需在终端运行以下初始化指令： **devecocli init** 运行该指令后即可完成深度集成。你的 AI Agent 甚至可以自主指挥 DevEco CLI 去安装更多用于 HarmonyOS 应用开发的精品 Skills。

**3、让 AI Agent 调度端到端研发原子能力**

接入完成后，你的 AI Agent 就可以自动推进整个研发流程。你可以通过提示词或脚本，让 Agent 执行以下操作：

• **工程初始化**：调用 **create** 命令，让 Agent 基于官方模板快速生成项目工程结构。

• **编译与构建**：调用 **build** 命令驱动 hvigor 构建系统，自动处理 HAP 打包、多目标产物构建及代码签名。

• **模拟器与运行**：使用 **device / emulator** 和 **run** 命令统一管理设备生命周期，自动完成安装、权限配置并启动应用。

• **实时语法检查与编译前错误拦截**：Check MCP 为模型提供实时语法检查和编译修复工具能力，支持 ArkTS 和 C++ 语法检查，无需耗时编译即可实时发现错误，大幅缩短反馈链路，使 Agent 修复效率提升 5 倍以上。

同时 DevEco CLI 内置最新官方知识文档与极速检索，让 AI Agent 更懂 HarmonyOS。它能让裸模型获取官网最新 API，而非过时信息。
