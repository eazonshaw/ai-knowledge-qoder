## 正文

[Microsoft Ignite 2026](https://ignite.microsoft.com/en-US/home), held in San Francisco and online from November 17 to 20, centered on running AI agents in production, with Microsoft positioning Copilot as the operating system for work and extending agent identity, governance, and cost controls across Azure, Foundry, Entra, and Defender.

CEO Satya Nadella opened the keynote by acknowledging the November 12 Microsoft 365 outage, then positioned Copilot as the operating system for work, combining chat, coding, and autonomous agents in one experience. In his [edited keynote remarks](https://blogs.microsoft.com/blog/2026/11/17/ignite-2026-building-the-frontier-ecosystem/), Nadella argued that customers must be able to examine and independently verify what AI does, announced an AI Transparency Initiative aligned with NIST's Agent Standards Initiative, and rejected setups where models audit other models:

> These nested black boxes are simply unacceptable.

The [Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/) groups the announcements by product area, and many of them ship as previews rather than in general availability.

## Compute and Infrastructure

Azure Cobalt 200 virtual machines are now generally available, a year after InfoQ reported on Microsoft [introducing the chip at Ignite 2025](https://www.infoq.com/news/2025/11/azure-cobalt-200-chip) and two and a half years after the [preview of Cobalt 100 VMs](https://www.infoq.com/news/2024/05/microsoft-cobalt-arm-based-vms). According to the [Azure announcement](https://azure.microsoft.com/en-us/blog/azure-cobalt-200-vms-now-available-proven-on-real-workloads-and-built-for-the-agentic-era/), the processor combines 132 Arm Neoverse V3 cores on TSMC's 3nm process, and the VMs run in 14 regions today, with 23 planned by the end of 2026. Microsoft claims up to 50% better CPU performance than Cobalt 100, plus up to 15% higher network bandwidth and 20% higher remote storage IOPS through Azure Boost. Customers can run cores at a fixed 3.2 GHz in Deterministic Mode or let them boost up to 3.6 GHz in Opportunistic Mode, and the lineup adds Mpsv4 VMs for high-memory workloads and storage-optimized Lpsv5 VMs. Amadeus reported more than 30% higher flight-search throughput than on Cobalt 100, and OpenAI's Vadim Filanovsky described a similar result:

> We saw higher throughput and lower latency on Cobalt 200.

Confidential computing gains three previews: multi-GPU confidential computing on VR72 for models larger than a single GPU, Azure Confidential Enclaves with AKS Kata CoCo containers, and Azure Confidential Clean Room for multiparty analytics without exposing raw data.

Customers can now deploy Foundry open-weight models and agents to their own AKS clusters. At the same time, an Agent Sandbox extension provides VM-level isolation for agent-written code, and Agent Grid applies central policy to agent, model, tool, and service interactions. Flex nodes extend AKS clusters to servers outside Azure. According to the [AKS team's Ignite post](https://techcommunity.microsoft.com/blog/appsonazureblog/run-models-and-agents-on-your-own-kubernetes-clusters-aks-at-microsoft-ignite-20/4573912), managed GPU node pools, which handle GPU drivers, device plugins, and Azure Monitor metrics, are generally available, with NVIDIA GB200 and GB300 support and mixed multi-instance GPU in preview. Confidential VM node pools on Azure Container Linux are also generally available on both Intel TDX and AMD SEV-SNP VM sizes.

On the operations side, Azure Monitor health models are generally available and build a real-time health graph from telemetry, ranking incidents by business impact. The Azure Copilot deployment agent, also generally available, turns natural-language requirements into deployed workloads, and Azure SRE Agent picks up previews for customer-managed keys, Entra Agent ID integration, cross-agent communication, and multicloud investigations. For migration projects, [Azure Catalyst](https://azure.microsoft.com/en-us/blog/introducing-azure-catalyst-agentic-modernization-and-new-ai-infrastructure-innovations/) is now generally available, with its agent (formerly the Azure Copilot migration agent) handling discovery, assessment, and planning. Separately, GitHub Copilot modernization adds a preview of BizTalk-to-Logic Apps migration.

## Hybrid, Sovereign Cloud, and Windows Server

Microsoft now pitches Sovereign Private Cloud as a full stack on Azure Local, with VMs and AKS at the base, followed by data services, Foundry Local, GitHub Enterprise Local, and Microsoft 365 Local. Darryl van der Peijl, a Microsoft MVP for Azure Local, Hyper-V, and Azure Arc, listed what shipped in his [Azure Local Insider newsletter](https://www.linkedin.com/pulse/azure-local-insider-microsoft-ignite-2026-darryl-van-der-peijl-npeje/): Foundry Local on Azure Local and GitHub Enterprise Local are generally available, while a Sovereign control panel, Blob Storage and DocumentDB on Azure Local, multi-tenancy, and rehoming are in preview. The control panel assesses data residency, encryption, network exposure, and business continuity for Azure resources without enforcing any controls, and during the preview it runs in European regions only, with the service hosted in Sweden.

Van der Peijl singled out rehoming, which moves an Azure Local instance from Azure management to local management while VMs, AKS clusters, and data stay in place:

> Until now, going from connected to disconnected meant a migration project. Microsoft showed a script that does the rehoming in one run.

Azure Local also runs on arm64 for the first time, in public preview on the NVIDIA Jetson AGX Thor Development Kit, which hosts containers on bare metal without a hypervisor. Windows Server 2028 entered preview through the Windows Server Insider Program, bringing a hardened Server Core, post-quantum cryptography, native NVMe enabled by default, NVMe over Fabrics, and boot from ReFS. According to van der Peijl, Microsoft added inference as a new pillar for the release, calling on-premises inference servers token factories, and is moving network drivers from kernel mode to user mode as part of its Windows resiliency work. Windows Admin Center vMode is now generally available at no extra cost and manages up to 1,000 Hyper-V hosts and 25,000 VMs, which Microsoft described on stage as "kind of a replacement for SCVMM."

## AI, Models, and Microsoft Foundry

Foundry's main theme was [continuous improvement](https://azure.microsoft.com/en-us/blog/continuous-improvement-comes-to-microsoft-foundry/). Multi-turn evaluation and production insights that group recurring failures and rank fixes are now generally available, while the agent optimizer, human annotation, rubric evaluators, Managed Training, and Programmed Training for custom SFT and reinforcement learning loops on open-weight models are in preview. The optimizer adjusts an agent's instructions, skills, and model choice, with a human approving each change before it ships.

*(Source: [Microsoft blog](https://azure.microsoft.com/en-us/blog/continuous-improvement-comes-to-microsoft-foundry/))*

In a separate engineering post, the Microsoft team behind the optimizer [described how the loop works](https://commandline.microsoft.com/the-agent-optimization-loop-and-how-we-built-it-in-foundry/). They reported that the reflector, a separate model that reads failing traces and diagnoses why an agent scored poorly, influenced results more than switching the agent's own model, for example between gpt-4o and gpt-4.1-mini. Developers drive the loop from the Azure Developer CLI:

```
azd ai agent eval init                         # generate dataset & evaluator from a one-paragraph description
azd ai agent eval run                          # score the current version (baseline)
azd ai agent optimize                          # search over candidates
azd ai agent optimize apply --candidate <id>   # apply the winner locally
azd deploy                                     # ship as the next version
```

Writing on [DEV Community](https://dev.to/htekdev/azure-weekly-ignite-2026-turns-azure-into-an-agent-platform-1i7), Hector Flores advised readers to treat Microsoft's claim that the model router saves up to 65% compared with a frontier model as a ceiling rather than a forecast, and he welcomed the human approval step in the optimizer loop:

> Self-modifying agents with no review gate are an incident waiting to happen.

On the model front, Microsoft-Decision-1.1 is generally available in Foundry, OpenRouter, and Vercel. Built on Gemma 4 26B A4B with added image input, it scores 68 on the Artificial Analysis Decision Index v2.1 and runs more than twice as fast as its predecessor, and Copilot uses it to route requests. MAI-Code-2 and MAI-Code-2-Flash are generally available on GitHub, MAI-Image-2.7 is in preview, and the model router now covers the top 50 models in a catalog of more than 11,000. OpenAI's [GPT-6.2 Astra and GPT-6.2 Sol](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/gpt-6-2-astra-and-gpt-6-2-sol-now-generally-available-in-microsoft-foundry/4574122) became generally available in Foundry, with Global Standard deployments covering 28 regions. On Standard deployments with short context, Sol costs $2 per million input tokens and $10 per million output tokens, while Astra costs $8 and $40. Foundry IQ added knowledge graphs and an iterative retrieval model, Microsoft-Retriever-1, both in preview.

Microsoft also [made Azure AI Gateway generally available](https://techcommunity.microsoft.com/blog/integrationsonazureblog/azure-ai-gateway-is-now-generally-available-ship-faster-stay-in-control/4572644) as a standalone product, split out of the API Management AI tier, to govern, route, and monitor access to AI models and MCP tools across providers. It includes 10,000 free requests per gateway per month, with paid billing starting January 1, 2027, across 17 regions.

Microsoft IQ, which Nadella described as an externalization of the context system behind Copilot, is now generally available without a new SKU. It exposes Work IQ, Fabric IQ, Foundry IQ, and Web IQ context to Copilot, GitHub Copilot, Foundry, and MCP-compatible harnesses, and Web IQ is now available to all Azure customers at a lower price. Business plugins, which package reusable context, skills, and tools with hierarchical inheritance and governance, are available through the Frontier program.

## Data

PostgreSQL got most of the attention on the data side. Azure HorizonDB is now generally available as a managed, PostgreSQL-compatible database with built-in vector indexing, and teams can lock it down with Entra ID, private endpoints, and their own encryption keys. Calling models from SQL through AI Functions and AI Pipelines is still in preview. The same holds for Fabric HorizonDB, a serverless variant inside Fabric that provisions in seconds and pauses when nobody uses it, and for a DMS path that moves existing Azure Database for PostgreSQL servers onto HorizonDB.

Teams moving off Oracle can test a new Oracle-to-PostgreSQL migration in Azure DMS, also in preview. Cosmos DB developers now have a generally available Rust SDK and semantic reranker, and Cosmos DB Shell lets them query from VS Code or the portal with MCP support built in. On Azure Managed Redis, the Redis 8 preview folds JSON, search, time-series, and vector search into a single version. Anyone who wants to develop against Azure SQL Database on a laptop can pull a preview container that needs no Azure subscription.

## Developer Tools

The Microsoft Copilot SDK 2.0 is generally available, built on a native Rust runtime, supported in six languages, and using the same agent harness Microsoft and GitHub run internally. The GitHub Copilot app now takes Azure DevOps repositories from clone to merge and runs tests in a real, signed-in browser. Copilot code review adds local reviews in the CLI and app, secret detection, adaptive review effort, and cross-repository context. Copilot Code, a natural-language app builder with cloud and local sandboxes, is in the Frontier program, with general availability planned for December and a macOS local sandbox still to come.

## Copilot and Business Applications

The Copilot app now brings Chat, Cowork, Code, and Autopilot into one experience, and Office in Copilot puts Word, Excel, and PowerPoint inside it as a generally available feature. Autopilot, a long-running personal agent with its own identity, memory, and tool access, is rolling out to Frontier customers. Salesforce in Copilot entered preview with more than 38 prebuilt sales skills, and zero-copy data federation between Salesforce Data 360 and Fabric OneLake is generally available. For spend control, Agent 365 FinOps previews cost visibility, policies, alerts, and Fabric-based chargeback.

Cost tracking also featured in practitioner reactions. In his [newsletter](https://www.linkedin.com/pulse/which-8-microsoft-ignite-announcements-am-i-most-ai-why-karuparti-qirue/), Microsoft principal AI apps architect Anurag Karuparti wrote that tokenomics is among the top challenges his customers raise, and he proposed a different unit for agent ROI:

> The metric that matters isn't just tokens consumed. It's cost per successful business outcome. That's how I think enterprises should start measuring agent ROI.

Writing for business leaders, Aaron Reich, CTO of the Accenture and Microsoft joint venture Avanade, [built his Ignite analysis](https://www.linkedin.com/posts/aaron-reich_heres-my-microsoft-ignite-2026-analysis-ugcPost-7531042241856053250-ZkXp) around trust rather than speed:

> Speed isn't the bottleneck anymore, trust is. As AI drives the cost of knowledge toward zero with apps being easier to build, agents doing more work, and abundant intelligence, the scarce things are hard and need more attention: institutional knowledge, judgment, accountability and trust.

## Security, Identity, and Governance

At the Microsoft Hub, where he spent the week answering customer questions, Microsoft MVP Muhammad Atif [noticed a change](https://www.linkedin.com/pulse/thats-wrap-microsoft-ignite-2026-muhammad-atif-sxief/) in what customers wanted to know:

> How do we actually put this into production? How do we scale AI and agents across the organisation? How do we govern and secure them? How do we control the cost as adoption grows?

Entra now assigns Agent IDs automatically to discovered local agents, starting with GitHub Copilot CLI and Claude Code, and previews an MCP Firewall that controls access to MCP servers, tools, prompts, and transports. The Microsoft MCP Server for Enterprise, which gives agents permission-controlled access to Entra data, is generally available. Defender's runtime protection for local AI agents on Windows is generally available to Defender for Endpoint P2 customers, while Intune previews local agent governance that marks devices with unapproved agents as noncompliant. Agent 365 now has a generally available tools registry that lists the plugins, skills, MCP servers, and connectors agents use; MCP governance is in preview through Azure AI Gateway and LiteLLM; and Dynamic Agent Risk combines runtime, posture, and blast-radius signals into risk levels for each agent. Microsoft Perception, formerly Project Perception, is now generally available, with its Triage Agent covering about 80% of alerts in a typical Defender queue.
