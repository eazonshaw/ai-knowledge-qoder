## 正文

VoidZero, who have been aquired by Cloudflare, have [released Vite+ 1.0](https://voidzero.dev/posts/announcing-vite-plus-1-0), the first stable version of its unified JavaScript toolchain, around three months after the [beta](https://voidzero.dev/posts/announcing-vite-plus-beta) that InfoQ [covered in August](https://www.infoq.com/news/2026/08/vite-plus-beta/). The MIT licensed release is, according to VoidZero, approaching two million weekly downloads, with more than 2,600 public repositories already depending on the `vite-plus` package.

The core proposition is unchanged from the beta, a single `vp` command line tool manages the Node.js runtime, the package manager, and a frontend stack of Vite 8, Vitest, Oxlint, Oxfmt, Rolldown, and tsdown, all configured from one `vite.config.ts`. Rather than adding new headline commands, the work between beta and 1.0 has concentrated on CI, migration, diagnostics, and ecosystem compatibility.

On the CI side, the `setup-vp` action, which collapses Node.js setup, package manager setup, and dependency caching into a single step, is now available for GitLab CI/CD alongside the existing GitHub Action. Vite+ is also now distributed through Homebrew and as a Docker image.

`vp migrate` now handles [tsup](https://github.com/voidzero-dev/vite-plus/pull/2434) projects and resolves a range of edge cases reported during the beta. The command prints its plan before touching any files, though VoidZero cautions that large projects may need follow-up work and advises teams to read the [migration guide](https://viteplus.dev/guide/migrate) before running it on production code. A ready-made migration prompt is also provided for teams using coding agents.

Two new diagnostic commands target the opacity of a bundled toolchain. `vp toolchain` reports the exact version of every tool Vite+ provides, while `vp env doctor` explains how the runtime and package manager were resolved when that resolution goes wrong. A new `vp hooks` command sets up, enables, and disables Git hooks, with `vp staged` running checks against staged files only, a role commonly filled by Husky and lint-staged.

The tools underneath Vite+ have moved on since the beta as well. Vitest 5 is now stable, Vite 8.1 shipped bigger experiments around Bundled Dev Mode, and Oxc gained [native React Compiler support](https://oxc.rs/blog/2026-08-18-react-compiler-support), which VoidZero says makes the compiler 10 times faster than the Babel plugin it replaces. Because Vite+ ships as a single dependency tested as a unit, these upgrades arrive as one version bump.

VoidZero highlighted [Tiptap](https://github.com/ueberdosis/tiptap/pull/8151) as an example of 1.0 adoption, with the editor project replacing its separate Vite, Vitest, tsup, and Oxc setup with Vite+. Other named adopters include Dify, Cloudflare's Next.js-compatible vinext framework, BlockNote, Inkline, npmx, and Hono.

Commentary on the stable release has repeatedly reached for the Python comparison, with developers on [Hacker News](https://news.ycombinator.com/item?id=48759761) framing Vite+ as the JavaScript answer to `uv` and one calling the bundled tools "killer good and fast". Others welcomed a "boring but works" default. The sharpest criticism targeted churn rather than the concept: one commenter noted Vite shipped "five major versions in the four years 2022-2026", each with breaking changes, and said they did not want to become "a vite upgrade engineer".

On [Reddit](https://www.reddit.com/r/javascript/comments/1wu45s9/announcing_vite_10/), early adopters flagged that Vite+ installs runtimes into folders:

> The one thing I've noticed since installing Vite+ is that it puts everything into its own folders so debugging and finding where things are installed is a bit of a nightmare

To which VoidZero have confirmed the reasoning for this:

> Oh yes. That’s for easier switching and separation.

VoidZero is explicit that 1.0 is a stability milestone rather than a finished product. Remote caching, deeper monorepo diagnostics, and new `vp release` and `vp docs` commands are [planned for future versions](https://voidzero.dev/posts/announcing-vite-plus-1-0#what-s-next).

Vite+ is an open-source, MIT licensed unified toolchain for web development developed by VoidZero, the company founded by Vite creator Evan You, which has joined Cloudflare. Built by the team behind Vite, Vitest, Rolldown, and Oxc, it brings runtime and package manager management, linting, formatting, testing, building, and task running together behind a single command and configuration file. Vite+ is framework-agnostic and can be used for anything from React apps and Vue component libraries to Node.js CLIs and large monorepos, even in projects that do not already use Vite.
