## 正文

“macOS 和 Windows 已经不适合 Agent 时代了。”David Heinemeier Hansson（DHH）近期在播客中分享道。

从事软件开发约 30 年来，他互联网软件开发领域颇具影响力的人物。作为 Ruby on Rails 的创造者、Basecamp 的联合创始人，DHH 曾经是 Apple 生态的长期拥护者。但如今，他正在推动一个名为 Omarchy 的 Linux 发行版，并将其称为第一个为 Agent 时代原生打造的操作系统。

“我们希望让数十万人从 Windows 和 Mac 转向 Linux，最终让那个持续了 25 年的预言成真：Linux 桌面之年终于来了。”DHH 说道。

在他看来，过去 Linux 最令人头疼的终端、配置文件和复杂错误信息，恰恰是 Agent 最擅长处理的东西。与此同时，AI 正在让软件开发成本迅速下降，Word、Photoshop 这样的传统应用也可能逐渐失去存在的必要。这场变化甚至可能重新打开操作系统竞争的大门。DHH 的目标是，未来三年让 Linux 的用户规模超过 macOS。

他认为，AI Agent 正在改变软件行业最底层的竞争规则：代码不再是长期护城河，开发一款软件也不再需要庞大的工程师团队。过去只有微软、Adobe 这样的巨头才能建立的产品和生态，小团队如今也有机会重新创造。操作系统、应用软件，乃至程序员本身的价值，都可能因此被重新定义。

**太长不看版**

Q：Linux 桌面迎来转机，有多少来自 Apple、Windows 等公司的生态限制，又有多少来自 AI？

DHH： 真正的转折点是 Agent。现在只需要告诉 Agent“修改我正在使用的操作系统”，它就能直接完成。Linux 过去让人头疼的终端、配置文件和复杂错误信息，恰恰是 Agent 最擅长处理的东西。相比之下，Apple 却在不断增加 macOS 与 Agent 协作的难度，甚至警告用户不要让 Claude 访问文件。macOS 和 Windows 都不适合 Agent 时代。

Q：过去 Linux 无法成功，一个重要原因是缺少 Word、Photoshop 等关键应用。现在情况有什么不同？

DHH： Omarchy 社区有人只用了两周，就重新开发出我过去唯一还需要在 Mac 上使用的 Adobe Lightroom 替代品，效果甚至更好。现在，任何人都可以借助 Vibe Coding 复刻优秀软件，开发成本和难度已经大幅下降。更重要的是，很多应用甚至不需要复刻，因为 Agent 可以直接完成原本需要打开应用才能完成的工作。

Q：软件真正重要的部分，往往是设计、交互和长期打磨，而不是代码行数。AI 能替代这些工作吗？

DHH： 完全正确。AI 反而让我能够把更多品味、愿景和完美主义注入软件。过去发现一个像素位置不对，到真正修好，中间存在很多障碍，现在这些障碍消失了。AI 可以完成前 80%的工作，但最后 2%的细节打磨仍需要人的判断。我最享受的恰恰是最后这部分。

Q：你认为 AI 什么时候才算真正达到超级智能？

DHH： 至少在软件开发领域，我认为我们已经拥有了超级智能。从综合能力和任务完成速度来看，AI 已经超过我认识的绝大多数程序员。当然，在非常狭窄的专业领域，顶尖程序员仍然有优势。但实体机器人完全是另一回事，我去过宇树科技，他们认为通用机器人可能还需要 4—10 年。

Q：你怎么看前沿实验室与开源之间的关系？

DHH： 开源和开放权重至关重要，它们能够让行业保持公平竞争。我很欣赏 Opus 等闭源前沿模型，也认可 OpenAI 等实验室的技术进步，但绝不能让 AI 行业最终变成两家实验室瓜分市场的双寡头格局。我们需要闭源前沿模型和开放权重模型同时发展，否则整个行业都会受到伤害。

Q：未来 12—24 个月，你希望实现什么目标？

DHH： 我最大的目标之一，是大约 3 年内让 Linux 桌面用户超过 macOS。全球 macOS 用户大约只有 1.8 亿，Linux 完全有机会超过这个数字。过去 25 年，Linux 桌面一直被认为是一个永远无法实现的预言，但 Agent 让这个机会窗口重新打开了。我们希望先拿下桌面端，再向移动端发展。

Q：现在的程序员应该如何面对 AI 带来的变化？

DHH： 我真正尊重的那些顶尖程序员，已经 100%拥抱了 AI。很多普通程序员会焦虑，因为他们过去依靠多年积累的手工编码技能获得职业位置，现在突然不知道自己还能不能成为优秀的创造者。我理解这种焦虑，但我们不应该因此退回工业化以前的时代。技术变革不会倒退，我们必须继续向前，并找到让所有人参与其中的方式。

下面是播客详细内容，我们在不改变原意基础上进行了删减，以飨读者。

## “macOS 和 Windows 都不适合 Agent”

主持人： 你第一次用 Linux 发行版是什么时候？

DHH： 是 Ubuntu，大概两年半前。如果是说桌面系统，那确实比较晚，但服务器上的 Linux，我从 20 世纪 90 年代就开始用了。过去我没有把 Linux 当桌面操作系统用，2001 年以来，我一直是 Mac 用户。我当时应该是从 OS X 的 Beta 4 版开始用的，此后一直留在 Apple 生态里。

直到 Apple 开始偏离正轨，沉迷于轻松躺赚服务费：只要从别人的业务里抽走 30% 就行。这生意多好啊，你甚至不需要创新。你可以花 10 年开发一辆最后根本卖不出去的车，也可以推出一款彻底失败的滑雪面罩式产品，没人会在意。只要能从别人的业务里抽走 30%，你就能过得很好。

但这套商业模式对开发者并不友好。我曾经是那些几十年来一直替 Apple 说话的开发者之一。最终我还是受够了，于是转向了 Linux。

主持人： 这是不是 Linux 桌面迎来转机的主要原因？其中有多少来自 Apple、Windows 等公司对生态的限制，又有多少来自 AI 和新技术，尤其是现在可以借助 AI 修改操作系统？

DHH： 我昨天晚上还在试用，真的非常惊人。你只需要告诉 Agent：“修改我当前正在使用的操作系统。”它就会去做，而且修改确实能生效。这太不可思议了，这才是 Linux 真正迎来大规模发展机会的原因。

其他那些促使我离开 Apple 的因素，比如 Apple 对开发者不够友好，其实只有少数开发者在乎，不是所有开发者都在意。很多人仍然忍着，因为你要卖商业软件，就必须进应用商店。所以我不认为这些问题足以推动大批用户转向 Linux。

但 Agent 时代绝对可以做到这一点。就在今天，又有消息说 Apple 正在进一步增加 macOS 与 Agent 协作的难度，弹出更多让人紧张的提示，警告用户不要让 Claude 访问自己的文件。可你不给它文件访问权限，它还能做什么？Apple 正在朝完全不同的方向走。

我们则会全力投入 Agent。过去大约 5 个月，甚至可能已经 6 个月，整个操作系统都有 Agent 参与开发。我没有亲手为 Omarchy 写过一行代码，但通过 Agent 已经生成了几十万行代码。我们用这种方式加速 Omarchy 本身的开发，创造东西的速度快得连我自己都难以相信。

现在，我们还要把这种能力交到用户手里。想象一下，当你发现整个操作系统都可以灵活修改时，会是什么体验。你可以改任何东西，也可以改其中任何一个元素的工作方式。你想要一个新的开始菜单，想把时钟移到别的位置，想换一个日历，或者只是想给操作系统现有某个功能加一项能力，都可以直接通过提示词完成。有时几秒钟就能实现，最多也就几分钟。这种体验非常让人着迷。

任何人真正体验 5 分钟之后，都不会再愿意回到过去的方式。所以我非常相信一个判断：macOS 和 Windows 都不适合 Agent 时代。未来谈到个人电脑，Agent 时代可能会成为最重要的事情。我们现在用的操作系统已经存在 40 年了，它们围绕鼠标和点击操作建立起来，但这种交互模式并不适合 Agent 时代。

举个简单的例子。如果你想在 macOS 里重新设置切换工作区的快捷键，只有一种办法：手动进设置应用，一个字段接一个字段地点、输入新快捷键、再点下一个字段，再输入另一个快捷键。你不能用自然、自动的方式完成这件事。当然，你也可以让计算机使用功能去操作界面，但那种方式很笨，也很荒谬。

而 Linux 过去那些让人觉得难用的特点——高度依赖终端、有一堆难懂的配置文件、错误信息晦涩，恰恰是 Agent 最喜欢的三件事。它们希望所有事情都有命令行接口，希望配置文件结构明确、可以直接编辑和更新，也希望错误信息尽可能包含完整细节。

所以，Linux 过去那些长期短板，今年竟然变成了人们想在电脑上用 Linux 的理由。只要你关注 Agent 和 AI，就会理解这一点。而现在，谁做东西还能完全不关注 Agent 和 AI 呢？

我认为，Apple 现在有可能成为 Agent 时代的 AOL。它会打造一个“围墙花园”，告诉用户：“我们这里有自己的模型，你不需要用真正前沿实验室开发的 Agent，只要给我们一个机会，我们就能提供一个经过弱化、受到保护的版本。”但大多数人并不想要 AOL，他们想要开放互联网。我们希望通过 Omarchy 把这种开放性带给用户。

## “Agent 会直接消灭整类应用”

主持人： 那在这样的世界里，移动设备会发生什么变化？

DHH： 移动设备也必须发生同样的变化。这也是我为什么如此期待 Agent 时代先从桌面端开始：25 年来，第三个操作系统平台的机会窗口第一次重新打开了。

上一次出现这样的机会，是 2001 年 OS X 发布的时候。那是上一次有新操作系统进入市场，并真正撼动全球市场份额。此后，机会窗口一直关着。今年，窗口重新打开了。Linux 突然又有了机会，而且是过去 25 年里从未有过的机会。

移动领域也一直受同样格局制约。我们长期处在双寡头市场，Google 和 Apple 把其他所有企业业务里那笔丰厚的 30% 收入分走了。你还能怎么办？Microsoft 曾经试过，花了几十亿美元想让 Windows 成为移动操作系统，但最终没成功，一个重要原因就是应用不够。假如 Windows Phone 上连 Instagram 都没有，谁愿意换过去？所以这个项目最后不了了之。

现在情况正在改变，而且我们已经在 Linux 上看到这种变化。

Omarchy 社区里有一个人，重新开发了我过去唯一还需要保留一台 Mac 来运行的应用：Adobe Lightroom。因为 Lightroom 里有我所有插件，还有为相机设置的预设，我一直不愿意放弃这些东西，所以之前专门留了一台 Mac。

结果，一位社区成员只用了大约两周，就把 Lightroom 的功能重新实现了一遍。不仅如此，他做出来的东西甚至比 Adobe 花了 15 年、投入数千万美元乃至更多资源开发的产品还好。

把这件事放到手机和移动操作系统上想一想：如果一个新平台能获得你想要的所有应用，会发生什么？因为只要某个应用不存在，就会有人把它做出来。现在，大家只需要通过 Vibe Coding 花 5 分钟就能完成。整个游戏规则都变了。

这些生态系统之所以能形成锁定效应，核心就在于应用是否可用。而在 Agent 时代，软件开发的价格和难度都已经降到了接近零。任何人，不只是软件开发者，只要能够引导这些 Agent，就有机会复制出 Adobe 级别的产品，或者任何其他优秀软件。这彻底重置了竞争格局。

所以我现在的口号是：先拿下“曼哈顿”，也就是桌面端；然后再拿下“柏林”，也就是移动端。

主持人： 这确实很有意思。5 年前，打造第三个移动生态几乎注定失败，难度大得难以想象。而现在，只需要投入一定的 Token 预算，就有机会复刻排名靠前的数万款应用。甚至很多应用可能根本不需要被复刻，因为 Agent 可以直接完成用户原本需要通过应用来完成的工作。

DHH： 没错，这完全有可能实现。

主持人： 这里还有一个很有意思的地方。过去谈到 Linux 为什么无法成功，历史上最常见的例子就是它缺少几个关键应用：没有 Microsoft Word，没有 Adobe Photoshop，还有其他一些重要软件。现在情况已经不同了。我上一次打开文字处理软件是什么时候？我现在只需要让 Agent 帮我起草一份合同，然后用 Markdown 审阅。满意之后，再让它生成 PDF，效果就很好。

DHH： 我最近一直在筹建 Omarchy 背后的非营利组织 Omicron Foundation。我们已经通过 Token 和捐赠筹集了大约 2300 万美元。

期间，我需要制作很多合同，而每一份合同都是 Agent 完成的，整个过程根本没用到文字处理软件。我现在甚至不再亲自签署文件。我只需要检查一遍，确认没有问题，然后告诉 Agent：“可以了，签字吧。”Agent 已经有我的签名，它会把签名放到文件上，再把文件发送出去。

所以，我现在不再使用文字处理软件，也不再需要 Word。照片处理也是一样。如果你想让照片变得更好，只需要告诉 Agent：“把这张照片处理得漂亮一些。”难道你还要花几十个、几百个小时去学 Photoshop 的各种复杂功能吗？没人会这么做。大家会直接让 Agent 处理，而且它能做得非常出色，最后把一张效果很好的照片交还给你。如果你想从照片里移除某个人，也只需要说：“把左边那个讨厌的家伙删掉，我只想留下这两个人。”然后就完成了。

我认为，Agent 会直接消灭整类应用。

过去，像 Photoshop 这样的应用不仅仅是一个软件，它本身甚至代表一种职业。你必须学它，有时还需要花几年时间才能熟练掌握。现在，Agent 已经接手了这些工作，不需要打开应用也能完成。即便你仍然想用应用，比如当你需要 Word 的某项功能，或者 Photoshop 的某项功能时，基本上都可以临时生成出来，马上使用。我在社区里也已经看到了很多类似情况。

我们现在看到的 AI 还处在一个很奇怪的早期阶段。模型通常每秒运行大约 50 个 Token；如果开启超高速模式，速度可能只有每秒 12 个 Token。这还不足以让整个体验真正有生命力。

大约两周前，Fireworks 在他们的大会上展示了每秒 1500 Token 的生成速度。他们演示了一个游戏案例：从输入“帮我做一个俄罗斯方块游戏”，到游戏真正运行起来，只用了 4 秒钟。随后，他们又制作了另一个游戏，比如横版卷轴游戏、射击游戏。游戏已经显示在屏幕上并且正在运行，演示者只需要继续输入提示词：“增加激光”“增加炸弹”“增加更大的怪物”。整个游戏就在实时变化。

这简直就是软件未来形态的预告：一切都将能够实时变化。现在每秒 1500 个 Token 已经可以实现了。那么明年会怎样？两年后，当模型达到每秒 10 万个、甚至 100 万个 Token 的速度时，又会发生什么？

从整体方向来看，任何人想要推出一个新生态系统并获得成功，过去面临的那些历史性障碍都将逐渐消失。

不仅生态系统本身可以更容易地创建，现有产品也可以被更快地开发出来。目前这个版本的 Omarchy，是我和项目中的主要合作伙伴 Ryan Hughes 利用业余时间、在大约两个半月内完成的。它后来发展成了现在这个迅速受到关注的项目。

我们现在面对的竞争对手，是微软内部成千上万名程序员，以及全球大型公司里数以万计的开发人员。但突然之间，只有几个人组成的小团队，就能够做出不仅具有竞争力、甚至更优秀的产品。这在过去是完全不可想象的。

这也会改变风险投资的逻辑。过去大约 20 年里，资金大量流向开发人员，因为你需要雇佣开发人员来构建产品，还需要准备好几年的资金，让他们慢慢把产品做出来。现在，这个周期突然被压缩到了几天、几周，最差也只是几个月，而且我们用的还是当前这一代模型。

在我开发 Omarchy 的这段时间里，模型进步就非常明显。我开始新一阶段开发时用的是 Opus 4.8，当时它已经很好用了，后来又有 Sonnet，现在则有了 Opus 5.5。Opus 4.8 和 Opus 5.5 之间的差距非常大。

圣诞节前我们还会不会迎来一次模型更新？很可能会。如果没有，明年年初也会有。这些跨代进步正在加速。所以，谁要是还认为源代码能形成护城河，哪怕是数百万行代码，或者认为代码能保护一个生态系统，那都太天真了。

## 任何不完美的软件都是机会

主持人： 听你这么说很有意思，因为我一直把你看作一个非常讲究工艺的人。你的设计审美很好，交互体验也做得非常出色，你在这个领域很有传奇色彩。我自己也玩《星际争霸》，现在还在玩，虽然已经 50 岁了。最近游戏刚推出一个补丁，调整了幽灵兵的属性。这个单位已经存在 20 年了，现在仍然只是做一些细微调整。

某种程度上，我能理解我们可以让大模型很快写出一段代码。但另一方面，看看你做的产品，再看看《星际争霸》这样的游戏，我意识到软件真正重要的部分，往往是那些与代码行数无关的细节。随着时间推移，软件的价值就在于这些细微调整，而不是代码本身。这对我来说像是一种护城河。软件的长期价值来自设计上的大量细节选择。所以，变化也许没有想象中那么大，我们仍然需要真正热爱软件、能够把自己的品味和理念融入产品的人，只不过他们不再需要亲自写每一行代码了。是这样吗？

DHH： 完全正确。我觉得，现在我反而能把更多自己的品味、愿景和完美主义注入软件，因为从我发现某个地方不够好，比如有几个像素的位置不对，到真正把它修好，中间的障碍已经消失了。

我很喜欢这种状态。现在，只要看到任何问题、任何不够完美的软件，我都会把它当成一个机会，继续打磨，直到它变得完美。这就是为什么我现在每天工作 16 个小时。

过去我还专门写过一本书，叫《It Doesn't Have to Be Crazy at Work》。这本书的主张就是工作不应该疯狂。但现在，工作简直疯狂得不得了。原因在于，如果你和我一样，是那种极度追求完美、喜欢不断打磨细节的人，那么你现在就像突然获得了超能力。这种感觉令人着迷，甚至可能对健康和睡眠造成危险，至少在一段时间内是这样。

我认为，我们正处在这样的阶段。你说得完全对，很多人都可以做出这些东西。过去很多事情，只要花足够长的时间，任何人都可能完成，但他们最终并没有去做。现在仍然需要一定的愿景、足够的关注和耐心，还需要把所有部分整合起来，并有决心把事情真正做完。

我们现在看到很多 Vibe Coding 项目，刚开始看起来很有希望，但后来开发者逐渐失去兴趣。对一些人、甚至大多数人来说，最有成就感的阶段可能是最初的 80%。先把前 80% 做出来，已经很不错了。

主持人： 对，先把前 80% 做完就很有成就感。剩下的 20% 往往有些不协调、不够完善，还会有一些 Bug。很多人到了这个阶段就失去兴趣了。

DHH： 但不知为什么，我的多巴胺奖励机制恰恰集中在最后 2%。前面 98% 我其实并不那么在意，我真正想要的是最后那 2%。软件开发最让我满足的，就是把最后这部分打磨好。如果你也是这种类型的人，不断增加细节、持续迭代，直到产品真正完美，那么现在是历史上一个极其容易让人上瘾的时期。

至少目前，仍然需要有人来引导这些 Agent。我还没有找到一种正确的循环或工作方式，能够让我一次性发出指令，就让所有东西都完美生成。设计和产品判断仍然需要人的眼光，需要有人在关键时刻给出方向。

但与此同时，你会感觉自己身后有一支庞大的军队，而且完全没有协调成本。我以前就说过，我从来没有兴趣把 37signals 扩张成一家拥有 6000 人、甚至 60000 人的公司。那当然可以做得更大，但我就得和 60000 个人打交道了。那简直是一场灾难。

主持人： 绝对是痛苦和折磨。

DHH： 但如果通过 Agent 获得 60000 人的生产力，那就完全不一样了。没有无休止的争论，没有人力资源管理，没有委员会会议。只有我和一整支 Agent 队伍，以极高的沟通效率，围绕我提炼出来的愿景执行任务，共同打造我心目中完美的计算机。天哪，这太不可思议了。

Toby Lütke 曾经谈到过类似的感受：他周末独自与 Agent 工作，效率极高，但到了周一又必须回到那家拥有 7000 名员工的公司。周末与 Agent 一起工作，就像进入了超速模式，一切都进展得非常顺利；然后突然停下来，回到办公室，又要处理人力资源、团队协作、进度更新、报告，以及经营一家公司的各种琐事。如果采用另一种工作方式，就不必处理这些事情，而且你仍然可以获得相近、甚至更好的结果。

这就是当前这个阶段最令人震惊的地方。更令人惊讶的是，它的成本竟然如此低。我大约一个月前在 X 上开过一个玩笑，说自己拥有无限 Token。毕竟，我已经工作了 20 年，现在算是有钱了，想买多少 Token 都可以。

你知道我实际买了多少吗？我只订阅了 3 个 Claude 套餐，就这么多。过去 3 个月里，我只记得有两周真正用满了这些额度或接近用满。大多数时候，我只需要一个每月 200 美元、20 倍额度的套餐，就能完成所有事情。

所以，不要告诉我这种生产力革命只属于那些真正拥有无限资金的人，完全不是这样。而且我现在用的还是前沿模型，我们甚至还没有讨论开放权重模型、更便宜的模型，或者使用 Llama、进行各种优化之后会发生什么。

我现在只是用 Opus 5.5，让它把所有事情处理好，就这么简单。我的工作推进速度已经快到，现有能力几乎被充分利用了，但我们仍然可以以这种闪电般的速度继续前进。所以，我认为现在仍然有人的发挥空间。

但我也没有自负到认为这种情况一定会永远持续。我认为完全有可能到明年，我们就会拥有真正的超级智能，它在所有事情上都比人类做得更好，甚至比我更擅长打磨一台完美的计算机。到那时，你只需要告诉它：“给我做一台好用的电脑。”它就会为你定制 Linux 内核，以及其他所有东西，然后一切就完成了。

所以，我很珍惜现在这个阶段：也许只在一眨眼的时间里，人类仍然能够为这个过程增加额外价值，同时又拥有如此强大的能力。至于明年年底会发生什么，我不知道，也许到时候我们都已经不在了。所以，享受当下吧。

## 和宇树团队交流：他们认为超级智能还得好几年

主持人： 每次有新模型出来，你都会用什么方法判断它是否已经达到超级智能？我可以举个例子。我自己的测试是，每次出现一个新模型，我都会让它去购买实现自身所需的所有东西。我的家里经常会收到各种机器人零部件，我不是开玩笑。我给它 20000 美元预算，然后告诉它：“去把你的机器人造出来。”接着就会有东西寄到家里，比如 OLED 显示屏，以及各种其他零件。

但现在的模型距离真正完成这件事还差得很远。这就是我的人工超级智能测试：当我拥有一台能够自主行走、能够自己订购零件并把自己组装出来的机器人时，我就会认为它已经达到了某个重要阶段。我想知道，你有没有类似的判断标准，能够告诉自己：“现在，它真的来了。”

DHH： 我还没有，也许我应该有。不过，我现在有一种感觉：至少在软件开发领域，我们已经拥有超级智能了。

如果考虑能力的广度，AI 已经比我认识过的任何程序员都更优秀。我认识的一些顶尖程序员，在非常狭窄的专业领域里仍然能够胜过 Agent，但如果把所有能力放在一起，再考虑它们完成任务的速度，那么我们已经拥有了超级智能。现在，我只需要通过提示词，再稍微引导一下，就能构建任何东西，真的是什么都可以。

不过，你刚才提到机器人，这个例子很有意思。大约两周前我刚去过中国，我们去了宇树科技，也和那里的团队交流了，我听到的观点和硅谷很不一样。我刚看过 Dwarkesh 的一场访谈，其中有人认为，明年我们可能就会迎来超级智能，并出现快速起飞。但宇树的人却认为，也许还需要 4 年、5 年，甚至 10 年。

主持人： 是的。所以这里出现了一种很奇怪的反差：从事软件工作的人会觉得“天哪，这一切马上就要发生了”；而从事执行器、机械结构等实体硬件工作的人则会说：“我不确定，也许剥一个洋葱其实都很难。”

DHH： 就我目前的情况来说，Grokbot 认为，在我家里部署 AI 的正确方式基本上就是家庭自动化。所以它一直在为我家订购各种智能家居设备。我觉得，至少我可能会先拥有一个类似《星际迷航》的家庭系统：墙上有一块显示屏，屏幕上有一张会和你说话的脸，还能控制整栋房子。它可能会先于真正的机器人出现。但我认为它的选择其实很务实。

## 两家 AI 实验室瓜分市场会是灾难

主持人： 你刚才提到了开源。我一直觉得你是一个非常反传统、对权力集中有强烈看法的人。你已经谈到了一些相关问题，那么你怎么看前沿实验室与开源之间的关系？

DHH： 我认为，开源和开放权重至关重要，它们能够让整个行业保持公平竞争，我们需要竞争。

在职业生涯的两个阶段，我都非常反感双寡头瓜分一切的局面。互联网曾经给我们带来过一段短暂的避风港，大约从 2000 年到 2009 年。那是一个非常美好的时代，最重要的平台完全开放、完全免费。任何人都可以构建任何东西，不需要向谁申请许可。

后来，移动平台出现了，游戏规则就结束了。我们又回到了那种严苛的经济环境：你必须请求平台允许自己的应用上架，才能让自己的业务存在。我个人完全无法接受这种局面。

所以，尽管我很欣赏 Opus 5.5，也认可 OpenAI 正在做的事情，但如果最终行业变成双寡头格局，尤其是这种格局还由政府动用强制力量来维持，那将是一场噩梦，对我们所有人都非常不利。

这个行业曾经经历过类似的事情。20 世纪 90 年代的加密战争期间，我们差一点就要禁止公钥加密，因为 NSA 等机构担心，使用加密技术之后，他们将无法监听所有通信。试想一下，如果互联网没有加密技术，它的发展轨迹会是什么样？人们如何进行商业交易？如何通信？这会对世界经济、全球发展以及互联网本身造成巨大伤害。我认为，AI 现在正处于类似的临界点。

我经常听到一些聪明人说：“也许政府应该直接接管 AI。”天哪，即便政府不接管，如果最终形成两家实验室瓜分市场的商业格局，也会造成灾难性后果。我们必须避免这种情况。

好的一面是，与计算机行业历史上其他阶段相比，现在闭源模型之间的竞争其实更加激烈。领先者并不只有两家实验室。SpaceX 的 AI 业务也非常接近前沿水平。Google 有时看起来处于领先位置，下一刻又像是跑到某个岛上抽着奇怪的东西一样，状态让人摸不着头脑。但至少它仍然有机会重新参与竞争。除此之外，还有几家实验室正在逐渐追赶。我认为这非常重要。但更重要的是，开放权重模型也正在变得越来越好。

我不知道它们究竟落后多少。比如 GLM 5.3 或 DeepSeek Flash，在某些任务上可能落后 6 到 7 个月，甚至没有那么久。当然，现在有很多针对基准测试的优化，我并不完全相信那些结果。

某家公司发布一个基准测试，声称自己的模型和 Opus 4.8 一样好，但我真正使用时可能会发现，在它自己的测试中也许是这样，在真实世界里却未必如此。但这又有什么关系？它们已经进入竞争了。这些模型确实有用，而且可以在自己的本地硬件上运行。

这件事让我非常惊讶。大约 6 个月前，我还写过一篇文章，大意是：人们为什么要购买性能强大的个人电脑？当时能够在本地运行的模型实在太差了，几乎什么都做不了，也无法完成真正重要的任务。幸好，我完全错了。现在甚至还没到同一年年底，DGX Spark 就已经能够运行真正有用的模型。

Qwen 3.8 Flash Next 也是一个完全可以使用的模型。你可以在桌面上放一台小型设备，里面就拥有真正的智能，而且只需要花几千美元就能买到。这太不可思议了，我们迫切需要这样的产品。

不过，我希望所有路线都能存在。开源社区里有些人立场非常强硬，认为要么完全开源，要么就没有意义。我并不认同这种观点。

我也会为美国拥有两家领先的前沿实验室而感到高兴，因为它们取得的进展可以让我们继续在此基础上构建产品。只要它们受到竞争约束，不至于失去制衡，这就是很棒的事情。我们不能让它们拥有一种无限资金的“作弊模式”，在没有竞争的情况下，想把 Token 价格提高到每百万个 500 美元就提高到 500 美元。因为我们真的会付钱，我们绝对会付钱。

我们已经见过类似的故事。社交媒体和整个互联网产业发展起来之后，在线广告市场逐渐被 Google 和 Meta 两家公司瓜分。它们吸走了在线广告价值链中 99% 的价值，因为所有人都愿意为了每花 1 美元多拿回 1 美分，而接受这样的市场结构。我认为这很不正常。尽管我承认这两家公司在某些领域作出了贡献，但当它们几乎拿走了全部新增价值时，这种局面就很反乌托邦。

如果不受到约束，AI 实验室也完全可能这样做，因为资本主义就是如此运作的。很多时候，这甚至可以说是资本主义的一个特征，而不是缺陷：正是这种预期激励了投资，每个人都想成为下一家 Google、Meta、Anthropic 或 OpenAI 的股东。

但这些想法可以同时成立：我们需要开放权重模型，也可以为前沿实验室的进步喝彩。如果两条路线都能发展起来，每个人的处境都会变得更好，我们就有机会进入一个资源极其充裕、所有人都能分享繁荣的世界。

## DHH 的计划：让 Linux 超越 macOS

主持人： 我注意到，随着模型能力不断增强，我们似乎都在不断提高自己的目标。这也是我觉得很有意思的一点：即使是那些在软件开发最初 10% 阶段就能获得多巴胺奖励的人，也必须不断提高自己的野心，才能继续获得这种满足感。你做出的东西，可能在 5 年前还会让人觉得不可思议，但现在回头看，你却会觉得它不怎么样。

你希望在 X 上得到一个点赞，结果你做了一个 3D 项目，别人却说：“就这？”你只好说：“不，我做的是一个能够自我修改、具备各种惊人功能的游戏。”最后也只得到 40 个赞。你就会开始怀疑自己到底在做什么。所以，我觉得现在很有意思。

我们正在谈论你推动的这场全新的 Linux 桌面革命。接下来，你的目标会提升到什么程度？未来 12 到 24 个月，你可能会构建出什么过去从未想过自己能够做到的东西？

DHH： 我已经承认，这个项目的野心一直在膨胀。我去年刚开始做它的时候，甚至还在手动开发。如果你能相信的话，当时我用自己的十根手指写一些 Bash 脚本，经常对着 Bash 破口大骂，而且能做的事情非常有限。

我当时只是想：“如果我能给自己做一台更好的电脑，找到一个不受 Apple 控制的地方，那就足够了。”我只想为自己、几个朋友，以及互联网上的一小群人做这件事。后来，我们真的做出来了，进展还不错，有数万人在使用。我们有了一个不错的开源项目，也终于有了一台更好的电脑。这已经很棒了。

然后，Agent 出现了。我的想法从“做一台稍微好一点的电脑就不错了”，变成了“天哪，我们真的可以打造一台完美的电脑”。过去 40 年里，我使用电脑时想要的所有东西，现在基本都可以靠自己实现。当然，和朋友一起做会更有意思，所以我邀请了几十万人一起参与。但即使只有我一个人，也已经有能力打造一台完美的电脑。

当我看到这不仅是可能的，而且真的正在发生；当我看到人们使用 Linux 时，不再只是把它当作 macOS 或 Windows 的替代品，而是认为它明显更好，这种感觉实在太令人满足了。你当然会开始产生一些宏大的想法。

我现在的一个宏大目标是：大约 3 年内，让 Linux 的用户规模超过 macOS。

全球 macOS 用户只有大约 1.8 亿。Mac 并没有那么庞大。我知道在美国，尤其是在硅谷，几乎所有人都使用 Mac，所以它看起来很普及。但在其他地方，它的规模其实很小，只有 1.8 亿用户。这甚至算不上一个顶级互联网服务的规模。那些最大的互联网服务拥有数十亿用户。所以，Linux 当然有机会超过这个数字。

过去 25 年里，Linux 社区一直在谈论桌面 Linux 时代的到来，听起来像一个永远无法实现的预言。但现在，我们真的走到了这个阶段，而且发展速度正在加快。这就是我的野心为什么在过去几个月里不断变大。尤其是最近发布的 Quattro 版本，我们全面投入 Agent 开发，用 Agent 构建产品，再把 Agent 交到所有用户手中。

看到数十万人开始使用它，我就想：好吧，也许 3 年就能做到。但我又想：为什么不在 12 个月后重新检查一下？我们能不能在 12 个月内撼动 Mac 的地位？Apple 花了 20 年才建立起 macOS 的市场位置，而在此之前，它还是一家从 20 世纪 70 年代一路发展而来的公司。我认为这并非完全不可能。

当然，我不会认为未来 12 个月内发生这种事情的概率超过 50%，但我也不会排除这种可能。如果一些实验室里的聪明人认为，RSI（递归自我改进）将在大约 12 个月内带来一个近乎全能的 AI 超级系统，那么我们当然也可以在这个时间里，启动一个全球排名第二的操作系统项目。

当然，这只是我在自己的小圈子、自己关注的领域里保持野心。我并不擅长像马斯克那样在宏观层面设定目标。比如“让人类移居所有星球”，这听起来很棒。如果能让我搭乘 Starship 去火星，我也非常愿意，但那不是我的风格。我会在自己关注的狭窄领域里保持极强的野心，把所有精力投入进去。同时，我也尽量不去想 12 个月后的世界会是什么样子，因为我觉得那是让自己患上严重 AI 精神错乱最快的方式。

我更喜欢“AI 兴奋感”。这是一种温和得多的状态：你对未来感到兴奋和乐观，因为你关注的是当下已经能够实现的事情，是你正在使用现有工具构建的东西。如果你试图想象模型再迭代两代、三代、四代之后会发生什么，就很容易陷入疯狂。因为那时你会开始问：那还有谁需要发挥作用？人类为什么还需要存在？我们最终会不会都变成 AI 仓库里的一堆回形针？我认为这不是一条好的思考路径。

我觉得很多 AI 安全研究人员之所以会变得非常焦虑，就是因为他们每天都在做这样的事情：坐在那里想象未来 12 个月里所有最糟糕的事情发生后会有多可怕。

主持人： 是啊，可能确实会非常糟糕。如果你在 1944 年坐在 Oppenheimer 身边，对他说：“天哪，等这个东西问世，你能想象 5 年后会发生什么吗？地球会变成一片荒原，到处都是核废料。”但后来发生了什么？核弹反而成为维护世界和平的重要因素。
