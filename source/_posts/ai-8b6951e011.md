## 正文

Microsoft has [released TypeScript 7.1 Beta](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/), the first update to the Go-based native compiler that landed as TypeScript 7.0 in July, and the release that finally hands tool authors a programmatic API again. Daniel Rosenwasser announced the beta on 20 October 2026, and the team [pointed developers to it on X](https://x.com/typescript/status/2112610990202507582), inviting feedback ahead of a release candidate and stable build that the [iteration plan](https://github.com/microsoft/TypeScript/issues/63703) tentatively places in late November, though the beta itself arrived two weeks behind schedule.

The headline change restores the compiler API that 7.0 dropped. For three months anything that embedded the compiler, from Vue’s Volar to Svelte, Astro, ts-morph and type-aware linting, was stranded on TypeScript 6. Rather than revive the old monolithic module, 7.1 splits it into focused entry points such as `typescript/sync`, `typescript/async`, `typescript/fs` and `typescript/ast`, paths that previously sat behind an `unstable` prefix now dropped to signal intent. The client also models incremental edits through reusable snapshots, so an editor can derive new state from an old one without rebuilding the world, and the team says the surface will stay backward compatible across all of 7.x once stable.

Sitting on top of that is the beta’s most discussed feature, content mappers, a supported plugin point that lets a package hand TypeScript a virtual view of a non-standard file such as a `.vue` or `.svelte` component, with mappings back to the original so errors point at the right line. Because a mapper runs as a separate process it executes only when you opt in, and the team warns the flag should be treated like any build plugin.

Vue’s language tools are already [porting to it](https://github.com/vuejs/language-tools/pull/6170): maintainer Johnson Chu has shipped Vue Language Tools v4 alpha on top of content mappers, dropping the separate `vue-tsc` binary in favour of a `@vue/content-mapper` that runs inside `tsc` itself. In a [hands-on migration write-up](https://alexop.dev/posts/goodbye-vue-tsc-typescript-7-content-mappers/), the Directus admin app, 581 Vue components across 882 TypeScript files saw type checks fall from 14.19 to 3.10 seconds on tsc 7.1 plus the mapper, a 4.6x speedup over `vue-tsc` 3. The author also flagged that teams adopting the beta would need to run 7.1 in CI alongside an older TypeScript in the editor until Vue tooling stabilises on top of the stable release.

Microsoft’s [MUI docs benchmark](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/#optimizations) falls from 22.2 to 11.9 seconds while roughly halving memory, though heavier codebases such as VS Code see closer to 1.2x. An [independent test against NestJS](https://dev.to/alexgeorgiev17/typescript-71-betas-native-compiler-checks-a-353000-line-project-in-28-seconds-instead-of-124-3h91) put a 353,000 line check at 2.76 seconds on the beta against 4.95 on 7.0 and 12.42 on the old compiler, while flagging a 7.0 memory regression that 7.1 reverses.

On [GitHub](https://github.com/microsoft/TypeScript/issues/65084), Akira Higuchi reported that, in a particular editor workflow, saving a mapper’s watched configuration file could leave types stale until the language server is restarted. The issue remains open.

The language itself gains import attributes in ambient module declarations, TC39 source phase imports for loading WebAssembly, and a stable `es2026` target carrying additions like `Math.sumPrecise()` and `Error.isError()`.

Teams still on TypeScript 5 should move through 6 to 7, and projects using Vue, Svelte or Angular should keep a dual TypeScript 6 and 7 install until their framework tooling ships a 7.1 build. Tool and library authors are urged to port to the new entry points now and to flag missing functions through the [API status tracker](https://github.com/microsoft/TypeScript/issues/64709) while gaps can still be filled before stable. The independent numbers are a reminder that the native compiler now sets the bar, with rival type checkers on Hacker News already [measuring themselves against tsgo 7.1 beta](https://news.ycombinator.com/item?id=50251925).

TypeScript is an open-source programming language developed and maintained by Microsoft. It builds on JavaScript by adding optional static typing, catching errors before code runs and making large codebases easier to build and maintain with confidence. Since version 7.0 its compiler has been written in Go rather than in TypeScript itself, a native port that underpins the speed gains in this release, and it remains widely adopted across the frontend and backend ecosystems, with first-class support in frameworks such as React, Angular, Vue and Node.js.
