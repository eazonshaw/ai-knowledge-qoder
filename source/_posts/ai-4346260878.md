## 正文

Vercel 已正式推出 [v0 API](https://vercel.com/blog/introducing-the-new-v0-api)，让开发者能够以编程方式访问其 AI 应用构建智能体。开发者可以通过 API 发送提示词，让 v0 生成和修改应用程序文件，在 [Vercel Sandbox](https://vercel.com/docs/sandbox) 中运行生成的应用程序，并获得一个可以嵌入自有界面的预览 URL。

该 API 以聊天为单位组织每个应用程序，聊天会维护应用程序的当前状态。开发者可以使用同一个聊天 ID 发送后续消息，让 [v0](https://v0.app/) 继续编辑现有应用程序。该 API 支持同步、异步和流式请求，流式响应会公开智能体的各项操作，例如读取文件、编辑、搜索、执行 Bash 命令和调用工具。

开发者还可以基于现有 GitHub 仓库、ZIP 压缩包或文件集合创建应用程序。应用程序准备就绪后，开发者可以关联一个 Vercel 项目，并通过 API 进行部署。预览环境使用短期令牌，并且可以通过服务器端代理访问，从而避免在浏览器中暴露 [v0 API](https://v0.app/docs/api/v2) 密钥。

该 API 还支持外部工具和设计系统。开发者可以连接 [MCP 服务器](https://en.wikipedia.org/wiki/Model_Context_Protocol)，或者从团队或用户记忆、[skills.sh](http://skills.sh/)或已连接的仓库中加载技能。每个请求最多可以传入三项技能。Vercel 还提供了相关集成，可以通过 MCP、[AI SDK](https://ai-sdk.dev/) 或 Vercel 的 eve 框架，将 v0 作为工具用于其他 AI 智能体。

这使 v0 与 [Lovable](https://lovable.dev/) 和 [Bolt](https://bolt.new/) 等应用构建工具形成了不同的定位，后两者主要提供用于生成应用程序的交互式环境。相比之下，[v0 API](https://vercel.com/blog/introducing-the-new-v0-api) 将应用构建智能体作为基础设施开放，开发者可以从自己的产品、脚本、CI 流水线或其他智能体中调用它。Vercel 的方案还将生成的应用程序直接与其 Sandbox 和部署 API 集成。

社区的讨论主要集中在该 API 对全程可编程应用开发的支持潜力上。AI 领域影响力人士 [ZenithAI](https://x.com/ZenithAiLab/status/2085424422186635674) 如此评价此次发布：

这是迈向全程可编程应用开发工作流的重要一步。

Vercel 开发者 [@EstebanSuarez](https://x.com/EstebanSuarez/status/2085370198819815567) 强调了预期的智能体工作流。他解释说，智能体可以将提示词和设计系统发送给 v0 API，获得 Vercel Sandbox 中的实时预览，对应用程序进行迭代，并在准备就绪后进行部署。他写道：

你的智能体需要一个应用程序。它将提示词连同你的设计系统一起发送给 v0 API，随后会收到一个预览 URL：应用程序已在 Vercel Sandbox 中实时运行。你的智能体会对它进行迭代。准备就绪后，它会进行部署。这就是新的 v0 API。

新的 API 可以通过 v0 SDK 使用，其中 v2 API 的地址为 [https://api.v0.dev/v2。开发者可以创建](https://api.v0.dev/v2%E3%80%82%E5%BC%80%E5%8F%91%E8%80%85%E5%8F%AF%E4%BB%A5%E5%88%9B%E5%BB%BA) API 密钥、安装 SDK，并构建能够发送提示词、流式传输智能体活动、渲染预览和部署生成应用程序的界面。
