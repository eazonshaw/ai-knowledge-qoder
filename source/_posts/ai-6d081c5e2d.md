This week's Java roundup for November 9th, 2026, features news highlighting: Lazy Constants proposed to target for JDK 28; TornadoVM jitLLM 3.0; point releases of Seed4J; second release candidates of Spring AI and Spring Boot; first release candidates of Hibernate ORM and Hibernate Reactive; fourth milestone release of GlassFish; and the second milestone release of Apache TomEE.

#### OpenJDK

JEP 547, [Lazy Constants (Fourth Preview)](https://openjdk.org/jeps/547), has been [elevated](https://mail.openjdk.org/archives/list/jdk-dev@openjdk.org/thread/PMNSAVN3SBA4FM65PMCQY4JVXBVFJNWO/) from **Candidate** to **Proposed to Target** for JDK 28. This JEP proposes a fourth preview, with no changes, after three rounds of preview delivered in the upcoming release of JDK 27 and JDK 26 through JDK 25. Formerly known as *Stable Values* and *Computed Constants*, this feature introduces the concept of *computed constants*, defined as immutable value holders that are initialized at most once. This offers the performance and safety benefits of **`final`** fields, while offering greater flexibility as to the timing of initialization. The name change from *Stable Values* to *Lazy Constants* with the release of JDK 26, better captures the intent of a high-level use case. The review is expected to conclude on Wednesday, November 18, 2026.

#### Spring Framework

The [second release candidate](https://spring.io/blog/2026/11/09/spring-ai-2-1-0-RC2-available-now) of [Spring AI](https://spring.io/projects/spring-ai) 2.1.0 delivers new features such as: a new DecisionModel API, anchored by the **`[DecisionModel](https://docs.spring.io/spring-ai/docs/2.1.0-RC2/api/org/springframework/ai/decision/DecisionModel.html)`** interface, that returns the probability of different outcomes instead of generated text based on yes/no answers, questions about text or a set of fields; and a new **`similaritySearch(float [], [SearchRequest](https://docs.spring.io/spring-ai/docs/2.1.0-RC2/api/org/springframework/ai/vectorstore/SearchRequest.html))`** method, added to the **`[VectorStoreRetriever](https://docs.spring.io/spring-ai/docs/2.1.0-RC2/api/org/springframework/ai/vectorstore/VectorStoreRetriever.html)`** interface to complement the corresponding overloaded methods, to search with a user's embeddings in more vector stores. Further details on this release may be found in the [release notes](https://github.com/spring-projects/spring-ai/releases/tag/v2.1.0-RC2).

The [second release candidate](https://spring.io/blog/2026/11/06/spring-boot-4-2-0-RC2-available-now) of [Spring Boot](https://spring.io/projects/spring-boot) 4.2.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: support for reading the value defined in a **`X-Forwarded-Prefix`** HTTP header in a WebFlux application on Reactor Netty when the **`server.forward-headers-strategy`** property is set to **`native`**; and a database assigned to the **`spring.data.redis.database`** property is now properly applied to master/replica connections if a value is assigned to the **`spring.data.redis.masterreplica.nodes`** property. More details on this release may be found in the [release notes](https://github.com/spring-projects/spring-boot/releases/tag/v4.2.0-RC2) and this [wiki page](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.2.0-RC2-Release-Notes).

The [Spring for Apache Pulsar](https://spring.io/projects/spring-pulsar) team has [announced](https://spring.io/blog/2026/11/10/spring-pulsar-new-home-asf) that the project is moving as a subproject within [Apache Pulsar](https://pulsar.apache.org/) at the Apache Software Foundation to "*foster even deeper integration and collaboration with the broader Pulsar community.*" As stated in the blog post:

> Bringing this integration directly into the Apache Pulsar project allows the community to streamline development, accelerate feature support, and ensure long-term alignment with the evolution of Apache Pulsar.

Spring for Apache Pulsar 2.0.8, released in October 2026, was the final release under the auspices of the Spring ecosystem.

#### GlassFish

The *fourth milestone release* of [GlassFish](https://glassfish.org/) 9.0.0 provides bug fixes, documentation improvements, dependency upgrades and new features such as: implementation of the [Jakarta Persistence 4.0.0-M7](https://jakarta.ee/specifications/persistence/4.0/) specification with [EclipseLink 6.0.0-M1](https://github.com/eclipse-ee4j/eclipselink/releases/tag/6.0.0-M1); a move of the [Sun Theme](https://github.com/eclipse-ee4j/glassfish-woodstock/tree/master/woodstock-webui-jsf-suntheme) module out of the out of the external GlassFish [Woodstock Components](https://github.com/eclipse-ee4j/glassfish-woodstock/blob/master/README.md) repository into its own module in GlassFish so that Sun Theme and the Admin Console can be modified together; and an update to versions 1.2.0-M2 and 2.0.0-M1 of [Eclipse JNoSQL](https://www.jnosql.org/). Further details on this release may be found in the [release notes](https://github.com/eclipse-ee4j/glassfish/releases/tag/9.0.0-M4).

#### TornadoVM

Beehive Lab, makers of TornadoVM, has [released](https://x.com/jitllm/status/2121197742282432654) version 3.0 of [jitLLM](https://github.com/beehive-lab/jitllm/blob/main/README.md), a JVM-native LLM inference and serving engine, delivers notable changes such as: 1.43 times faster startup with GraalVM Native Image; an up to 9.3 times faster prefill phase; and a more efficient reading of model weights by eliminating the copy from the mapped [GGUF](https://huggingface.co/docs/hub/en/gguf) file into a Apple Metal buffer. More details on this release may be found in the [release notes](https://github.com/beehive-lab/jitllm/blob/main/CHANGELOG.md).

#### Hibernate

The [first release candidate](https://in.relation.to/2026/11/12/orm-80-cr1/) of [Hibernate ORM](https://hibernate.org/orm/) 8.0.0 ships with notable changes such as: an implementation of the Jakarta Persistence 4.0.0-M7 and [Jakarta Data 1.1.0-M4](https://jakarta.ee/specifications/data/1.1/) specifications (the latter via [Hibernate Data Repositories](https://hibernate.org/repositories/)); and support for coordination of graph-based flushing that builds a dependency graph for pending entity and collection mutations. Further details on this release may be found in the [what's new](https://docs.hibernate.org/orm/8.0/whats-new/) page.

The *first release candidates* of [Hibernate Reactive](https://hibernate.org/reactive/) 5.1.0 and 5.0.0 provide notable changes such as: the **`EXTENDED`** constant, defined in the Jakarta Persistence **`[PessimisticLockScope](https://jakarta.ee/specifications/persistence/3.2/apidocs/jakarta.persistence/jakarta/persistence/PessimisticLockScope.html)`** enum class, now locks the collection tables as intended to align with the same functionality in Hibernate ORM; and an update to the **`[VertxFactory](https://github.com/hibernate/hibernate-reactive/blob/main/hibernate-reactive-core/src/main/java/org/hibernate/reactive/vertx/VertxFactory.java)`** interface to allow for adding observability without changing the functionality in using the **`[DefaultVertxInstance](https://github.com/hibernate/hibernate-reactive/blob/main/hibernate-reactive-core/src/main/java/org/hibernate/reactive/vertx/internal/DefaultVertxInstance.java)`** class. These versions are compatible with Hibernate ORM 8.0.0.CR1. More details on these releases may be found in the release notes for [version 5.1.0.CR1](https://github.com/hibernate/hibernate-reactive/releases/tag/5.1.0.CR1) and [version 5.0.0.CR1](https://github.com/hibernate/hibernate-reactive/releases/tag/5.0.0.CR1).

#### Apache TomEE

The *second milestone release* of [Apache TomEE](https://tomee.apache.org/) 11.0.0 delivers bug fixes, documentation improvements, dependency upgrades and new features such as: resolutions to 38 CVEs; completion of their implementation of the [Jakarta Authorization 3.0](https://jakarta.ee/specifications/authorization/3.0/) specification; and TomEE Plume, the enterprise version, now ships the modular [EclipseLink JPA artifact](https://central.sonatype.com/artifact/org.eclipse.persistence/org.eclipse.persistence.jpa) instead of the **`eclipselink`** Uber-Jar. #### Seed4J

Versions 2.4.0 and 2.3.0 of [Seed4J](https://seed4j.com/), formerly known as JHipster Lite, deliver bug fixes, dependency upgrades and new features such as: install [Playwrite](https://playwright.dev/) *only* on applications that execute the relevant Playwright component tests; and improved efficiency by creating one global Maven cache that is shared by the Seed4J build and every generated Maven application that replaces a Maven cache for each generated application. More details on these releases may be found in the release notes for [version 2.4.0](https://github.com/seed4j/seed4j/releases/tag/v2.4.0) and [version 2.3.0](https://github.com/seed4j/seed4j/releases/tag/v2.3.0).
