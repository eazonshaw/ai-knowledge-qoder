## 正文

最新发布的 [Android Studio Quail 2](https://android-developers.googleblog.com/2026/06/android-studio-quail-2-stable-features.html) 现已进入稳定版。该版本扩展了 IDE 内 Gemini/AI Agent Mode 的能力，支持多个 AI 对话并行运行，并进一步推进 Google 将 AI 驱动工作流直接融入 Android Studio 的战略。同时，该版本还增强了调试和性能分析能力，并让开发者更容易探索实验性功能。

Google 表示，Quail 2 中的 Agent Mode 已经过全面重新设计，带来了更好的性能、更有效的任务拆解能力，以及更完善的工具支持。其中最值得关注的是，新设计允许开发者同时处理多个 Agent 对话：

> 过去，开发者必须等待 Android Studio Agent 完成任务后，才能在 Agent Mode 中提出另一个问题或启动独立任务，这种瓶颈已经成为过去。现在，你可以无缝进行多任务处理：在一个标签页中启动 UI 重构，在第二个标签页中修复 ProGuard 规则，在第三个标签页中生成文档。

Android Studio 的 Agent Mode 除了支持 Gemini 之外，还支持多个大型语言模型。为了帮助开发者了解哪些模型在特定任务中表现更好，Google 创建了专门针对 Android 开发的基准测试 [Android Bench](https://developer.android.com/bench)。该基准测试会使用一组常见开发任务对模型进行评估，同时将权限、导航、连接等领域的 Android 最佳实践纳入考量。

Android Studio Quail 2 还通过将广受欢迎的开源工具 LeakCanary 集成到 IDE 中，提升了对[内存泄漏检测](https://square.github.io/leakcanary/)的支持：

> 这一集成通过将堆分析任务从资源受限的测试手机转移到性能更强的开发电脑上，改变了调试体验。通过在电脑上运行分析，泄漏追踪速度最高可提升五倍，并且不会产生卡顿，让测试应用能够在设备上保持流畅运行。

一旦检测到泄漏，IDE 就可以帮助开发者快速跳转到负责该问题的具体代码行，使用 Agent Mode 修复问题，或者让模型解释保留引用产生的根本原因。

Google 表示，Agent Mode 集成能够显著帮助开发者的另一个领域，是定位崩溃的根本原因。随着 App Quality Insights（AQI）现在完全集成到 Android Studio 中，IDE 可以自动综合分析堆栈信息、设备数据和源代码，识别问题并提出修复建议。在处理崩溃问题时，Agent 会分析根本原因，提出分步骤的修复方案，并允许开发者在应用必要修改到项目并验证修复效果之前先进行审查。

Android Studio 还让 [Studio Labs](https://developer.android.com/studio/releases#studio-labs) 正式稳定下来。Studio Labs 是一项旨在帮助开发者发现和测试实验性 AI 功能的特性，开发者无需升级 IDE 即可体验这些功能。

最后值得一提的是，[Android Studio Quail 2](https://developer.android.com/studio) 还包含来自 IntelliJ 平台的最新稳定性和性能改进。
