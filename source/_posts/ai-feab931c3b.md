## 正文

这个月，个人助手突然成了 AI 行业最热门的产品类型。

8 月，xAI 先推出 Grokbot。到了 9 月，竞争明显升温：Meta 发布 Muse，把“个人 AI Agent”直接推到台前；几周之内，Muse 又从独立产品进入 AI 眼镜、企业平台和开发者体系。OpenAI 随后推出 Dots，同样强调长期运行、个人上下文和跨应用执行。进入 10 月，Google 和 Microsoft 也接连把自己的产品和操作系统往 Agent 方向推进。

短短几周，Meta、OpenAI、Google、Microsoft、xAI 几乎同时开始争夺同一个位置。

Muse 是这一轮里最显眼的信号之一。Meta 直接称它为“个人 AI Agent”：它有自己的运行环境和浏览器，可以替用户处理邮件、预订、表单和长期任务，并随着使用逐渐了解用户。Muse 发布后，Meta 很快又把它接进眼镜、企业产品和开发者平台。到 10 月，华尔街已经开始把它当成 Meta 下一代 AI 入口来讨论。

OpenAI Dots 走的也是类似方向。每个 Dot 都拥有自己的云端电脑，可以持续围绕用户目标工作，并连接大量外部应用。OpenAI 对它的描述里有一句很关键：Dot 会逐渐知道“什么对你重要”，越来越像用户本人的延伸。

也差不多在这个时间点，YC CEO Garry Tan 在 Startup School 2026 的演讲中提出了一个更激进的判断：“个人 AGI”正在从一个听起来有些激进的说法，变成一条越来越清晰的产品路线。

在 Tan 看来，大家一直在等待 AGI 以某个轰动世界的时刻降临，但它真正出现时，可能根本不像“数据中心里的神”。它可能只是一个终端窗口、一组 Markdown 文件、一个在你睡觉时继续运行的任务，以及一个建立在你个人 Context 之上的 Agent。

他把这种东西称为“个人 AGI”。

Tan 也在演讲中详细拆解了自己的实践：他如何用 22 万页 Markdown 知识库、Skill 文件和开源框架 GBrain，构建出一个“跑在自己基础设施上的 AI 大脑”。

以下是这场演讲的核心观点：

-   个人 AGI 不是每月 20 美元的聊天机器人，而是跑在你自己的基础设施上、从你拥有的记忆里读取、执行你写的流程、并且不断复利增长的资产。
    
-   Markdown 实际上就是代码。如果你能用清晰的英语写指令，你就是程序员，编译器是语言模型  
    
-   GStack 架构真正的点睛之笔，大部分其实就是 Skill 文件加一个 Agent 能驱动的浏览器，几页英文加上一个与世界交互的方式。是 Markdown，不是魔法，肥 Skill，瘦 Harness。
    
-   几百个创始人，每天每个人都在做过去一个人一整年的工作量。这不是未来，这是这一批创业者现在的及格线。如果你不做，你的竞争对手在做，他们会礼貌地吃掉你的午餐，然后谢谢你。
    
-   过去的建议是：挠你自己的痒处，希望它恰好是市场。新版本好得多：挠你自己的痒处，因为挠痒几乎免费。而有些为你一个人做的工具，最终会变成整个公司。当其他人开始求你给他们用的时候，你就知道了。
    

## 被整个时代封杀后，他选择继续构建

网上有人把我称为互联网上“AI 精神病最严重的人之一”。既然如此，我今天的演讲，理所当然应该从历史上遭受抵制最严重的人之一讲起。他的名字叫巴鲁赫·斯宾诺莎。假如你上学时没有选过哲学课，下面这些就是你需要了解的重点。

1929 年，有人给爱因斯坦发电报：“你信上帝吗？”爱因斯坦说：“我相信斯宾诺莎的上帝，他在万物和谐的法律中显现自己，而不是那个关心人类命运和行为的上帝。”最著名的在世科学家，被问到了最大的问题，他指向了斯宾诺莎。

斯宾诺莎是塞法迪犹太社区的成员，1656 年 7 月 27 日，23 岁的他站在犹太会堂里，长老们用最暴力的诅咒将他逐出教门：“愿他白日受诅咒，夜晚受诅咒。愿他躺下受诅咒，起身受诅咒。无人可与他说话，无人可与他交易，无人可进入他四肘之内，无人可读他写的任何东西。”这项禁令，在那个世纪发出的大约 40 项禁令中独一无二，没有悔改条款，从未被解除，技术上至今仍然有效。

实际上，在诅咒之前，社区试图用一年一千荷兰盾收买他，在当时那是笔大钱。他要做的只是偶尔去趟会堂，管住自己的嘴。用创始人的话来说：他们给他发工资，让他停止建造。他说：“不，一万也不干。”他说他想要真理，而不是舒适。就在被逐出教门前不久，一个狂热分子拿刀袭击了他。刀刃划破了他的斗篷，没刺中他。他把那件斗篷留了一辈子，破洞从未修补，他要以此记住思想的代价。

那么，17 世纪最被除名的人接下来做了什么？他白天磨镜片，制造光学仪器，用来让人看得比肉眼更远。他做得太好，欧洲最顶尖的科学家都来找他买。到了晚上，他写一本危险到活着时无法出版的书。44 岁去世时，肺里满是磨镜片吸入的玻璃粉尘，手稿锁在书桌里。他的临终遗言是：用运河驳船把书桌运到阿姆斯特丹的出版商那里。他的遗著手稿，立刻引发全欧洲的关注，启发了启蒙运动中最重要的一批哲学家。

你可能会问，斯宾诺莎和创业有什么关系？这是一个被所有认识的人除名、被花钱收买让他停止、差点因为交付而被杀的人，他的回应是白天造精密工具，晚上写全欧洲最危险的书。独自一人，不需要任何人许可。如果你要创业，你可以好好学学斯宾诺莎。

他给支撑自己走下去的引擎起了个名字：Conatus，意思是你的奋力求存，即每个生命体保持前进、增强行动能力的驱动力。不是你的简历，不是你的头衔，不是你的工作，而是那股奋力求存的劲头本身。这场演讲，讲的就是放大这股劲头的工具。

那他到底说了什么，值得被除名？他的异端邪说大意是：上帝不是宝座上的国王，上帝散布在一切存在之中，“上帝即自然”。四百年后，我们正在对“智能”犯下同样的错误。

## AGI 不会从天而降，它已经藏进了基础设施

所有人都在等待 AGI 作为一个单一事件降临，数据中心里的神、某个公告、某个阈值、某一天天空变色。现在，我要提出一个四百年后的“斯宾诺莎异端”版本：所有人都在仰望天空，可他们等待的东西，其实已经在房间里了。它看起来不像神。它看起来像基础设施，像一个终端窗口，像一组 Markdown 文件，像一个在你睡觉时自动完成的任务。它分散在一切事物之中，而这恰恰是斯宾诺莎告诉你应该寻找它的地方。

AGI 不是作为事件到来的，它是弥散式到来的：作为你的 Agent ，跑在你的上下文里，做你的工作。我称之为“个人 AGI”，不是给所有人同时到来的通用人工智能，而是给你一个人的通用智能。这是很多人的梦想，万尼瓦尔·布什（Vannevar Bush）把它叫做 Memex，一台作为你和你的大脑延伸的机器。

把话说精确，因为“个人 AI”这个词已经被营销部门污染了。我说的不是每个月花 20 美元租的聊天机器人，不是稍微好一点的自动补全，不是只知道你日程表的助理。那只是你租来的订阅，是一个你不拥有的企业 AGI，你关掉标签页它就重置了，它知道的是所有其他人也都知道的东西。当背后的公司转向的时候，你这个所谓的助理会在别人的时间表上接受一场脑叶切除术。

个人 AGI 是另一种东西，是一个跑在你自己的基础设施上的 Agent ，从你拥有的记忆里读取，执行你写的流程，并且不断复利增长。你不拥有的企业 AGI，只有等公司发版才会变好。而你的个人 AGI，每用一天就变好一点，因为它每天都在多了解一点你的生活。一个是消耗品，一个是资产。这个世界上几乎没有人拥有后者，但这个房间里每个人都能在周一之前拥有它。我相信这种智能应该被你拥有，而不是租用。如果你为自己去建造它，2034 年不必像 1984 年。

## 同一个 Claude，为什么有人 2 倍，有人能 100 倍

你可能会问，为什么个人 AGI 偏偏是现在才出现？我认为是因为 Agent 能做的事，这在 Coding Agent 上体现得最明显。

2013 年，我是 YC 的合伙人，晚上写我们内部社交网络 Bookface，我一天大概能产出 14 行有用的代码，如果你了解程序员生产力的文献，这个数字正好是中位数，那已经是我全力以赴的产出了。今年，我全职运营 YC，同样的脑子，同样的工时，外加下午 5 点接孩子放学，而我的产出，大约是 2013 年的 400 倍。

我知道第三排的怀疑论者已经开始质疑这个数字了，那就让我自己先来拆台。你不相信原始代码行数，可以。那就用你能忍受的最病态的冗余惩罚来折算，假设 Agent 写的代码全是臃肿的，假设一半都是 Harness，假设我是在自我吹捧。即便在最严苛的折算下，也是 8 倍。无论你怎么折腾这个数字，它都大得吓人。这不只是编码。如果你正处于职业生涯的起点，那你走运了。这个乘数效应适用于设计、产品管理、增长，适用于你想做的每一个领域，是每一种知识工作的乘数。

而且这不只发生在我身上。在 YC，我们能从投资组合的规模上看到这一点。一年半前的冬季 25 届 batch 里，四分之一的公司的代码库有 95%是 AI 生成的。这些公司现在把 AI Agent 用在了所有事情上，不只是代码。而那一届 batch 正有望成为 YC 历史上增长最快、利润最高的 batch 之一。

我知道相关性和因果性的区别，所以让我谨慎地说：我无法证明 AI 生成的代码和其他一切导致了增长。但我能告诉你的是，我们资助的增长最快的创始人，没有把 AI 当作自动补全来用，而是当作一支劳动力队伍。有 2 倍的人，也有 100 倍的人，用的是同一个 Claude，同样的权重，同样的上下文窗口大小，同样的 API。但杠杆不在权重里，杠杆在于你给了它什么上下文、这些上下文有多相关、以及它是否在正确的步骤被调用。

斯宾诺莎在《伦理学》里写有一个我每周都会想到的定义，他把“喜悦”定义为：你感受到自己行动能力在增长的那种感觉。这就是为什么当一个 Agent 在一个下午完成你一周的工作时，它给人的感觉不是便利，而是喜悦。这不是我在诗意化，这是技术术语。你的行动能力增长了，你的 Conatus 变大了。他还定义了“悲伤”，即你的行动能力在减弱的感受，具体来说：你影响世界的能力在退缩，你觉得自己在安静地辞职。

所以，这是你未来十年的方程：一个前沿模型（租来的、商品、每个季度都在降价），加上你的上下文（你拥有的、独一无二的），再加上一个把它们连接起来的 harness（OpenClaw、Hermes Agent、Claude Code 或者 Codex）。

把它们加起来，你就得到了一个行动方式像超级加速版你的 Agent。模型质量是租的，但你的大脑是你自己的。麦克卢汉说技术是人的延伸，乔布斯说电脑是大脑的自行车。如果你拥有了我描述的这套东西，那你拥有的是一辆自动驾驶的火箭。

![](/ai-knowledge-qoder/_imgs/8cfd5c68fb427863.png)

保罗·格雷厄姆（YC 联创）教会了这栋楼里每一位创始人两件事：“做人们想要的东西。”、“做不扩展的事情。”这两条至今仍然统治一切，新的是第二条的乘数变了，Agent 就是现在一个创始人以规模做不扩展之事的方式。建议没变，但所有创业公司和你所能做的事情的物理规律变了。

## 100 万 Token 还不够，真正的问题是该打开哪三本书

斯宾诺莎磨镜片，磨的是让人看到超越肉眼极限的仪器。接下来我想花 15 分钟向你们展示，为心智磨镜片是什么样子的。这是我实际运行我人生的信条，每个概念都能迁移到你使用的任何技术栈上。

你我作为人类，脑子里一次大约能装七件事，这来自著名的认知心理学论文，也是为什么本地电话号码是七位数，为什么你会忘记购物清单上的第八项，那就是一个人的全部工作记忆（working memory）。而人类建造的每一个机构、每一张检查清单、每一张组织架构图、每一个文件柜、每一次站会，都是对这个限制的义肢。

但一个 AI Agent，能容纳一百万 token，那大约是上千页纸，三本《哈利·波特》同时摊开在它脑子里，而且它能在任何一本里找到一根针，并在几秒内跨三本综合出答案。三本《哈利·波特》对比七位数字，你可以说这还不是完全的 AGI，但这已经是一个不同的运行体制。而地球上几乎所有人，仍然在用为七位数字大脑设计的组织架构图和做事方式运行他们的人生。

把这个数字往另一个方向推。一千页很多，但也很少。你的人生不是三本书，你的人生是一座图书馆：你发过的每一封邮件、每一次会议、每一个决定以及背后的每一个理由、和你认识的每一个人的每一次对话。决定你的 Agent 是天才还是金鱼的问题在于，谁来决定哪三本书摊开在桌面上，这就是大脑的意义。这也是 GBrain 想要成为的东西，图书馆加图书管理员。

我一直在公开建造 GBrain。我的个人 OpenClaw 有一个 Karpathy 风格的知识 wiki，大约有 22 万个 markdown 页面，我人生 25 年的日记化记录，每一封邮件、每一次会议、我的笔记、我的照片、我的草稿、我犯过的错，大部分由 Agent 编译、策展和搜索，但我从不重复问我已经回答过的问题，系统中的亲历经验才是关键。一位创始人给我发邮件谈危机，我还没读完邮件，我的 Agent 就已经拉出了我和那位创始人的所有过往对话、三家撞过同一堵墙的投资组合公司、以及对他们真正有效的做法。当我的 Agent 做任何事时，它都是在知道我已知一切的前提下做的，这就是助手和同事之间的区别。

我的一天是这样的：睡觉时，我的 Agent 处理我的收件箱，它知道哪些邮件来自陷入困境的创始人，哪些来自想卖我东西的人，哪些来自我从未真正退订的 17 个邮件列表。重要的邮件会被加上从图书馆调取的上下文进行分诊：这个人是谁、我和他们的全部历史、他们真正在问的是什么、以及这对我会意味着什么。我醒来时看到的是简报，不是一堆邮件。每次会议前，一份准备文档：我要见谁、我们上次说了什么、自那以后发生了什么变化、我应该问什么。午夜时我好奇的研究，到早上已经完成了。当世界上发生什么有趣的事，我的 Agent 通常在我喝咖啡之前就已经读完了，对照过我在乎的东西，然后归档了。

在这套图书馆架构之上，跑着我的 Agent 编码框架 GStack——现在有 12.3 万颗星，已经排进 GitHub 开源项目历史前 100 名。

## Markdown 正在变成新代码，所有人都会成为 Agent 管理者

这整套架构真正的点睛之笔，大部分其实就是 Skill 文件加一个 Agent 能驱动的浏览器，几页英文加上一个与世界交互的方式。是 Markdown，不是魔法，肥 Skill，瘦 Harness。

这是一个真实的 Skill 文件，我想让你看到它有多不神奇。上面写着：“当 CircleBack 的会议录音进来，用说话人标签做转写；提取里面做出的承诺、谁做的、截止日期是什么；把提到的每个人去图书馆里交叉核对，链接到他们的页面；摘要归档到这里，完整转录放到那里；如果任何内容和我们已经相信的事实矛盾，标记出来，不要覆盖。”

![](/ai-knowledge-qoder/_imgs/e1acf101930a6581.png)

一页英文，这就是一个 Skill。一个聪明的实习生，其实任何一个识字的人都能照着执行。检验标准是：如果聪明的实习生能照做， Agent 就能跑。这意味着一件挺深刻的事，Markdown 实际上就是代码。如果你能用清晰的英文写指令，你就是程序员，编译器是语言模型。

所以这不再只是工程师的事了。在 YC，我们的媒体团队、活动人员、财务团队，那些一辈子没打开过终端的人，都在构建 Skill 文件和定时任务。我们财务团队有个人，把她手头大概一百个 Excel 工作簿，用内部 Agent 整合成了一个应用。她不是程序员，她是一个 Agent 的管理者。现在，每个人都即将成为这样的人。

计算只发生在潜空间和确定性空间里，把这两者搞混，是 Agent 失败的根源。一部分计算属于潜在空间——品味、判断力、从模糊请求里读出人类真正想要什么。这部分活在模型里，你用 Markdown 文件去引导它。另一部分计算属于确定性空间——算术、SQL 查询、比如你今天要参加哪些分会场的座位表。所有这些都需要存在 SQL 数据库里，供 Markdown 文件调用。想清楚这件事，能让你少走很多弯路。

让 Agent 或真人安排五个人围坐一桌，很简单，在潜空间里就能完成。但让它给体育馆里 6000 人排定制日程，你的潜空间 Agent 就必须写代码来跟踪这一切。你们在这次大会上的体验，恰恰就是 Markdown 文件以这种方式调用代码的结果。没有代码，这事根本做不成。模型失败的地方，正是我们人类失败的地方。解法是让模型像人类一样计算：潜空间和确定性空间并存，Markdown 文件调用数据库和脚本。听起来简单，但一切真正运转的东西都建立在这个原理之上。

再举个例子，五天前，我决定这场演讲需要提到斯宾诺莎。于是我的 Agent 去搜罗了三本关于他的最佳传记——Nadler、Goldstein 和 Stewart 写的，总共大约 1500 页。它读完了全部三本，为我构建了一份综合材料：一份按时间顺序排列的生平年表，包括三位传记作者在所有存在分歧的地方的对照，以及带有章节引用的最佳原话摘录。而且因为它知道我需要什么，它还列出了他一生中最适合讲述的十个时刻，按讲述效果排序，附带了表演提示。

那把刀的攻击、那次贿赂，二十分钟前开场时你们可能感到震撼的每一个节拍，都来自那次过夜运行。1500 页变成了一篇可以直接上台的故事，而我可以编辑它。我管这叫“汇编 Skill”，我每天都在用。这是一个个人 Skill，是深度研究的超级加强版，比任何企业级 AI 产品给你的东西都要深得多。

你们正在看的这场演讲的主干，就是被这套东西激发出来的。如果你们想知道我的大脑到底是从哪里开始的，不是那 22 万页。是一个文件夹，是几个关于我正在合作的公司和我一直在发邮件的人的 Markdown 文件。而这个图书馆和其他任何东西变大的方式一样，每天一点点，复利增长，由 Agent 负责归档。

## 一个 Skill 文件就是一个员工

没有人会先建仓库，先搭一层架子。当你和一个 Agent 坐下来时，你不是在写代码，你是在管理一支由 Markdown 组成的劳动力队伍。一个 Skill 文件就是一个员工，它有一项能力、一份工作，写得足够清楚，让一个新人也能执行。一个解析器（resolver）就是一张组织架构图。任务进来，它决定哪个 Markdown 文件或者哪个人，来处理它。这意味着，在你注册任何公司之前，在你找到联合创始人或设计 Logo 之前，你已经可以运营一个由你和你的 Agent 组成的组织。你是“你公司”的创始人和整个管理层，手下的员工数量由你决定。

![](/ai-knowledge-qoder/_imgs/8385bafe227ed8f8.png)

这套模式已经催生了打破旧数学的公司。我们 2024 年夏季批次孵化的 Emergent，从公开发布到九位数营收只用了八个月。他们年化收入跨过 1500 万美元时，团队只有 15 个人。冬季批次的 Retail，年化收入 6000 万美元，大约 40 人。这种人均产出在以前不存在，软件行业没有过，石油行业没有过，铁路行业也没有过。这些不是怪物，它们是第一批原生建立在“新物理学”之上的公司，而每一家都始于像我刚才描述的那样的一两个人。

想象一下我们在 Dogpatch 的孵化室，几百个创始人，每天每个人都在做过去一个人一整年的工作量。这不是未来，这是这一批创业者现在的及格线。如果你不做，你的竞争对手在做，他们会礼貌地吃掉你的午餐，然后谢谢你。

这也改变了软件本身的意义，软件不再那么珍贵了。你可以花一个周末，为一个人构建恰好需要的工具。过去的建议是：挠你自己的痒处，希望它恰好是市场。新版本好得多：挠你自己的痒处，因为挠痒几乎免费。而有些为你一个人做的工具，最终会变成整个公司。当其他人开始求你给他们用的时候，你就知道了。

还有一句诚实的提醒，一个没人打理的大脑，就是带了个好搜索引擎的垃圾场。检索会把一条过时的信息以百分之百的自信摆到你面前，一个糟糕的 Skill 文件，会把一个糟糕的流程永远编码下去。所以最底层的原语是记忆加上卫生：每个事实都要有出处，新信息和旧信息冲突时要跑矛盾检查，还要有一个真正的图书管理员，他的实际工作就是修剪。把大脑当生产基础设施对待，它会复利增长；把它当垃圾场对待，你会得到一个非常自信、但错得让人无法追踪的 Agent。

## 五步上手个人 AGI

接下来我们讲点实操。

第一步：今晚就选一个 Harness，在你自己的机器上跑一个 gent。我自己用的是 OpenClaw 和 Hermes Agent，搭配 GBrain。托管版本在 gbrain.io，免费，GBrain 本身也是免费开源的。我总是推荐法拉利，但说实话，本田也挺好。Codex、Claude Code，随便哪个，任何一款都能完成这件事的 99%。而且不开法拉利的好处是，你不用半路停下来修车。概念才是关键，不是某个特定的仓库或产品。智能就在那里，有很多条路通向它。

第二步：这个周末开始建你的图书馆。不是宏大的档案馆，就是一个 markdown 文件的文件夹。导出你的笔记，能导出邮件就导出邮件。为你正在做的每个项目、合作的每个人写一页纸。在那页上写下你真正知道的东西：你们在共同建造什么、他们在乎什么、你欠他们什么、他们上次说了什么。这些是地球上任何模型都没有的东西，因为它们只存在于你脑子里。而你的脑子，只能装七件事。第一次，一个 agent 用你的上下文而不是互联网的上下文回答问题时，你会感到那个“咔哒”一声，然后就回不去了。你们每个人手里都握着五到十年、散落在各个收件箱里的个人历史，那是你的护城河，就躺在那儿，未被索引，毫无作为。你和这整个架构之间，大概只隔着 24 小时。

第三步：写你的第一个 Skill 文件。选你每周最讨厌的那件事，可能是报销单、会议纪要、每周状态更新、竞品调研。用大白话把它解释给你的 Agent，就像你给一个聪明朋友讲他第一天上班要干什么那样。然后让它犯错。如果错了，纠正它。每一条规则、每一个例外、每一个“哦对了还有……”都写进去，它会修正。那一页纸，从此就是一个员工，运行它。

第四步：把它变成一个周期性任务，也许就是第三步创建的那个任务。每天早上 7 点做这个，每周五总结那个。第一次你醒来发现工作在你睡觉时已经完成了，你脑子里的某个东西会永久性地改变。从那天起，“一天”不再是你的工作单位，它变成了你能想象的东西，由你的目标和你想为这个世界创造的东西驱动。

第五步：永远不要做一次性工作。大多数人跑一次操作，然后就把上下文扔掉，关掉窗口，就完了，别这样。每项任务结束时，让 Sgent 把它自己“Skill 化（Skillify）”。Skillify 是 GBrain 里的一个特殊 Skill，你可以指向那个仓库说：提取 Skillify，学会它。把它变成一个你可以永远复用、反复使用的 Markdown 文件。我在 YC 常这么说：如果你一件事要问第二遍，你就失败了。捕捉所学的人，每一天都在变得更聪明。而每天早上醒来就失忆的人，纯粹是浪费时间。而且，如果你无法把模型的能力转化成真正的记忆，模型再好也没用。

做完这五件事，我可以告诉你接下来 90 天会发生什么。第一周，它就是个玩具。图书馆很薄，Skill 很笨拙，你修修补补的时间比省下的时间还多。第四周，飞轮开始转动。Agent 开始用你的上下文回答问题了，早上的任务开始产出你真正会读的东西，你写了第三个、第四个 Skill，因为前两个真的管用。第 12 周，你有了一个在你问完之前就回答的图书馆。十几个 Skill 文件在跑你过去最讨厌的那部分每周工作，还有一两个工具，别人一直在求着借用，在这个房间里，这就叫创业公司。这条曲线和你见过的任何复利曲线一样：平、平、平，然后陡峭上升。大多数尝试的人会在第二周放弃，但坚持到第 12 周的人感觉自己像在作弊。

## 你的经验，最后归谁所有？

现在，我得告诉你们不好玩的部分了，因为我刚才教的一切都是双刃剑。我之前讲过斯宾诺莎对悲伤的定义：你的行动能力减弱的感觉，这会变得政治化。在这里，Skill 文件不是文档，它是你认知的一部分。你做事的方式，从你脑子里提取出来，写下来，可执行。你教给 Agent 的每一个 Skill，都是你被外化的部分。而同一个文件，取决于一个变量，会通向两个截然不同的未来，取决于谁控制它。

举一个虚构的例子。有个支持工程师，叫她 Maya。两年里，她教会了她的 Agent 40 个 Skill：凌晨两点怎么给 P0 事故分级，怎么安抚一个即将流失的客户，怎么写一份真正能防止下一次事故的事后复盘。四十个文件，那是她的判断力。她花两年时间构建的东西，就躺在磁盘上。

版本一：这些文件放在 Maya 自己的仓库里。她换工作，它们跟她走。新公司入职第一天，她就能调用多年积累的判断力。她每工作一年，就复利一年，这就是所有权。如果她想创业，这就是她的专长。事实上她可以，如今整个初创公司都可以是几个 Markdown 文件。

版本二：这些文件放在公司的仓库里，受公司 IT 政策管辖。Maya 离职时什么都带不走。公司继续用她的判断力运转，四十个文件永远执行下去，提交历史里甚至没有她的名字。她不是拥有了一段职业生涯，她是被提取了一次。同样的文件，同样的 Maya，只差一个变量。

所以这是我的信条，我希望你们明天能复述出来：拥有你自己的 Skill 文件，否则你的工作就会变成一份 Skill 文件。这种事以前发生过，工匠拥有自己的工具，那是他们自由的根基。工厂打破了这一点：织布机归磨坊主所有。知识工作者曾经以为我们是安全的，因为我们的工具住在脑子里，没人能没收。Skill 文件终结了这一切，历史上第一次，你的认知可以被提取、存储、版本化、被占有。唯一的问题是：被谁占有。

还记得那一千荷兰盾吗？那个 offer 从来没有消失过，它只是换了身行头重新出现。每一个让你觉得“我的判断力在别人的代码仓库里复利增长”的舒适安排，本质上都是一年一千荷兰盾，让你按时出现、保持安静、别再搞自己的东西。这就是为什么你应该去创业，因为只有这样才能真正让那些 Skill 文件为你所用。

斯宾诺莎面对的是升级版的同一份合同。1673 年，海德堡大学向这位被诅咒的异端抛出了橄榄枝：教授席位、合法身份、学术讲席，还有那句著名的附加条款：“可以自由地进行哲学思考，只要不扰乱既定的宗教。”斯宾诺莎的回答是：“我不知道这种哲学思考自由的边界在哪里。”他读完了服务条款，然后拒绝了这次收购。

他用一个词来形容自己守护的东西：“under your own power”，在自己力量之下，而不是在别人的力量之下，你的行动力无论如何都存在。1673 年和 2026 年的政治问题是一样的：谁来指挥它？个人 AGI 的本质，就是掌控自己的认知能力并保护自己。这场演讲的全部论点可以浓缩成一句话：个人 AGI，就是让你在 Agent 时代依然活在自己力量之下的方式。 所以从第一天起，就把你的大脑和 Skill 放进你自己控制的仓库里，在任何平台、任何收购方对它产生想法之前。

斯宾诺莎去世后，人们清点他的房间：两条裤子、七件衬衫、一台透镜车床、160 本书，还有被锁在书桌里的《伦理学》。他几乎一无所有，但从来没有人控制过他的 Skill 文件。那张书桌的抽屉就是他的仓库。像他守护自己的那样，守护你的。

## 模型越强，Context 越值钱：个人 AGI 的真正护城河

我站在这儿都能听见你们心里的反驳，那就直接来吧。

第一个反对意见：模型进化太快了，你这套“套件”很快就会过时，等下一个版本发布就行了。 这是"苦涩教训"的忠实信徒们，我很爱他们。但注意每次模型发布时实际发生的事：模型越好，差异化就越往上下文迁移。当所有人的引擎都是一千马力时，比赛就赢在驾驶员和地图上。权重是大家的，但你的库是你自己的。一个更好的模型只会让你的库更值钱，因为更聪明的读者能从同样的书里读出更多东西。我和这栋楼里的任何人一样为实验室们加油，但他们每发布一个版本，都是在给我已经拥有的劳动力做一次免费升级，而这个劳动力，我希望你也拥有。

第二个反对意见：这不就是 RAG 吗？当然，Postgres 也不过是 B 树而已。检索是原语，不是产品。难的是周围的一切：一开始该写下什么？如何被丰富和链接？什么该提升为热记忆，什么该归档为冷参考？当两个事实冲突时，谁来仲裁？检索很容易，值得被检索才是产品。

第三个反对意见，也是最值得尊重的一个：你把整个人生放进一个系统：邮件、会议、孩子的日程，泄露了怎么办？我的答案和整场演讲的答案一样：正因如此，它才必须是你的。 我的大脑跑在我自己的基础设施上，在我自己的仓库里，在我自己的钥匙下。而对比一下默认选项是，你的生活早已散落在十朵云上，那些云属于利益与你无关的公司，除了你谁都能搜索。不是我整合上下文才创造了风险，是我接管了它，监护权就是安全模型。如果你不信任自己持钥匙，我保证答案不是去更信任别人的服务条款。

为什么我把这一切开源？套件、大脑架构、Skill、整个个人操作系统。人们问这个问题，因为他们觉得肯定有猫腻。答案是：因为我可以。但其实真正的问题是，为什么每个人都应该。答案是：强者的工具，应该被赠予。

每个时代都有一种私有的杠杆技术，强者拥有、其他人没有的东西。很长一段时间是识字能力，然后是资本。现在，就是眼前这个东西：这套架构、这个库、这支由 Markdown 组成的劳动力。拥有它的人，正在以一种别人无法企及的规模悄悄运转，而差距每个月都在拉大。这正是这次大会的全部意义：赋予你自己动手构建的能力。当某种强大的东西保持私有，你得到的是一个祭司阶层；当它被赠予出去，你得到的是一场文艺复兴。

我知道自己想生活在哪个世界，所以我要做自己真正相信的事。我把这当作我的信条：说别人不愿说的话，资助别人不愿资助的人，建造别人不愿建造的建筑，写下来并赠予别人不愿赠予的代码，离开别人不愿离开的机构。

当你公开构建时，你得知道接下来会发生什么。斯宾诺莎的故事还有最后一章：1676 年 11 月，欧洲最耀眼的头脑莱布尼茨，带着一台计算器，专程到海牙，在一个阁楼里和全欧洲最被憎恨的人待了三天，然后他用接下来的 40 年对此撒谎。公开场合：只是路过拜访了几小时。私底下：他的笔记里塞满了对斯宾诺莎的痴迷评论。我每周都在经历一个小规模版本：我说“AI 现在写了我大部分代码”，午饭前嘲讽就来了。然后我看看那些嘲讽最大声的人实际在发布什么——全是 AI Agent，嘲讽只是采用曲线的自我介绍。

我想展示这套架构指向真正重要之物时的样子。我有个朋友，他的儿子患有一种罕见的癫痫。没有实验室、没有经费、没有许可，他就是直接去做了。他建了一个包含 8 万份 Markdown 文件的仓库，为一个小男孩打造了一个大脑，把自己推到人类对这个病症认知的绝对边缘。每一次专家问诊、每一篇论文、每一次发作记录、每一种药物相互作用，全部索引、交叉链接，随时准备好。当新医生提出一个想法，他几分钟内就能知道这个方案是否已经试过。一个父亲、一台笔记本、一座图书馆，这就是个人 AGI。不是基准测试，不是演示。没有人会来为他构建这个东西，所以他构建了。同样，也没有人会来为你构建你的。

你被告知需要的一切，团队、资金、许可、资历，都是因为一个人只能同时记住七件事、一天工作 16 小时这个事实的变通方案，这个事实过期了。你可以飞了，不是比喻，是机械意义上的。每一个你曾想“我要是有这个人该多好”的问题，现在可以了。每一个大到读不完的档案，每一个乱到理不清的数据集，每一片你被告知不要煮沸的海洋，我们现在可以煮沸海洋了。
