#### Spring Boot

[Spring Boot](https://spring.io/projects/spring-boot) 4.2.0 的[首个候选版本](https://spring.io/blog/2026/10/23/spring-boot-4-2-0-RC1-available-now)（RC）带来了 Bug 修复、文档改进、依赖项升级以及以下新功能：迁移至 [Ubuntu Resolute 构建器](https://discourse.ubuntu.com/t/ubuntu-26-04-resolute-raccoon-lts-released/80833)以取代 [Noble Java Tiny 构建器](https://github.com/paketo-buildpacks/builder-noble-java-tiny/blob/main/README.md)；通过直接查找嵌套 JAR 文件中的类和资源来提升 Uber-Jar 的性能。要了解有关该版本的更多详细信息，请参阅[发布说明](https://github.com/spring-projects/spring-boot/releases/tag/v4.2.0-RC1)和该[维基页面](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.2.0-RC1-Release-Notes)。

#### Spring Framework

[Spring Framework](https://spring.io/projects/spring-framework) 7.1.0 的首个候选版本（RC）带来了 Bug 修复、依赖项升级以及以下新功能：改进了 [DataAccessUtils](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/dao/support/DataAccessUtils.html) 和 [LinkedCaseInsensitiveMap](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/util/LinkedCaseInsensitiveMap.html) 类中的空值处理；在 [RetryListener](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/core/retry/RetryListener.html) 接口中定义了新的重载方法 onRetrySuccess() 和 onRetryFailure()，在参数列表中添加了 一个 [RetryState](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/core/retry/RetryState.html) 类的实例，以便监听器在失败时能够直接访问重试状态。要了解有关该版本的更多详细信息（包括移除已弃用的 API），请参阅[发布说明](https://github.com/spring-projects/spring-framework/releases/tag/v7.1.0-RC1)。

#### Spring Data

[Spring Data](https://spring.io/projects/spring-data) 2026.1.0 的[首个候选版本](https://spring.io/blog/2026/10/22/spring-data-2026-1-0-RC1-released)（RC1）带来了 Bug 修复、依赖项升级、所有子项目的 RC1 更新，以及 [Spring Data Redis](https://spring.io/projects/spring-data-redis) 中一项值得注意的新功能：如果某个 Bean 实现了 [SubscriptionListener](https://docs.spring.io/spring-data/redis/reference/4.2/api/java/org/springframework/data/redis/connection/SubscriptionListener.html) 接口，那么该功能现在会转发与带注解的监听器方法相关的订阅通知。

#### Spring Cloud

[Spring Cloud](https://spring.io/projects/spring-cloud) 2026.0.0（代号为 Paddington）的[首个候选版本](https://spring.io/blog/2026/10/23/spring-cloud-2026-0-0-RC1-has-been-released)（RC1）带来了依赖项升级、所有子项目的 RC1 更新，以及一项值得注意的变更：[Spring Cloud Bus](https://spring.io/projects/spring-cloud-bus) 不再作为独立的项目存在，而是已经并入 [Spring Cloud Stream](https://spring.io/projects/spring-cloud-stream)。该版本基于 Spring Boot 4.2.0-RC1 构建。要了解有关该版本的更多详细信息，请参阅[发布说明](https://github.com/spring-cloud/spring-cloud-release/releases/tag/v2026.0.0-RC1)。

#### Spring Security

[Spring Security](https://spring.io/projects/spring-security) 7.2.0 的[首个候选版本](https://spring.io/blog/2026/10/23/spring-security-7)（RC）带来了 Bug 修复、依赖项升级以及两项新功能：由于 Spring Framework [HttpMethod](https://docs.spring.io/spring-framework/docs/7.0.9-SNAPSHOT/javadoc-api/org/springframework/http/HttpMethod.html) 类中定义的 valueOf() 方法现在已经对大小写进行了规范化处理，所以 [StrictServerWebExchangeFirewall](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/web/server/firewall/StrictServerWebExchangeFirewall.html) 类的实例不再将大小写不规范的 HTTP 方法视为独立值； 此外，[RestClientOpaqueTokenIntrospector](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/oauth2/server/resource/introspection/RestClientOpaqueTokenIntrospector.html) 和 [SpringOpaqueTokenIntrospector](https://docs.spring.io/spring-security/reference/7.2/api/java/org/springframework/security/oauth2/server/resource/introspection/SpringOpaqueTokenIntrospector.html) 类现在将 Content-Type 头设置为 application/x-www-form-urlencoded。要了解有关该版本的更多详细信息，请参阅[发布说明](https://github.com/spring-projects/spring-security/releases/tag/7.2.0-RC1)和[新功能介绍页面](https://docs.spring.io/spring-security/reference/7.2/whats-new.html)。

#### Spring for GraphQL
