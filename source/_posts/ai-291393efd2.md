## 正文

在经历诸多争议、近期凭 Muse“翻红”后，10 月 12 日，Meta 发布新一代 Muse Wonder 系列，包括 Muse Wonder 和 Muse Wonder Full 两个模型。Meta 将其称为目前公司能力最强的模型，并明确把产品目标指向“个人和专业 Agent”。

“一夜之间，竞争格局从双强对决演变为三方角逐。Meta 发布了 Fable 级模型。”有网友给出了超高评价。

与此前更强调推理不同，Muse Wonder 的核心能力被概括为两个新的关键词：主动记忆和主动专注，前者负责跨对话记住用户的重要信息，后者负责让 Agent 在长时间任务里持续推进目标、绕过障碍并根据新信息调整行动。

Muse Wonder 已通过 Meta Model API 和 Muse Code 开放，价格为每百万输入 Token 4 美元、缓存输入 0.2 美元、输出 20 美元；Wonder Full 则暂时没有单独 API 定价，只包含在 Muse Code 的 Power Usage 和 Maximum Usage 订阅中，后者分别为每月 50 美元和 200 美元。

之后，Muse Wonder 还将逐步进入 Muse 产品，首先向订阅用户推出并承担 Artifact 生成以及需要更高智能水平的复杂任务。Meta 称，未来还计划基于 Wonder 训练更多专用模型。

这也是 Meta 过去 14 个月重建 AI 技术栈后的又一次重要模型升级。Meta 表示，Muse Wonder 延续了此前 Muse Spark 确立的 Scaling 路线，从预训练和强化学习两个方向继续扩大模型能力，并在千兆瓦级 Prometheus 数据中心完成训练。

“我对 Meta 有很多不满，但越多公司跻身前沿领域越好。”有网友说道。

就在 Muse Wonder 发布前一天，Alexandr Wang 还在 David Senra 的播客里从产品侧详细披露了 Muse 背后的故事：它最初受到 OpenClaw 启发，1 至 2 周做出第一个原型，从原型到正式发布用了 7 个月，整个团队不到 200 人。

为了决定模型什么时候能够真正面对消费者，团队列出了一张超过 100 项能力的清单，为其中每一项设定发布门槛，直到第一次出现“全部变绿”的模型 Checkpoint。这背后其实也是 Muse Wonder 的训练理念。

Wang 对这套路线的判断是，个人 Agent 可能成为某种“终极消费产品”。对 Meta 来说，这场竞争最重要的筹码，是它每天触达的约 35 亿用户，以及 Instagram、WhatsApp、Facebook 长期积累的个人关系和消费场景。

可以看出，当下 Meta，在模型上，Meta 正在把主动长期记忆和长程执行直接写进基础能力；产品上，Muse 在走向真正可以替用户办事的个人 Agent；而这两者都服务于 Meta 的 AI 理念：一种以“个人超级智能”为核心、试图持续放大普通人主体能动性的 AI 路线。

## 新模型带 Meta 重回 AI 前沿？

先看新模型。Muse Wonder 最明显的一项变化，是 Meta 开始把“记忆”单独定义为 Agent 的核心能力。Meta 将这一机制称为主动记忆。它并不只是把历史对话塞进更长的上下文，而是要求模型跨对话保存用户相关的重要信息，并在后续任务中主动判断哪些旧信息值得重新调用。

从模型规格来看，Muse Wonder 和 Muse Wonder Full 在推理阶段支持最高 100 万 Token 上下文，输入模态包括文本、图像、视频和音频，输出目前仍以文本为主。Meta 还专门设计了 MemoryBench，测试模型能否在 6.4 万至 10 万 Token 的复杂多轮对话中找回关键信息，同时处理干扰信息以及后续对原信息的更新和冲突。

在这一内部测试中，Muse Wonder 得分为 85.6，Muse Wonder Full 为 85.5，高于 Meta 报告中的 GPT-6 Astra 81.4、Claude Opus 5.5 的 81.5 和 Claude Fable 5.1 的 79.0。

![](/ai-knowledge-qoder/_imgs/00310d97af1d7db5.png)

主动专注解决的则是另一个 Agent 难题：能不能把一件事情一直做下去。Meta 对其的定义是，当任务遇到障碍时，模型能够继续尝试其他方案，在新信息出现后调整计划；需要额外信息时主动向用户澄清，而在采取重要行动之前则先请求用户确认。

Meta 使用 FocusBench 测试这一能力，并用 SWE-Marathon 检验模型在超长软件工程项目中的持续执行能力。

![](/ai-knowledge-qoder/_imgs/2d9b0f2ed636a7b9.png)

这两个能力放在一起，实际上描绘出 Meta 对下一代个人 Agent 的基本判断：Agent 应该长期了解一个人，并且能够围绕他的目标连续工作。

Coding 是 Meta 此次特别强调的一项能力。相比单轮代码生成，真实软件开发同时需要长期记住需求、跨文件修改代码，并不断经历“修改—测试—失败—再次修改”的循环，因此本身就是对 Memory 和 Focus 的综合测试。

Meta 表示，Muse Wonder 和 Wonder Full 专门接受了更多长时间运行任务的训练，希望模型能够在大型软件项目中保持连续进展。从 Meta 公布的评测来看，Muse Wonder Full 在部分长程 Coding Benchmark 上表现突出。

在 DeepSWE v1.1 上，Muse Wonder Full 得到 79.0，Muse Wonder 为 78.8；作为对比，Meta 列出的 GPT-6 Astra 为 74.1、Claude Opus 5.5 为 74.2、Claude Fable 5.1 为 67.4。

![](/ai-knowledge-qoder/_imgs/19ac6da97ad83f05.png)

更明显的差距出现在 SWE-Marathon。这项测试专门针对超长软件工程任务，Muse Wonder Full 得到 57.5，Muse Wonder 为 53.1，高于 Claude Opus 5.5 的 46.3、Claude Fable 5.1 的 45.6 和 GPT-6 Astra 的 42.5。

不过，Muse Wonder 并没有在所有 Coding Benchmark 上领先。比如 ProgramBench 中，Wonder Full 得到 59.0，而 Claude Opus 5.5 达到 70.5。

值得注意的是，各项数字也并非全部来自完全统一的测试环境。Meta 在 Model Card 中说明，部分内部 Coding 对比使用相同 Harness，但一些外部结果沿用了不同模型提供商或评测机构各自使用的 Agent 产品和 Harness。例如 SWE-Marathon 中，GPT-6 Astra 使用 Codex，Claude Fable 5.1 使用 Claude Code，因此这些结果并不属于严格意义上的同 Harness 对照实验。

Muse Wonder 的另一条产品路线，是从通用聊天继续向专业工作渗透。

Meta 针对法律、金融、医疗、商业工作流和电脑操作都进行了单独评测。以法律 Agent Benchmark Harvey LAB-AA 为例，Muse Wonder Full 得分 13.1，Muse Wonder 为 10.0，高于 Meta 报告中的 GPT-6 Astra 、Claude Fable 5.1、Claude Opus 5.5 模型。其他领域，模型得分各有高低。

Meta 首次建立了一项内部综合指标 Personal Superintelligence Index（PSI），把 Agents' Last Exam、AutomationBench-AA、FocusBench、JobBench、GDP.pdf、VBT 和 DRACO 等 7 类个人与知识工作任务合并评估。按 Meta 自己的测试，Muse Wonder Full 的 PSI 为 59.1，Muse Wonder 为 54.3；GPT-6 Astra 为 54.5，Claude Opus 5.5 为 55.2，Claude Fable 5.1 为 49.9。

随着 Agent 开始接触消息、日历、私人文件甚至能够代表用户采取真实动作，Muse Wonder 的安全评估也比普通聊天模型更重。网友的一些讨论，直接触发了 Meta 长期积累的信任问题。

有网友直言，Muse 所要求的信任水平与 Meta 过去的隐私声誉之间存在明显冲突。一些用户认为，一个需要持续积累个人记忆、处理邮件、日历和文件的 Agent，本质上要求用户把比传统社交平台更多、更敏感的信息交给模型提供商。

不过，Meta 就介绍了安全相关的问题。其表示，Muse Wonder Full 在未经安全缓解的情况下，不能排除其化学和生物能力达到公司“高风险”阈值的可能性。因此 Meta 对模型采用了安全后训练和系统级分类器等额外限制。

Meta 也明确建议，当 Muse Wonder 被部署到能够产生现实后果的 Agent 场景时，应针对不可逆操作加入人工确认。公司同时承认，目前模型在多步推理的新颖场景中仍可能出错，3D 等精确视觉与空间推理仍然属于已知弱项，模型表现也会受到量化、服务配置、Prompt、工具以及 Agent Harness 的明显影响。

Meta 产品方面，Alexandr Wang 对于 Muse 的研发经过、用户粘性等方面讲得很详细。此外，他也分享了自己进入 Meta 时与扎克伯格的详细对话经过，以及现在在 Meta 的主要职责等。为最大程度保留信息，我们直接采用了 QA 形式以飨读者。

## Alexandr Wang：Muse 凭什么带 Meta 翻红？

#### 7 个月做出 Muse

**主持人： 跟我讲讲 Muse 的来历吧。**

Wang： 我想，首先要从我们创办 Meta 超级智能实验室（Meta Superintelligence Labs，MSL）时的愿景说起。

实验室刚成立时，Mark 发布了一份叫《个人超级智能》的备忘录，我、Nat Friedman 以及其他一些人都和他一起密切参与了这份备忘录的工作。它最核心的问题就是：我们怎样打造足够强大的人工智能（AI），真正让所有人的生活变得更好？怎样做出一种真正能够整体提升人类体验的东西？

那份备忘录里谈到了很多想法。回头看，其中其实已经隐约指向了 Muse 最终会变成的样子，只不过当时还非常早。那是 2025 年 6 月，智能体还没有真正以有意义的方式发展起来。2025 年夏天，AI 所处的阶段和现在完全不同。但这就是我们想前往的方向，也是 MSL 的使命，是我们希望把所有工作带向的地方。

之后我们就开始埋头做模型。任何前沿模型的端到端开发流程都要花很多个月：先搭完整的技术栈，准备数据集，做预训练，再做后训练，而且这些环节本身又都需要一整套基础设施。整个端到端过程非常漫长。

到今年年初，Opus 4.5 让很多人，包括我们，真正开始看到智能体的未来可能是什么样，也把智能体的潜力一下子推到了台前。与此同时，OpenClaw 也在年初出现了。

我和 Nat Friedman 一直合作密切。我觉得他应该是 MSL 内部最早开始用 OpenClaw、认真尝试 OpenClaw 的人。他的体验介于“恐惧”和“狂喜”之间。他几乎是彻底投入进去，对它高度信任。

他后来在 Stripe Sessions 的一次采访里讲过一些故事。比如他告诉自己的 OpenClaw，希望自己多喝水，于是 OpenClaw 会通过安保摄像头观察他到底有没有喝水，看到他喝了还会夸一句“干得不错”。他还有很多类似的离谱故事，但这些故事会让你意识到：一些很神奇的事情确实发生了。

我记得 Nat 对我说过一句话，这是我印象最深的事情之一。他说：“我觉得这里真的有东西。”Nat Friedman 这种早期采用者其实是个很好的信号。他当年是 Stripe 最早的一批客户之一，很早就参与了很多开源开发者项目，也参与创建了 GitHub Copilot 等很多产品。

所以这对我来说是一个非常明确的信号：个人 Agent 这件事，本身确实有某种很特别、很神奇的东西。真正开始信任一个个人 Agent，把它深度带进生活之后，你会发现它能做的事情实在太多了。

听完那些疯狂的故事后，我也开始非常深入地用 OpenClaw。连续好几个星期，我们两个人几乎所有空闲时间都在和自己的 OpenClaw 对话，彻底沉浸在“个人 Agent 到底可以是什么”这个问题里。

**主持人： 你最初的反应是什么？狂喜，还是恐惧？**

Wang： 当时 Nat 做了一个 prompt，基本上就是对自己做一次完整的心理分析。它会进行好几轮非常深入的心理探查。他写了提示词让你拿去配合 OpenClaw 使用。我自己的 OpenClaw 装好以后，最早做的事情之一就是这个。那种感觉可能相当于把 3 年心理治疗压缩到了一个瞬间。

**主持人： 我很好奇，你第一次用 OpenClaw，为什么最先做的事情之一会是这个？**

Wang： 我把它下载、安装好，当时 Nat 就在旁边，他说：“你应该试试这个。”我就想，“好吧，那我就按你说的做。”然后就有了这次非常疯狂的体验。

**主持人： 再具体讲讲，为什么会觉得疯狂？**

Wang： 因为强度真的很高。就像我刚才说的，像是把 3 年心理治疗压缩在一起。它一轮接一轮地进行深层心理探查，而且手里还有关于我的其他信息：它能访问我的邮件，也能访问很多照片，还能去查找其他资料，再把这些信息全部拼到一起。在整个过程中，我处在一种非常脆弱、非常暴露的状态里。

那是在 2 月，我们两个人基本已经得出了共同结论：这里显然正在发生一件非常特别的事情。于是我们各自写了备忘录，并把它们递交给 Meta 董事会。当时正好是董事会密集开会的时期。

我写的备忘录大意是：从很多角度看，这可能就是某种“终极消费产品”；超级智能体在消费产品这条线上，某种意义上可能已经指向一个很清晰的终点。Nat 则写了两篇，标题都非常好记，一篇叫《Claw 即规则》（The Claw Is the Law），另一篇叫《信任是必须的》（Trust Is a Must）。后来我们打造这些产品时，很多核心原则其实都受到了这两篇备忘录的影响。

之后我们开始组团队，大概一两周就做出了一个原型，并向董事会演示。整个节奏非常快。最终 Muse 产品里的很多关键决定，其实第一版原型里就已经有了。Jollybot 当时就在，Muse Charm 的早期版本也出现在第一次会议里。当然，并不是所有想法、所有标签页当时都有，但很多核心东西已经在了。

接下来才是真正困难的部分。从 2 月那个原型开始，到 7 个月后产品正式发布，我们经历了一个非常艰难的过程：最初那个原型有时能工作，而且效果非常神奇，但更多时候它根本不工作，会不断出故障。我们必须把它从那种状态变成一个高度可靠、精心打磨的消费级产品，让我们有信心把它真正交给大众。这个过程非常漫长，也相当痛苦。

**主持人： 你们只用了 1 到 2 周就做出原型，拿给董事会看。Mark 在整个过程中扮演了什么角色？**

Wang： 他和我们一样，也在同时经历这种“狂喜与恐惧”。我记得他在一些采访里谈过，他会在家里拿它做很多事情，会和孩子们一起用，也会用于自己的综合格斗（MMA）训练。他让智能体看自己训练的视频，然后给他建议，告诉他哪些地方可以改进。

后来 Meta 团队里还形成了一种习惯：开管理层会议时，大家会互相问：“你最近和自己的智能体发生过什么疯狂的事情？”这还是 2 月份的时候。

**主持人： 现在回头看整个周期很有意思。OpenClaw 现象当时冲到顶峰，然后又消退了。**

Wang： 对，它没有持续下去。我觉得很多人的体验都类似：偶尔会出现一些特别神奇的瞬间，但绝大多数时候它并没有那么好用、问题很多，最后热度就慢慢下去了。

所以我们做产品时，一个非常重要的重点就是：怎么把它真正变成一种可靠的消费体验；怎么让你敢于把它逐步推到数十亿人面前，而且有把握说，大多数人都会获得非常好的体验。

**主持人： 为什么你们能做到，而 OpenClaw 的开发者没有做到？**

Wang： 首先，我非常尊敬 Peter Seinberger，以及所有为 OpenClaw 做出贡献的人。我觉得 Peter 毫无疑问是个有远见的人。OpenClaw 能从他的大脑里诞生，本身就很厉害。

但 Muse 之所以最后显得那么神奇，其中一个很“不性感”的部分，就是我们真的一点一点把所有细节磨出来，让模型加产品的整体体验足够好。我们对模型本身做了非常多轮迭代，也把整个模型路线图都朝着个人超级智能这个方向推进，其中个人 Agent 当然是非常重要的一部分。

**主持人： 它和你们的竞争对手有什么不同？**

Wang： 这个问题其实很有意思，最好回到当时的环境看。年初，也就是 2 月，Opus 和 Claude 在编程能力上远远领先其他所有人，而且增长极快。那是 Anthropic 开始在整个行业强势崛起的阶段。对很多人来说，那其实是一个很有压力的时刻：他们在编程上领先太多了，而且还有 Mythos 等产品，优势非常明显。

当时行业里的主流判断是：编码智能体可能是高级 AI 唯一重要的产品形态，甚至可能是唯一重要的技术、唯一真正重要的能力。因此整个行业有一股很强的力量，都在往这个用例里挤，希望在编码智能体上和 Anthropic 竞争。

但我们自己的体验，让我们对个人 Agent 形成了很强的信念。再退一步看，我们一开始之所以做个人超级智能，本来就是因为我们认为这是 Meta 最具独特优势的方向。

甚至在 Scale AI 和 Meta 的交易发生之前，我最早告诉 Mark 的事情之一就是：如果未来真的出现 AGI 或者 ASI，不管你愿意怎么叫它，Meta 其实会是一家非常特别的公司。

AI 的一部分承诺在于，我们每个人的生活里都混合着两种事情：一种是“我们想做的事”，一种是“我们不得不做的事”。AGI 的承诺是，未来我们几乎不再需要把时间花在那些“不得不做”的事情上，因为 AI 会替我们完成其中很大一部分，我们可以把更多时间都花在真正想做的事情上。

在我看来，Meta 的产品代表的恰恰就是人们“想做的事情”。我用 Instagram、WhatsApp、Facebook，是因为我在关注自己的兴趣、爱好、朋友，以及自己在乎的人。Meta 的整个产品组合，覆盖的基本就是“我们真正愿意把时间花在哪里”这个领域。从长期看，我一直认为 Meta 会是这场变化中的巨大受益者。这也是我最早形成的、关于 Meta 与超级智能的判断之一，后来很多想法最终汇聚成了“个人超级智能”这个概念。

还可以从另外几个角度理解。先看公司的历史基因：Meta 一直在连接人与朋友、家人，帮助人们发现自己的兴趣，这些事情本身都非常“人”。再从商业角度看，Meta 的应用每天触达 35 亿人，所以 Meta 最自然、最有可能做出巨大成功的领域，就是消费级人工智能。

**主持人： 不是工作，不是编程，而是个人生活。**

Wang： 对，正是如此。所以个人 Agent、个人 AI，以及更广义的消费级 AI，一直都是我们认为 Meta 能做出非常特别东西的领域。

#### 扎克伯格对持续改进产品的执念

**主持人： 好，那就到了 2026 年年初。你们已经有原型，也获得了内部支持，大家都知道 Mark 站在这件事背后。接下来就是 7 个月艰难的产品打磨。**

Wang： 对。当时一直有个心理“阴影”：个人 Agent 好像来过一阵，然后又消失了。但我们始终觉得，原因不是这个方向本身不成立，而是体验还没有真正做好、没有被打磨成熟。开发 Muse 时，我们必须始终把这个问题放在心里。

于是我们重新聚焦模型研发路线。最优先、至少也是最优先的方向之一，就是个人 Agent。我们做了非常长的表格，列出模型要成为理想个人 Agent 所必须具备的具体行为和能力。不是几千项，超过了 100 项，而且拆得非常细。

之后，我们逐渐为每一项建立评测，再研究怎样训练模型，让它在每一个项目上都做得非常好。我们会定期做评审，把那张表拿出来，看哪些地方还不行，再确保它们持续改善。整个过程非常细致，就是一点一点把模型所有毛边磨掉，直到它足以支撑产品。

**主持人： 这也是 Meta 的文化吗？这种不断把产品一点一点磨细的方式？**

Wang： 很大程度上是。Meta 的一个特点是，一旦你知道自己到底在衡量什么，这里有很多非常优秀的人，就可以围绕这些指标不断优化，把所有细节磨好，最后做到非常出色。

在 AI 之前的消费产品时代，这通常意味着：怎么优化转化率？怎么优化推荐率？怎么优化新用户引导的每一个环节？怎么把整条流程都做到几乎完美？到了 AI 时代，尤其是在 Muse 上，同样的文化更多体现为：把模型的每一个细节打磨到真正适合这个产品。

**主持人： 你看过 Jeremy Stern 在 Colossus 写的那篇关于 Zuckerberg 的人物特写吗？**

Wang： 看到了。说实话，太长了，我没读完。

**主持人： 那篇文章里，Zuckerberg 谈到自己相对于 Elon、Sam Altman 等人的一个优势。他说自己的能力一点也不“性感”，但他很擅长搭团队，然后在很长时间里一点一点把产品持续改好。而且和 Elon、Sam Altman 等人相比，他不会失去公司的控制权，也不需要再去融资，所以可以把这件事做非常非常久。你刚才谈到 Muse 那 7 个月的打磨期时，我脑子里一直想到这段。**

Wang： 我觉得完全正确。这件事需要巨大的耐心。7 个月听起来也许不长，但 AI 的节奏太激烈了，AI 世界里的 7 个月，可能相当于非 AI 世界里的 10 年。

我非常愿意把这件事的功劳给 Mark。整个过程需要耐心、克制，也需要对过程本身有足够信任。你可以回头看 2 月到 9 月这段时间 Mark 在财报电话会上的说法，他其实一直在暗示我们正在做个人 Agent。我们没有真想把这件事藏起来，我们确实在做，也一直有谈。

但整个时期，公司外部、甚至内部都有很多怀疑。华尔街非常主流的一种叙事是：“天啊，Meta 就是在疯狂烧钱。他们真的能在 AI 上做出什么东西吗？”

**主持人： 还不只是这个。更直接的说法是：“扎克伯格不可能赢下 AI。”这种话在很长时间里一遍又一遍被说。Jeremy Stern 那篇文章里还私下采访了他的竞争对手，其中有一个研究员曾经和 Zuck 共事，现在去了另一家实验室。那个人说：“我不想和他们竞争，因为 Mark 简直就是个终结者。”意思是，他根本不会停。**

文章还讲到扎克伯格的一个“超能力”：他从来不会对产品现状感到满意，所以永远想继续改。但他又不是那种会粗暴破坏团队氛围的人。他当然是非常强势的决策者，但并不靠无礼、羞辱人的方式管理。那篇文章里甚至提到，团队凝聚力对他极其重要。

Wang： 我觉得这些都对。Muse 很神奇的一点就在于，我们确实花了足够长的时间，把所有细节都认真磨过之后才发布。

个人 Agent 这个产品领域其实像走钢丝：如果它能稳定地交付那些神奇体验，它完全可能成为有史以来最伟大的消费产品之一；但你面对的是模型，是非确定性系统，是会出错、会失效的智能体。如果用户一再遇到不可靠体验，他们就会直接觉得这个东西很垃圾。所以我们必须把产品质量和价值做到一个足够高的水平，才能让这么多下载并使用它的人真正产生共鸣。

#### 怎么判断 Muse 已经可以发布

**主持人： 你们到底投入了多少资源、团队有多大、有多少人在做？你们会不会掌握类似这样的数据：一个用户用了 Muse，遇到 9 次很棒的体验、2 次不稳定甚至很糟糕的体验，然后就流失了？你们会分析这种情况吗？**

Wang： 年初很多其他智能体产品都能看到类似现象，几乎所有人最后都会从那些产品里流失，根本原因就是它们不可靠。

我们对 Muse 做了大量用户测试。一轮又一轮地让新用户从零开始下载、使用，然后观察整个体验到底是什么样。

Muse 最重要的前提之一，也是我认为真正成立的一点，就是它和大多数人过去接触的消费级 AI 完全不是一回事。它不是聊天机器人，它是智能体，可以替你做真正属于智能体范畴的事情。

对开发者来说，这可能早就是“旧闻”了，因为他们很早就开始下载各种智能体来用。但对大多数普通人而言，从聊天机器人跨到智能体这一步本身都需要被解释，而且必须通过非常周到的新手引导帮助他们理解。

另外，我们当然会不断比较不同模型版本，也会持续做 A/B 测试。产品体验对模型质量极其敏感：模型能不能可靠地完成任务，能不能可靠地和用户沟通进度，遇到需要用户决策或指导的事情时，能不能可靠地回来询问用户，这些都会显著影响最终体验。

**主持人： 那你们究竟怎么知道，它已经“准备好可以发布”了？**

Wang： 一部分判断非常量化。还记得我刚才说的那张超过 100 项能力的表格吗？我们给每一行都设定了阈值：低于什么水平就属于“阻塞发布”，达到什么水平才算“好”。

我们经历过很多模型检查点：可能 80 项是绿的，但 20 项还是红的。我们很清楚，那还不够。直到第一次出现一个所有项目全绿的模型检查点，它是专门训练过的 Musepark 1.3 版本。这是非常数字化的一部分。

另一部分就是实际体验。我们自己去用这个模型，可以明显感觉到，它比此前迭代过的任何版本都好得多。

**主持人： 回到那 7 个月，从模型到产品一共多少人在做？**

Wang： 总共不到 200 人。听起来可能不少，但放在大公司里，其实规模很小。

现在回头看，这件事很酷。我们很早就知道，这会是今年 Meta 最重要的产品之一，整个管理层都知道。但组织上我们还是保持了克制，确保它由一个很小、非常专注的团队来做，而不是突然膨胀成“公司一大片人都在参与”的状态。

因为我们知道，它必须像一件完整的作品。你需要非常明确的观点，非常强的聚焦，才能最终把它做成一个统一、漂亮的体验。

**主持人： 为什么需要一个统一视角？**

Wang： 我觉得大型组织做出来的产品有一个常见问题，而且现在已经开始困扰不少 AI 实验室：产品会变成某种“弗兰肯斯坦式”的拼接物，甚至像大卫·柯能堡电影里的混合怪物一样，把很多人的观点、愿景和信念硬拼在一起。

某种意义上，这就是产品经理（PM）地狱。每个 PM 都有一个自己想塞进产品里的东西，大家都往里面加，最后所有东西搅在一起，像一杯什么都放了的奶昔。

用户其实能感受到这一点。一个产品如果明显是很多不同的人分别做出来的，每个人目标还不一样，最后只是把东西硬塞在一起，消费者一用就能感觉出来。

Muse 必须完全相反。它要有一个清晰观点，有一个一致的整体体验，这是我们真正想交付给世界的东西。

**主持人： 我特别喜欢你这么说，而且很巧，我们录这期节目时正好是 Steve Jobs 去世 15 周年，我也不知道节目最后什么时候会发布。**

**如果说到消费产品里“有一个统一观点”的人，当然首先会想到 Steve。我读过几乎所有关于 Steve 和 Apple 历史的书，在另一个播客 Founders 里也做过大概 15 到 20 期相关节目。我最喜欢的一句描述是：“Apple 就是拥有 1 万条生命的 Steve Jobs。”产品反映的是他的品味、视角和世界观，他希望世界里出现什么，最终用户拿到的就是什么。**

**在 Muse 这件事上，我觉得 Nat Friedman 应该得到很多功劳。他的品味和判断，最终非常深地塑造了这个产品。你们现在会公开说 Muse 有多少用户吗？**

Wang： 我们公开说过“数百万”。我也转发过一些别人做的增长曲线，那些曲线会让人推断，Muse 是有史以来增长最快的消费级应用之一，至少是增长最快的消费级 AI 应用之一。

**主持人： 但你还是不会说具体数字。**

Wang： 我们说了“数百万”。

**主持人： “数百万”也可能是几亿，几亿也属于“数百万”的范围。你只是不说前面的数字而已。**

#### 用 Meme 让 Meta 再次变酷

**主持人： 我还想聊一个变化。带着善意说，你最近在 X 上的状态有点“放飞自我”。Muse 发布之后，你公开发帖的风格明显变了。这是一种营销策略吗？到底发生了什么？这肯定比你以前做 Scale AI 有意思多了吧？过去几个星期看起来简直是你职业生涯最开心的一段时间。**

Wang： 确实是我职业生涯里最开心的时期之一。我觉得有几个原因。

第一，我们觉得必须想办法让 Muse 真正“穿透”出来。现在 AI 行业更新像洪水一样。普通人每天都在被新 AI 产品、新创业公司、新模型、新功能轰炸：又一个模型、又一个产品、又一个功能，永远没有尽头。

我们团队专门开过大会议讨论这个问题：必须想办法突破这种信息洪流。Meta 当然拥有巨大的分发能力，我们可以确保很多人都知道这个产品，但“让所有人知道”并不等于它能在文化层面真正突破，让整个世界觉得它有趣、值得关注。

我个人生活里刚好认识并和一些做 Meme 的人交了朋友。我会开玩笑叫他们“精神分裂朋友”，其实就是那种一天到晚泡在网上、一直在研究 Meme 和互联网文化的人。

**主持人： 我认识一些人，他们不仅痴迷 Muse，也痴迷你的 X 时间线。他们坚信你背后有 100 个 Muse 在替你想 Meme。**

Wang： 事实是，我只是有一群天天泡在网上的“精神分裂朋友”。不过有一点可以说明：我 X 上那些帖子，真的是每一条都我自己写。

有一段时间，我开会时甚至很难集中注意力，因为脑子里会突然冒出一个 Meme，我就想：“天啊，这个必须马上发出去。”那种感觉很像灵感突然来了。

有一次我本来在和同事吃饭，吃到一半突然说：“等等，我想明白了。”然后立刻发了另一个 Meme。那种状态甚至让我重新有一点像工程师修 Bug：你会感觉到某个东西马上要“对上了”。所以第一件事，是我们想让 Muse 突破信息噪声。

另一件我觉得也很重要，就是：怎么让 Meta 再次变酷？Meta 明明拥有 Instagram、Facebook 这些极其有文化影响力的软件，但历史上有一段时间，Meta 本身并不“酷”。所以我们希望它重新变得有趣、好玩、有文化感。

至于那种“放飞自我”的风格，其实是慢慢自然形成的。Muse 刚发布时，我主要只是转发各种有意思的使用案例，一天能转很多条。后来因为发得实在太多，有些帖子我几乎没怎么想，心里就是一句“算了，发吧”。结果其中一些反而表现特别好。

**主持人： 你见过那种图吗？横轴是“花多少时间思考”，最后真正爆的内容反而是几乎没想就发出去的那种。**

Wang： 我没见过那张图，但我完全同意。有些帖子我真的没花多少时间。发出去后几个小时都没看手机，回来一看：“哇，这条居然这么好。”

然后我重新想起了互联网的一个规律。虽然不是刻意策划，但互联网会奖励风险，也会奖励惊喜，奖励那些大家意料之外的东西。于是我就越发越开。

很多同事其实都挺惊讶。那一周我一直发 Meme，Nat 在很多会议里反复说一句话：“我原本以为，我们会从中学到很多关于 Muse 用户、大家怎么使用 Muse 的东西。结果我们真正学到最多的，是 Alex 的大脑到底在想什么。”

确实特别有意思。我感觉自己把过去很多年积累的互联网知识，全部调出来用在了那几天里。我们没有很完整的追踪数据，所以很难严格证明，但我真觉得这些内容对增长产生了实际影响，这本身挺好笑的。

#### Muse 怎么留下用户？

**主持人： 我现在到哪儿都听人谈 Muse，而且和我聊这些的人，很多都已经下载了应用并开始用。回到你前面的话题。你们拥有分发能力，不代表一定能做出一个大家会回来持续使用、真正有黏性的产品。Muse 是怎么做到的？**

Wang： 我们一直在想：怎么让这个产品真正突破？其中有几部分。

第一，怎么尽快把用户带到那个“哇”的时刻，也就是所谓“wow 时刻”。Muse 天生比较适合做这件事，因为它本身就是 AI，可以做很多事。如果一个人以前从没真正用过 AI 智能体，它能做的很多事情都会让人吃惊。

第二，怎么把这些用户经历“哇”时刻的故事利用起来，让产品自己开始传播、自己“飞起来”。

**主持人： 但你们怎么利用这些故事？你们也没有专门给我投广告吧？**

Wang： 我们确实投过少量广告。但最开始最有效的事情，其实只是我会转发大量用户案例。只要看到有人用 Muse 做了有意思的事情，我就会引用转发。

**主持人： 我一直不理解，为什么 Anthropic 和 OpenAI 的广告会做得那么差。Anthropic 当时做了很大的户外广告，但几乎都在讲自己。OpenAI 也类似：放一个我觉得很多人甚至认不出的图标，再写一点不知所云的字，画面里就是两个人坐在桌边。**

我会想：这到底是什么意思？你们明明有那么多真实使用案例。广告只需要展示产品给用户带来的好处，就够了。你们有几百万个案例，直接把那些做成广告不就行了吗？这其实是最基础的营销逻辑，但大家还是会一遍又一遍犯这个错误。

Wang： 完全同意。我们在做 Muse、甚至在 Meta 做任何产品时，经常回到一个问题：为什么别人要在乎？他们并不在乎你，也不在乎你的公司。每个人都天然更关心自己。

**主持人： 有一本非常老的书叫《科学的广告》（Scientific Advertising），写于 20 世纪初。那本书价值高到什么程度？作者 Hopkins 当时是最顶尖的广告文案人之一，他基本把自己赚钱的方法全写进去了，所以有人甚至把手稿锁进保险柜 20 年。**

本质上，这本书讲的并不只是广告，而是不会变化的人性。他的核心观点就是：很多广告一直在讲“我是谁”“我的产品是什么”“我有这个东西，你来买”，但消费者根本不在乎。消费者关心的是自己。你真正要做的工作，是直接告诉他：“这个东西能给你带来什么？”然后从这里开始讲。

这些想法写于 20 世纪初，后来在 20 世纪 50 年代、60 年代、70 年代依然帮助很多人建立了巨大的公司和广告机构，直到今天仍然成立。

Wang： 100% 同意。我觉得这里有几个问题。第一，世界上绝大多数人根本不在乎 OpenAI 做了什么研究，也不在乎其他公司做什么研究，甚至不在乎我们自己做什么研究。他们只关心这东西到底能替我做什么？

我们还有一个非常幸运的资产，就是那个小小的 Jolly 吉祥物。我记得有一条帖子让我突然意识到：“这个东西很有潜力。”当时我正开车去上班，在路上生成了一张 Jolly 拎着公文包的图，然后发了一句“MFW 我周一去上班”。我当时就觉得，这是我最近发得最好的一条。

接着我意识到，这个小家伙几乎可以被放进任何场景。我们当时一直在想：怎样创造一种真正出人意料的时刻，和你过去见过的产品营销都不一样？我已经想不起上一次有谁真的用比较大胆、擦边的 Meme 去营销一个产品是什么时候了，甚至不知道以前有没有人这么做过。但我意识到，我们可以用这个小家伙做这件事，而且普通人会觉得有趣，会被勾起好奇心。

**主持人： 这些东西可以提高认知度，甚至让人下载应用。但应用装到手机里之后，怎么让用户继续留下来？**

Wang： 真正喜欢这个产品的人，通常都会经历一个循环，我们 2 月自己用的时候也是这样。

一开始，你只给它一个很小的任务，它完成了，你会想：“哇，它连这个都能做。”然后你再给它一个稍微更复杂一点的任务，它又做成了。你就会想：“原来第一个能做，第二个也能做。”于是你开始交给它更大的问题。

这有点像你和 AI 智能体之间做一场“信任倒”游戏。最开始其实不太信任它，只是好奇，所以先喂一点小任务，然后一点一点加码，任务越来越大。

我和大学生交流时尤其明显。有些人使用 AI 的方式已经完全进入了“全信任”状态。他们会直接录一大段语音，把脑子里的所有东西一股脑倒给 AI，然后直接相信 AI 会替他们整理思路、给出清晰计划，告诉他们下一步该做什么。

所以对真正成功使用 Muse 的用户来说，关键就是进入这样一个信任递进过程：让它处理一点更大的事情，再大一点，再大一点，而且每一次都真的做好。

**主持人： 我在读《从 0 到 1》时看到过一句我最喜欢的话之一：“我观察到最强大的一个规律，是成功的人总能在意想不到的地方发现价值。”他们靠的是第一性原理思考，而不是套公式。我很好奇，这里面到底有多少增长来自口碑。**

比如我这次要采访你，不管怎样我肯定会下载 Muse。但真正让我产生兴趣的，是一个朋友直接把他怎么用 Muse 的截图发给我。

你下载应用后，其实它并不会把“你能做什么”讲得特别清楚，更像是给你一个开放输入框。我有个朋友经营一家估值大约 1000 亿美元的公司，他把身份证落在 Flexjet 上了。他直接跟 Muse 说：“我完全不想参与这个过程。你自己想办法把证件拿回来。证件现在在这里，我人在这里，中间所有步骤你自己解决。”

然后 Muse 就一路把流程跑通了：安排快递员去取，设法通过他办公室的安保，再把东西送到楼上办公室。看到这个我就想：这简直是最好的营销。只需要三四张他和 Muse 对话的截图，他一句“我不想参与，你全都替我做”，然后 Muse 自己一路把问题解决了。

Wang： 对，这其实也是现代产品营销里很重要的一点。我不知道我们最开始有多刻意，但现代消费产品非常依赖截图传播。一个消费产品，必须“在截图里也成立”。截图本身要能在群聊、口碑传播和互联网上飞起来。

这对 Muse 的增长帮助很大。我们并不是刻意设计成这样，但截图里刚好总会出现那个小家伙，这件事其实非常重要。Jolly，或者说你自己的那个 Muse 角色，只要出现在截图里，别人一眼就知道：“这是 Muse 的截图。”这可能就是你能拥有的最好的营销。

**主持人： 你自己是不是一整天都在用 Muse？你个人到底怎么用？**

Wang： 我主要用它搭了很多工作流。我大部分时间都在开会，而我的工作决定了我得集中注意力、保持在场、和人互动，所以我不会一直盯着 Muse。更多时候，我是先搭好很多工作流，把它当成一种“第二大脑”。

**主持人： 你描述 Muse 的方式我很喜欢：如果每个人除了自己的大脑之外，还能再拥有一个“第二心智”。从哲学上讲，我觉得这是 AI 最有意思的问题之一：当我们拥有非常强大的 AI 之后，“做人”到底意味着什么？人与 AI 的关系会变成什么样？不同的人会有完全不同的想象。最令人恐惧的一种版本当然是，AI 高高在上，我们只是在跟着它做事。但也可能存在完全不同的关系模式。我想先问，你自己真正相信的版本是什么？**

Wang： 我真的相信 Muse，也相信个人 Agent 会成为一种长期存在的产品形态。

人类天生就有欲望、有愿望、有梦想。我认为 AI、以及 Muse 这样的个人 Agent，会成为一种机制和桥梁，帮助我们把这些事情做成，并且不断做成更多事情。然后人类会越想越大、越想越远。未来的孩子可能会梦想拥有自己的星系之类的，而 Muse 会帮助他们一步步做到。

Jeff Bezos 好像在某封股东信里写过一句话，大意是：消费者最美妙的地方，就是他们永远“美丽地不满足”，永远不会对现有选择真正满意。我觉得这就是我们与 AI 关系的一种模式。

当然还有其他模式。AI 会越来越多地参与科学发现过程，也会越来越深地进入经济体系的不同环节。但从长期看，我非常相信这样一种形态：每个人都有一个 AI，支持他真正想要的东西。

主持人： 所以在你看来，AI 有点像是在替人清掉生活里那些麻烦、笨重、我们根本不想做的事情。你那篇文章里好像写过，世界到处都是守门人和障碍，而 Muse 可以替你绕过它们，不再额外消耗你的时间，让你把注意力真正放到自己想做的事情上。

Wang： 我觉得 Muse 可以把“小时候梦想中的成年生活”还给每一个人。

人小时候都有很大的想法、很大的梦想。想象未来时，你可能觉得自己会成为宇航员、拯救地球、改变世界，或者做任何很大的事。孩子天然敢想。但因为各种原因，等人读完书、进入职场、工作了一段时间，那些希望、雄心和做梦的能力往往都被吸走了。

**主持人： 不只是吸走，是被生活一点一点打掉了。**

Wang： 对。作为成年人，我们可能低估了自己到底有多像“僵尸”。我们失去了主体能动性，也失去了雄心，我觉得“雄心”这个词非常准确。

AI 的一个巨大承诺，尤其是通过 Muse 这样的产品，就是让这种东西从童年一路延续下去。小时候你有很大的梦想，AI 帮你实现；然后你再做更大的梦，再实现；再做更大的梦，再实现。也就是说，你一生的主体能动性可以像坐扶梯一样不断上升，而不是小时候有很多能动性，后来却被现实一点一点压碎。

**主持人： 你刚才说这些时，我想到你和 Nat Friedman 之前做过的那个经历：AI 一波一波对你进行那种让人不舒服的心理审视。有没有可能把它反过来？不是把人拆解得更脆弱，而是给你更多自信，让你理解这个世界其实是可塑的：只要你真的用足够大的力量去推动，用足够多的精力和驱动力追下去，你是可以改变周围世界的。**

Wang： 对。我觉得最优秀的创业者身上普遍都有这种特质：先做一个大梦，把它实现，然后做一个更大的梦。也许下一个梦想要花 10 年，但如果又实现了，他们还会继续做更大的梦。

Elon 显然是很典型的例子，Mark 也是，很多标志性创业者的人生体验其实都是这样。我觉得这种体验应该属于每一个人。可悲的是，大多数人最开始都有很大的梦想和想法，进入公司、进入职场之后，慢慢就变成了“僵尸”。也许某一天你还想重新去追自己的梦想，但那时已经背上了太多承诺：可能有家庭，可能还有各种责任，于是整个人几乎被困在这种“僵尸状态”里。

**主持人： 我还想最后问一个 Muse 的问题。你那篇短文里有一句我特别喜欢的话：“到今天为止，世界一直由极少数狂热者塑造，他们想尽办法，把自己的愿望变成了现实。但我们还从没见过这样的人类社会：每一个人的主体能动性都被完全打开。”**

Wang： 我刚才描述的未来，就是每个人一生中的能动性都持续增加，每个人都有能力去完成自己的愿望和梦想。我觉得那会是一个非常疯狂、但非常好的世界。

它会特别有趣，会非常有艺术感，也会很酷。你走进世界不同角落，会看到非常多样、完全不一样的东西。

试着想象一下：突然之间，因为智能变得极度充裕，几十亿人都获得了把不可思议的事情做成所需要的资源。那个世界会非常疯狂。这就是 AI 承诺的一部分。

我脑子里有时候会把它想成《瑞克和莫蒂》（Rick and Morty）里的“跨维度电视”，只不过它不是电视，而是真的在现实世界里被人类做出来。那可能会非常棒。

主持人： 我脑子里一直响起那部剧里一句话：“宇宙会吃掉聪明人。”

#### 扎克伯格打来的那个改变一切的电话

**主持人： 好，我们回到 Scale AI。你创办了 Scale AI，也一直在经营它。有一天，Mark Zuckerberg 突然联系你。我猜他说的可能就是：“嘿，我想聊聊。”当时具体是怎么发生的？**

Wang： 我记得他发来的原话大概是：“你有时间打个电话吗？”

**主持人： 在这之前，你和 Mark 本来就有关系吗？你们以前一起相处过吗？**

Wang： 我有个朋友叫 Alex Schultz，我认识他很多年了，大概从 Scale 成立 1 年左右时就认识。我是在 旧金山见到他的。他现在是 Meta 的首席数据官，也是 Meta 长期以来非常重要的一位高管。

我记得大概是 2021 年或者 2022 年，他把我介绍给了 Mark，让我们聊 AI。那时 Mark 对 AI 的兴趣已经明显变强，而 Scale 也在 AI 上做很多事情。我印象中，第一次见面其实排了差不多整整 1 年。从 Alex 把我们介绍认识，到真正把会议排进日程，中间大概真的隔了 1 年。

**主持人： 为什么？**

Wang： Mark 的日程当然非常疯狂，要处理的事情多得难以想象。而且他非常擅长确定优先级。他会在真正重要的事情上花非常多时间，有时候甚至多到夸张。

他之所以还能同时做一个好父亲、好伴侣，又处理这么多工作，本质上就是因为他对优先级极度残酷。

第一次见面之后，我们也断断续续聊过几次，我还会以创业者身份找他请教。能向 Mark Zuckerberg 这种人请教，当然是一件很大的事。

我记得那时候有个细节让我很困惑：我会在 WhatsApp 上问他一个问题，然后他很快就回一大段特别完整、特别严谨的文字。我当时一直想，他怎么有时间写这么长？后来我才意识到，他只是写得真的非常快，而且思考非常严密。他能在很短时间里写出一段结构很完整的长回复，这是他非常厉害的一项能力。

**主持人： 这其实等于给你开了一扇窗，让你看见他脑子里正在怎么跑。**

Wang： 对。Meta 当时也是 Scale 的重要客户。在这次事情发生之前，我和 Mark 大概每 6 个月聊一次，差不多就是这种频率。

后来他打来电话。但第一通电话时，其实完全看不出事情最后会走到哪里。那是在 Llama 4 之后。他一开始基本只是问：“你觉得我们应该做什么？我们应该把注意力放在哪里？”

**主持人： 为什么“在 Llama 4 之后”这个时间点这么重要？**

Wang： 因为 Llama 4 并没有走在 Meta 原本希望的轨道上。对公司内部来说，它显然令人失望。与此同时，AI 的重要性还在越来越快地上升，大家已经非常清楚，AI 会成为 Meta 未来极其关键的一部分。

所以最初几次电话里，他主要还是在问我建议：你觉得我们该做什么？最应该聚焦什么？

**主持人： 我私下听过很多人讲 Mark。那不完全是“董事会”，虽然他也会向一些董事这么做，而是他身边有一群世界级创业者。我和其中一些人聊过，他们会说：“你根本不知道，他会有多频繁地来问意见。”**

他会不断联系这些人，说：“这是我现在生活里、工作里发生的事，如果是你，你会怎么做？”然后一遍又一遍地问。

Wang： 我觉得这是一种非常令人佩服的特质。因为这当然需要谦逊。一个人已经取得了那么多成就，还能一直这么做，并不容易。从他第一次联系我，到我们最终宣布交易，整个时间线只有大概 5 到 6 周，非常快。

**主持人： 这也是世界级创业者经常有的共同点。我们之前请 Groq 创始人 Jonathan Ross 来过这个播客，他第一次公开讲自己和 Nvidia 那笔 200 亿美元交易，也是在节目里。他说，从 Jensen 第一次打电话，到钱真正进银行账户，只用了 3 周。**

Wang： 太夸张了。我当时其实有很多想法：如果让我来做，我会怎么想 Meta 的 AI 战略。最早说的一件事，就是刚才讲过的那点：Meta 的历史基因一直围绕“人们真正想做的事情”，所以在 AI 这次巨大转变里，它其实处在一个非常特殊的位置。

我给 Mark 提了很多很多想法。与此同时，另一条对话也在并行发生，大意就是：“也许我们可以看看，有没有某种方式一起做点事情。”

**主持人： 他第一次这么说时你怎么想？因为这显然不是你能提前预料到的。**

Wang： 完全没预料到。整个过程当时都非常疯狂。我最初的反应基本是：“哦，挺好的，但应该不可能真的……”

**主持人： 你知道这种话通常是什么意思吧？“我们得找个办法一起合作”，翻译一下就是：他们想买你。**

Wang： 当时没有人这么“辅导”过我。而且我那时很明确地觉得，这件事可能压根就不太合理。我会想：“也许他只是试探一下，随口把这个可能性抛出来，但这真的有逻辑吗？”

**主持人： 为什么你觉得没有逻辑？当然，现在我们知道交易最后发生了。但我想问的是，你当时身处那个过程中，为什么第一反应会是“这不合理”？**

Wang： 退一步看，Meta 历史上最标志性的收购是 Instagram 和 WhatsApp，这两笔交易都有非常清晰的产品逻辑。Scale 则完全不同。我们是很深的企业级、政府销售业务，是一种和 Meta 完全不一样的公司。

所以我当时能想到的工业逻辑是：如果 Meta 想真正进入这些企业、政府市场，那也许收购或深度结合还有意义。但事实并不是这样。Mark 显然最关心的，是把 Llama 项目、以及 Meta 整体 AI 项目重新带上轨道。他真正想要的是人才。

**主持人： 对，他想要人才。**

Wang： 但整个过程很长一段时间都很模糊，并没有直接把这件事说透。

**主持人： 什么时候你觉得事情变清楚了？**

Wang： 钱打到账上的时候，开玩笑。真正开始谈数字的时候，我就想：“哇，好吧，那这件事确实认真了。”从那时开始，一切才变得更清晰。

**主持人： 一开始你觉得不太合理，后来越聊越多。Mark 花了多久让你相信，这条路对你来说是值得走的？**

Wang： 其中一个重要原因是，我觉得这个交易结构本身太有意思了。最终我们形成的安排是：Meta 投资 Scale，并持有 Scale 49% 的股份；Scale 继续独立运营；我和几个人加入 Meta。

我当时觉得最不可思议的地方，就是这是一种非常奇怪的交易结构，但它又确实形成了某种“三赢”：Scale 的股东赢了，因为所有股东都拿到了非常好的回报，受益很大；Scale 本身也继续存在，我真心相信 Scale 最好的日子还在后面；与此同时，我也能去 Meta 做新的事情。

**主持人： 我真正好奇的是：Mark 是不是一通电话解释完，你就马上接受了这个逻辑？还是你会想：“等等，这也太疯狂了，我得想几天。”能讲多少讲多少，这个决定过程到底是什么样？**

Wang： 持续了好几个星期。我的状态一直是：“这也太疯狂了，这是真的吗？这有道理吗？如果有道理，我自己到底怎么看？”

最主要的情绪就是太疯狂了。后来我开始真正意识到，我必须做一个决定：到底去不去。这件事本身就带来了很多对话，包括和 Scale 的同事、投资人交流，里面有很多很复杂、很有意思的讨论。

**主持人： 这当然很难。某种意义上，你是在放下自己的“孩子”。你做 Scale 多久？**

Wang： 从创办到那时，一共 9 年。

**主持人： 而且你还不到 30 岁，这差不多是你人生的三分之一。**

Wang： Paul Graham 讲过一个观点：如果你把自己的公司视为“人生作品”，你的经营方式就会完全不一样。我在 Scale 的整个时期，真的一直把它当作自己的人生作品。所以从情感上说，这是一个非常艰难的过程。

最后真正推动我做决定的是叠在一起者几件事。第一，这确实是一笔对各方都很好的交易。第二，我真的看见了 Meta 那边可能发生什么。当时 Meta 的 AI 在很多人眼里已经有点像“受损资产”，甚至可能不是做 AI 最有吸引力的地方。但这反而激活了我的创业者本能。我会想：你其实可以把它重新建一遍。

**主持人： 就像把整个实验室重新创办一次。**

Wang： 对。这也是后来最吸引我的地方之一。因为需要做的事情实在太多，反而给了我空间，从头搭很多东西：重新确立正确原则，重新建立正确文化。这些条件，让我们有机会真正建出一个很厉害的组织。

#### 从头重建 Meta 的 AI 实验室

**主持人： 你和 Mark 当时就是这么讨论的吗？“我们得重启。”如果继续沿着原来的路走，基本没戏，所以干脆把现有东西拆到地基，再用完全不同级别的人才重建。**

**我之所以这么问，是因为他的动作看起来根本不像“小修小补”。更像是：“这完全不工作，也不可能工作，那就拆掉重来。”**

Wang： 对。这个判断也是逐渐形成的。有一个原则我一直非常相信，而 Elon 在职业生涯不同阶段也证明过：如果你有一个规模很小、技术能力极强、组织层级非常扁平的团队，就能以非常快的速度完成非常多事情。

我对这种模式很有信念，而且我认为对 AI 来说尤其正确。特别是当你必须像我们当时那样高速推进时，这种组织方式非常重要。

很早的时候，我反复和 Mark 讨论这一点，他也很兴奋。后来它变成了我们整体战略最重要的支柱之一：团队要小、非常扁平、极度技术导向，同时保持极高的人才密度。如果这些条件都具备，组织到底能跑多快？

**主持人： 从外面看，我会用一个说法形容 Mark：一旦决定，他会直接把弹匣打空。你读过《拿破仑的思想》吗？**

Wang： 没有。

主持人： 这本书 1957 年出版。我是因为看过一次 Tyler Cowen 采访 Sam Altman 才找到它的。大概是在 2018 年，他问 Sam：“你今年读过最重要的一本书是什么？”Sam 说是《拿破仑的思想》。这本书非常难找，我后来买到一本。全书大约 300 页，全部是拿破仑自己的话，只是按照主题重新组织。

里面一个反复出现的观点就是：犹豫是致命的。但拿破仑的意思并不是“不思考”。真正采取行动之前，他会进行大量推演，从每一个角度研究，确认自己走的是正确方向。

我觉得这和 Mark 的方式很像：先花很多时间论证，确认方向。但一旦决定，就彻底押上去，不再犹豫，直接把所有火力打出去。我看你们这段经历就是这种感觉：他把你找来，然后你们开始重建整个组织。

Wang： 我觉得他真的把一个观念内化得非常深：失败本身并不重要，真正重要的是，当你赢的时候，你能赢多大。这个观念让他在很多情况下可以非常无畏地行动，因为他真的非常习惯承担巨大风险。

**主持人： 他有一句很经典的话：“在一个持续变化的世界里，最大的风险就是不承担任何风险。”**

Wang： 对。我觉得他确实把这件事内化得非常深。完全可以想象另一个版本的 Meta：它越来越像 Google，行动更慢、更官僚，最后变成一家完全不同的公司。但正因为 Mark 把这些经验内化得很深，他一直能让这家公司保持动态、保持速度、保持生命力。

#### 从创始人变成“教练”

这种方式对公司有利有弊。不过如果你第一次创业，我依然会建议这么做。因为相比一开始就把很多关键事情放出去，这种方式更有可能让第一家公司成功。

第二，在团队里发现特别的人才，然后给他们环境和资源，让他们把能力发挥到最大。大公司经常犯的一个错误是：其实公司里不缺非常优秀的人，但组织没有真正授权他们做出自己最好的工作。所以这些人最后会离开，去更小的公司、创业公司，或者别的地方。

**主持人： 你前面提到 Jeff Bezos 的股东信。他也反复说过类似的话。我读过很多关于他的书，也看过那些股东信：如果你有很棒的人，却不让他们真正建设东西，他们迟早会离开。**

Wang： 对，而且 AI 尤其特殊。现在大家经常说“研究”这个词，说得太多，甚至好像已经失去意义了。但从定义上说，人类确实不知道这些模型能力的边界在哪里，也不知道究竟还能拿它们做出什么东西。这些模型本质上仍然像一些我们并没有真正理解的未知物体。

我们还有一些非常出色的研究员，他们会冒出很激动人心的想法。那组织要做什么？就是创造一个环境，让他们能去探索。其中大多数想法可能不会成功，但少数一旦成功，会成功得不可思议。那些极少数成功案例，就足以解释前面所有投入。

所以我经常把问题分成两类：一种像“挖钻石”，一种像“盖摩天楼”。关键取决于你做的事情，回报分布到底是什么形态。有些领域是典型的幂律分布。绝大多数尝试可能都没有什么价值，但极少数东西，价值可能是其他全部投入的 100 万倍。风险投资（VC）就是一个很典型的“挖钻石”行业。核心不是把所有事情平均做好，而是找出那些极其特殊的想法，然后一直支持它走到底。
