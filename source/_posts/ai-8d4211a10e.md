This week's Java roundup for September 14th, 2026, features news highlighting: the GA release of JDK 27, LibericaJDK 27, Open J Proxy 1.0 and A2A Jakarta 1.0; point releases of Azul Payara, JHipster, JetBrains Ktor and BoxLang; and introducing Netflix ja, a modern JMS command line development experience for Java developers.

#### JDK 27

Oracle has [released](https://blogs.oracle.com/java/the-arrival-of-java-27) version [27](https://jdk.java.net/27/) of the Java programming language and virtual machine, which ships with a final feature set of nine JEPs. Further details may be found in this InfoQ [news story](https://www.infoq.com/news/2026/09/java27-released/).

#### JDK 28

[Build 16](https://github.com/openjdk/jdk/releases/tag/jdk-28%2B16) of the JDK 28 [early-access builds](https://jdk.java.net/28/) was made available this past week featuring [updates](https://github.com/openjdk/jdk/compare/jdk-28%2B15...jdk-28%2B16) from Build 15 that include fixes for various [issues](https://bugs.openjdk.org/issues/?jql=project%20%3D%20JDK%20AND%20fixversion%20%3D%2028%20and%20%22resolved%20in%20build%22%20%3D%20b16%20order%20by%20component%2C%20subcomponent). More details on this release may be found in the [release notes](https://jdk.java.net/28/release-notes).

For [JDK 28](https://openjdk.org/projects/jdk/28/) and [JDK 27](https://openjdk.org/projects/jdk/27/), developers are encouraged to report bugs via the [Java Bug Database](https://bugreport.java.com/bugreport/).

#### BellSoft

[Catherine Edelveis](https://www.linkedin.com/in/cat-edelveis/), Developer Advocate at BellSoft, describes all of the new JDK 27 features in this YouTube [video](https://www.youtube.com/watch?v=VxN-jrjF_GA). #### Jakarta EE

In his weekly [Hashtag Jakarta EE](https://www.agilejava.eu/) blog, [Ivar Grimstad](https://se.linkedin.com/in/ivargrimstad), Jakarta EE Developer Advocate at the Eclipse Foundation, provided an [update](https://www.agilejava.eu/2026/09/20/hashtag-jakarta-ee-351/) on Jakarta EE 12, writing:

The design of the [Starter for Jakarta EE](https://start.jakarta.ee/) has been refreshed to align with the design of the [Jakarta EE website](https://jakarta.ee/). Developers are encouraged to test drive this new UI and provide feedback

#### OpenJ Proxy

The [GA release](https://www.linkedin.com/feed/update/urn:li:activity:7507399472805507072/), along with two release candidates, of [Open J Proxy](https://openjproxy.com/) 1.0.0 delivers bug fixes and new features such as: improved performance with a local cache added to the immutable **`[DatabaseMetaData](https://github.com/Open-J-Proxy/ojp/blob/main/ojp-jdbc-driver/src/main/java/org/openjproxy/jdbc/DatabaseMetaData.java)`** and **`[ResultSetMetaData](https://github.com/Open-J-Proxy/ojp/blob/main/ojp-jdbc-driver/src/main/java/org/openjproxy/jdbc/ResultSetMetaData.java)`** classes; the ability to configure a leak detection threshold for the [HikariCP](https://github.com/brettwooldridge/HikariCP/blob/dev/README.md) JDBC connection pool using a new **`ojp.connection.pool.leakDetectionThreshold`** property; and an implementation of the [Core JDBC Type 3](https://www.geeksforgeeks.org/java/jdbc-type-3-driver/) driver.

In January 2026, Open J Proxy [partnered with OmniFish](https://omnifish.ee/omnifish-announces-partnership-with-open-j-proxy/) to "*help Java teams address database scalability challenges that arise in elastic architectures such as Kubernetes, microservices, and cloud-native deployments*."

Further details on this release may be found in the release notes for [version 1.0.0](https://github.com/Open-J-Proxy/ojp/releases/tag/v1.0.0), [version 1.0.0-RC3](https://github.com/Open-J-Proxy/ojp/releases/tag/v1.0.0-RC3) and [version 1.0.0-RC2](https://github.com/Open-J-Proxy/ojp/releases/tag/v1.0.0-RC2).

#### A2A Jakarta

WildFly has [released](https://www.wildfly.org/news/2026/09/10/A2A-Jakarta-1-0-0-Final-is-released/) version 1.0.0.Final of [A2A Java SDK for Jakarta Servers](https://github.com/wildfly-extras/a2a-jakarta/blob/main/README.md), the Jakarta integration for the [A2A Java SDK](https://github.com/a2aproject/a2a-java/blob/main/README.md). New features over the past few release candidates include: an implementation of the authorization tests from A2A Java SDK; and a replacement of the duplicated multiversion routing in favor of annotating classes and interfaces in the **`[a2a-jakarta-http-common](https://central.sonatype.com/artifact/org.wildfly.a2a/a2a-jakarta-http-common)`** module with the Jakarta RESTful Web Services **`[@PreMatching](https://jakarta.ee/specifications/restful-ws/4.0/apidocs/jakarta.ws.rs/jakarta/ws/rs/container/prematching)`** annotation that discover instances of the **`[A2AVersionProvider](https://github.com/wildfly-extras/a2a-jakarta/blob/main/http-common/src/main/java/org/wildfly/a2a/jakarta/common/A2AVersionProvider.java)`** interface via CDI. More details on this release may be found in the release notes for [version 1.0.0-CR2](https://github.com/wildfly-extras/a2a-jakarta/releases/tag/v1.0.0.CR2) and [version 1.0.0-CR1](https://github.com/wildfly-extras/a2a-jakarta/releases/tag/v1.0.0.CR1).

#### Azul Payara

The [release](https://www.azul.com/blog/whats-new-in-the-september-2026-azul-payara-release/) of [Azul Payara](https://www.azul.com/products/payara-server/) 7.4.0, the September 2026 edition, includes Community Edition 7.2026.9, Enterprise Edition 6.42.0 and Enterprise Edition 5.91.0. Along with bug fixes and component upgrades, all three editions ship with new features such as: support for [MicroProfile 7.1](https://microprofile.io/releases/7-1/#); a resolution to [CVE-2026-68497](https://nvd.nist.gov/vuln/detail/cve-2026-68497), a vulnerability in [Jackson Databind](https://github.com/FasterXML/jackson-databind/blob/3.x/README.md) that allows an unauthenticated attacker to submit a single large request, say, a few megabytes, that will force up to to several minutes of single-threaded CPU work, potentially saturating a server's worker threads; and support for the [Jakarta Agentic AI](https://jakarta.ee/specifications/agentic-ai/) specification in Payara Micro and Payara Embedded.

There is a breaking change in which support for the MicroProfile [OpenTracing](https://github.com/microprofile/microprofile-opentracing/blob/main/README.adoc) specification, moved to the set of standalone specifications with the release of MicroProfile 6.0, has been removed. As a result, the **`[@Traced](https://github.com/microprofile/microprofile-opentracing/blob/main/api/src/main/java/org/eclipse/microprofile/opentracing/Traced.java)`** annotation from MicroProfile OpenTracing can no longer be used since there is no equivalent in the MicroProfile [Telemetry](https://github.com/microprofile/microprofile-telemetry/blob/main/README.adoc) specification. Explicit instrumentation now moves to use of the OpenTelemetry **`[@WithSpan](https://github.com/open-telemetry/opentelemetry-java-instrumentation/blob/main/instrumentation-annotations/src/main/java/io/opentelemetry/instrumentation/annotations/WithSpan.java)`** annotation.

Further details on this release may be found in the [release notes](https://docs.azul.com/payara/release-notes/release-notes-7.4.0.html).

#### JHipster

The [release](https://x.com/jhipster/status/2100795037663810020) of [JHipster](https://www.jhipster.tech/) 9.4.0 provides bug fixes and notable changes such as: support for [Playwright](https://playwright.dev/) as an alternative to [Cypress](https://www.cypress.io/); a reimplementation of R2DBC repositories on top of [Spring Data R2DBC](https://spring.io/projects/spring-data-r2dbc) using the JHipster Framework CriteriaBuilder; and a migration away from the webpack [Module Federation](https://webpack.js.org/concepts/module-federation/) to [esbuild](https://esbuild.github.io/) and [Native Federation](https://native-federation.com/) for building Angular microfrontends. More details on this release may be found in the [release notes](https://github.com/jhipster/generator-jhipster/releases/tag/v9.4.0).

#### JetBrains Ktor

The [release](https://blog.jetbrains.com/ktor/2026/09/18/ktor-3-6-0-is-now-available/) of JetBrains [Ktor](https://ktor.io/) 3.6.0 delivers bug fixes and new features such as: the ability to automatically configure OpenID Connect OAuth2 flows through auto-discovery; and a new OpenID Connect plugin designed to reduce complexity when securing a service through OpenID Connect providers. Further details on this release may be found in the [release notes](https://github.com/ktorio/ktor/releases/tag/3.6.0).

#### BoxLang

The [release](https://foojay.io/today/boxlang-1-17-0-released-module-inception-cli-checker-jar-loading-and-much-more/) of [BoxLang](https://boxlang.io/) 1.17.0 ships with bug fixes and new features such as: a new **`[ModuleService](https://github.com/ortus-boxlang/BoxLang/blob/development/src/main/java/ortus/boxlang/runtime/services/ModuleService.java)`** class that support a Modules Inception feature to manage BoxLang modules and allows for the use of nested modules; a new **`check`** action command that serves as a syntax build checker by parsing one or more source files without the need to compile to bytecode; and a new encryption for sensitive values inside the **`boxlang.json`** and **`Application.bx`** files.

#### Netflix ja

Netflix has [introduced](https://netflixtechblog.com/leave-the-class-path-in-the-rearview-mirror-67a85b15b6be) a new utility, [ja](https://github.com/Netflix/ja/blob/main/README.md), built on the capabilities of the Java Module System (JMS), to provide a modern command line development experience for Java developers. This will allow traditional applications to naturally grow into a JMS application without the need for a complex build system. ja includes a subset of composable tools for module resolution, code conventions, source-aware symbol search and browsable API documentation.
