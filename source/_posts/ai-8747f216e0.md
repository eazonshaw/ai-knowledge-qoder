#### TornadoVM

The [release](https://www.tornadovm.org/blogs/tornadovm-8-0-0-tc-tornadovm-compiler) of [TornadoVM](https://www.tornadovm.org/) 8.0.0 delivers their new pure-Java compiler, known as the TornadoVM Compiler (TC), that compiles Java kernels to CUDA C++, OpenCL C or Metal Shading Language. This replaces the [Graal Compiler](https://www.graalvm.org/jdk25/reference-manual/java/compiler/) and [Java-Level JVM Compiler Interface](https://openjdk.org/jeps/243) (JVMCI) that have been integral to TornadoVM for the past ten years. Developers won’t need to change their code with TC. Classes such as **`[TaskGraph](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/TaskGraph.java)`**, **`[TornadoExecutionPlan](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/TornadoExecutionPlan.java)`** and **`[KernelContext](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/KernelContext.java)`**, and annotations such as **`[@Parallel](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/annotations/Parallel.java)`** and **`[@Reduce](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/annotations/Reduce.java)`** will work with TC.

TornadoVM now takes advantage of GraalVM Native Image and JEP 516, [Ahead-of-Time Object Caching with Any GC](https://openjdk.org/jeps/516), under the auspices of [Project Leyden](https://openjdk.org/projects/leyden/) for improved startup time. Further details on this release may be found in the [release notes](https://github.com/beehive-lab/TornadoVM/releases/tag/v8.0.0).

#### Eclipse JNoSQL

The release of [Eclipse JNoSQL](https://www.jnosql.org/) 1.2.0, a compatible implementation of the Jakarta NoSQL and Jakarta Data specifications, ships with notable changes such as: a new **`[VectorTemplate](https://github.com/eclipse-jnosql/jnosql/blob/main/jnosql-mapping/jnosql-mapping-vector/src/main/java/org/eclipse/jnosql/mapping/vector/VectorTemplate.java)`** interface to support vector databases; integrations of the [Milvus](https://milvus.io/), [Qdrant](https://qdrant.tech/), and [Weaviate](https://weaviate.io/) vector databases for vector search; and new fluent temporal query operations for working with time-series data. More details on this release may be found in the [release notes](https://github.com/eclipse-jnosql/jnosql/releases/tag/1.2.0).

#### Endive

The [release](https://www.linkedin.com/posts/andrea-peruffo-32269178_webassembly-java-jvm-share-7521965708919033856-PvPf/) of [Endive](https://endive.run/) 1.2.0 provides bug fixes, dependency upgrades and new features such as: support for SIMD instructions, by default, in the interpreter on JDK 11+ without the need to add or configure; improvements to [Redline](https://endive.run/docs/experimental/redline), their experimental, ahead-of-time (AOT) compiler, for more GC-friendly native memory; and continuous improvement on the [Endive Component Model](https://github.com/roastedroot/endive-cm/blob/main/Readme.md), an implementation of the WebAssembly [Component Model Design and Specification](https://github.com/WebAssembly/component-model/blob/main/README.md), to support the Endive runtime. Further details on this release may be found in the [release notes](https://github.com/bytecodealliance/endive/releases/tag/1.2.0).

#### JBang

The release of [JBang](https://www.jbang.dev/) 0.143.0 delivers bug fixes, documentation improvements and two new features: replace use of SDKMan with [mise-en-place](https://mise.jdx.dev/) as the former does not support WindowsOS; and a new unified syntax to execute a specific version of an alias. More details on this release may be found in the [release notes](https://github.com/jbangdev/jbang/releases/tag/v0.143.0).

#### JReleaser

The [release](https://andresalmiray.com/jreleaser-1-27-0-has-been-released/) of [JReleaser](https://jreleaser.org/) 1.27.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: the ability for the support for the [JReleaser Tool Provider](https://jreleaser.org/guide/latest/tools/jreleaser-tool-provider.html) to be invoked and/or loaded using Java Modules; improved generation of the changelog when GitHub issues are linked inside commit messages; and the removal of [XPath](https://www.w3.org/TR/xpath-31/) to parse POM files as there were issues when packaging JReleaser as a native image. Further details on this release may be found in the [release notes](https://github.com/jreleaser/jreleaser/releases/tag/v1.27.0).

#### LangChain4j

The *formal release* (along with the *thirty-third beta release*) of [LangChain4j](https://github.com/langchain4j) 1.23.0 provides bug fixes, documentation improvements, dependency upgrades and new features such as: a new **`[OllamaDecisionModel](https://github.com/langchain4j/langchain4j/blob/main/langchain4j-ollama/src/main/java/dev/langchain4j/model/ollama/OllamaDecisionModel.java)`** class to support decision models running in Ollama; and a new **`[ConfidenceCascadePlanner](https://github.com/langchain4j/langchain4j/blob/main/langchain4j-agentic-patterns/src/main/java/dev/langchain4j/agentic/patterns/cascade/ConfidenceCascadePlanner.java)`** class as a confidence cascade decision model-based agentic pattern. More details on this release may be found in the [release notes](https://github.com/langchain4j/langchain4j/releases/tag/1.23.0).

#### Hibernate

The [fourth beta release](https://in.relation.to/2026/10/28/orm-80-beta4/) of [Hibernate ORM](https://hibernate.org/orm/) 8.0.0 delivers bug fixes and notable changes such as: the ability to directly declare the **`[@Filter](https://docs.hibernate.org/orm/8.0/javadocs/org/hibernate/annotations/Filter.html)`** and **`[@SQLRestriction](https://docs.hibernate.org/orm/8.0/javadocs/org/hibernate/annotations/SQLRestriction.html)`** annotations on associations with the Jakarta Persistence **`[@ManyToOne](https://jakarta.ee/specifications/persistence/3.2/apidocs/jakarta.persistence/jakarta/persistence/ManyToOne.html)`** and **`[@OneToOne](https://jakarta.ee/specifications/persistence/3.2/apidocs/jakarta.persistence/jakarta/persistence/OneToOne.html)`** annotations that include associations mapped using join tables; and a new **`[@GeneratorOptimizer](https://github.com/hibernate/hibernate-orm/blob/main/hibernate-core/src/main/java/org/hibernate/annotations/GeneratorOptimizer.java)`** annotation that selects a "*standard optimizer for sequence or table identifier generation directly on an identifier field or getter.*"

The [first and third beta releases](https://in.relation.to/2026/10/30/hibernate-reactive-5_1_0_Beta1/) of [Hibernate Reactive](https://hibernate.org/reactive/) 5.1.0 and 5.0.0, respectively, ship with bug fixes and notable changes such as: a new platform Bill of Materials that manages the versions of Hibernate Reactive, Hibernate ORM and Vert.x SQL clients; and a version check during bootstrap to ensure that Hibernate ORM and Vert.x SQL clients on the classpath aren’t older than the minimum versions it supports. Both of these versions are compatible with Hibernate ORM 8.0.0.Beta4.

#### JobRunr

The release of [JobRunr](https://www.jobrunr.io/) 9.0.3 provides bug fixes, documentation improvements and dependency upgrades and one new feature that updates the **`[JobHandler](https://github.com/jobrunr/jobrunr/blob/master/core/src/main/java/org/jobrunr/server/JobHandler.java)`** class that improves the log messaging from the **`[JobZooKeeper](https://github.com/jobrunr/jobrunr/blob/master/core/src/main/java/org/jobrunr/server/JobZooKeeper.java)`** class. Further details on this release may be found in the [release notes](https://github.com/jobrunr/jobrunr/releases/tag/v9.0.3).

#### Gradle

The first release candidate of [Gradle](https://gradle.org/) 9.9.0 delivers notable changes such as: the ability for [Kotlin DSL](https://docs.gradle.org/9.9.0-rc-1/userguide/kotlin_dsl.html) scripts to be incrementally compiled using the [Kotlin Build Tools API](https://kotlinlang.org/docs/build-tools-api.html) for improved build performance; new [test filters](https://docs.gradle.org/9.9.0-rc-1/userguide/java_testing.html#test_filtering) that may be applied to JUnit Platform tests that are not declared as methods; and improvements to the [Problems API](https://docs.gradle.org/9.9.0-rc-1/userguide/reporting_problems.html#header) that provides a predefined hierarchy of problem groups from the **`[Problems](https://docs.gradle.org/current/javadoc/org/gradle/api/problems/Problems.html)`** interface. More details on this release may be found in the [release notes](https://docs.gradle.org/9.9.0-rc-1/release-notes.html).

#### Quarkus Almanac

The Quarkus team has [introduced](https://quarkus.io/blog/quarkus-almanac/) the [Quarkus Almanac](https://quarkus.io/almanac/), a utility for developers to compare changes between two releases. These changes include configuration properties, managed dependencies, extensions, and the API of the classes in the Quarkus jars. Developers can go as far back as November 2018 when Quarkus 0.0.1 was released.
