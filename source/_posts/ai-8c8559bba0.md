## 正文

Last week, Microsoft's team released [.NET 11 Preview 7](https://devblogs.microsoft.com/dotnet/dotnet-11-preview-7/), an update that brings changes and improvements to the C# language, ASP.NET Core, .NET MAUI, Entity Framework Core, Windows Forms, and F#.

In the C# area, the [*break* and *continue* statements](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/csharp.md#labeled-break-and-continue) can now name an enclosing loop or switch, so code can leave or continue an outer construct directly from an inner one without a flag or a goto.

```
string? foundValue = null;
outer: for (int x = 0; x < xMax; x++)
{
    for (int y = 0; y < yMax; y++)
    {
        if (GetValue(x, y) is { } value && value == target)
        {
            foundValue = value;
            break outer;
        }
    }
}
```

Also, the [Union types](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/csharp.md#union-patterns-match-the-union-or-its-value), still a preview feature, now use a try-both approach that first tests a pattern against the union itself and then against its contained value.

Correspondingly, [switch-expression](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/csharp.md#exhaustiveness-for-type-parameters-constrained-to-a-closed-type) exhaustiveness also understands generic parameters constrained to a closed type, so the compiler no longer warns when every derived case is handled. Further work refines the [Unsafe Evolution rules](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/csharp.md#unsafe-evolution-compat-mode-and-nameof) and adds a [null check](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/csharp.md#null-check-in-compiler-synthesized-inline-array-helpers) to inline-array helpers, so forming a reference from a null buffer now throws deterministically.

```
public closed record class Shape;
public record class Circle(double Radius) : Shape;
public record class Square(double Side) : Shape;
static double Area<T>(T shape) where T : Shape => shape switch
{
    Circle(var r) => Math.PI * r * r,
    Square(var s) => s * s
};
```

[ASP.NET Core](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md) receives a wide set of additions, most of them centred on Blazor. [Interactive Server circuits](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#auto-pause-blazor-circuits-on-inactivity) can now pause themselves when a browser tab is hidden, releasing server resources until the user returns. A new [*CacheView* component](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#cache-blazor-ssr-output-with-cacheview) caches the rendered output of a server-side subtree, replaying stored HTML on a cache hit to cut processor and memory use.

Furthermore, [five new Blazor analyzers](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#new-blazor-analyzers) ship on by default to flag common mistakes, and QuickGrid gains [programmatic scrolling](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#quickgrid-supports-initialitemindex-and-scrolltoitemasync). Validation message localization is now built in and activates as soon as a string localizer is registered, while the *ValidatableType* and *SkipValidation* attributes leave preview.

The SignalR .NET client [can refresh authentication](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#signalr-net-client-supports-auth-refresh-after-redirects) after a negotiate redirect, endpoints that return server-sent events are described in [OpenAPI 3.2](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#openapi-server-sent-events-in-openapi-32), and applications can read the TLS [channel-binding token](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/aspnetcore.md#tls-channel-binding-token-access-from-itlsconnectionfeature) to defend against relay attacks.

One notable change reverses part of [Preview 6](https://www.infoq.com/news/2026/07/dotnet-11-preview-6): automatic cross-origin protection now validates only endpoints that opt in, matching .NET 10 behaviour so existing apps are not broken.

For [.NET MAUI, Preview 7](https://www.infoq.com/news/2026/08/dotnet-11-preview7-maui) adds cross-platform passkey authentication, XAML Incremental Hot Reload, and Shell route templates, 

Next, Entity Framework Core now translates *int.Parse* and related methods to a [SQL Server CAST](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/efcore.md#linq-query-translation-improvements), rewrites several GroupBy patterns into single joins for cleaner queries, and also adds support for the [16-bit Half type on SQLite](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/efcore.md#half-type-support-on-sqlite).

As reported, the Azure Cosmos DB provider is modernised to use [*System.Text.Json*](http://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/efcore.md#azure-cosmos-db-provider-improvements), also, the [Package Manager Console](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/efcore.md#migrations-improvements) gains a -NoBuild switch for adding and applying migrations.

Windows Forms introduces an opt-in modern rendering pipeline through *[VisualStylesMode](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/winforms.md#opt-in-to-net-11-visual-styles)*, along with a way to react to system visual settings, [deferred form reveal](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/winforms.md#deferred-form-reveal) to avoid, as reported, an unstyled flash at startup, and a *[SuspendPainting scope](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/winforms.md#suspend-painting-during-bulk-mutations)* that reduces flicker during bulk updates.

[The F# programming language](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/fsharp.md) receives minor compiler fixes, including support for computation-expression bindings within a plain let and correct attribute resolution in recursive modules.

For interested readers and developers, the full release notes for .NET 11 Preview 7 are available on the [dotnet/core repository](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/preview7/README.md) on GitHub.
