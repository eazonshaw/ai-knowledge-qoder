This week's Java roundup for September 21st, 2026, features news highlighting: GA releases of TornadoVM 7.0 and Groovy 6.0; point releases of GraalVM and Gradle; maintenance releases of Quarkus and GDK for Micronaut; the seventh release candidate of Maven 4.0; milestone releases of Micrometer Metrics and Tracing; and beta releases of Open Liberty and Hibernate ORM.

#### OpenJDK

JEP 544, [Ahead-of-Time Code Compilation](https://openjdk.org/jeps/544), has been [elevated](https://mail.openjdk.org/archives/list/jdk-dev@openjdk.org/thread/KAQGAGMSCWSWWTE6MJ4M26NU4NJ37FNJ/) from **Candidate** to **Proposed to Target** for JDK 28. This JEP proposes to improve application startup and warmup time such that it is instantly available with optimized native code when the HotSpot JVM starts. This enables applications to achieve peak performance more quickly and to sustain peak performance. The review is expected to conclude on Monday, September 28, 2026.

JEP 546, [Adaptive Heap Sizing for ZGC](https://openjdk.org/jeps/546), has been [elevated](https://mail.openjdk.org/archives/list/jdk-dev@openjdk.org/thread/B2RAQU4ROFMNUJRS6ST2ZRE7I5OIME5R/) from its **JEP Draft 8377305** to **Candidate** status. This JEP proposes to "*enhance the Z Garbage Collector to adaptively adjust the size of the heap based on the resources available, the application's needs, and the needs of neighboring applications contending for the same resources*."

JEP 545, [Faster Startup and Warmup with ZGC](https://openjdk.org/jeps/545), has been [elevated](https://mail.openjdk.org/archives/list/jdk-dev@openjdk.org/thread/KD7LEJXNKS5BJD2XSHSB4ZJJIQA3BT2H/) from its **JEP Draft 8329758** to **Candidate** status. This JEP proposes to "*improve application startup and warmup by enhancing the Z Garbage Collector to acquire and prepare physical memory more swiftly and efficiently in response to application needs*."

#### GraalVM

The [release](https://x.com/graalvm/status/2102434304961745051) of [GraalVM](https://www.graalvm.org/) 25.4 delivers notable changes such as: new classes, **`[PullThroughPhiPhase](https://javadoc.io/doc/org.graalvm.compiler/compiler/latest/jdk/graal/compiler/duplication/phases/PullThroughPhiPhase.html)`** and **`[DuplicationPhase](https://javadoc.io/doc/org.graalvm.compiler/compiler/latest/jdk/graal/compiler/duplication/phases/simulation/DuplicationPhase.html)`**, as additional compiler configuration optimizations; and an extension of the **`[OptimizeDivPhase](https://javadoc.io/doc/org.graalvm.compiler/compiler/latest/jdk/graal/compiler/phases/common/OptimizeDivPhase.html)`** class to include magic-number optimizations for unsigned integer division and remainder operations by constant values. Further details on this release may be found in the [release notes](https://www.graalvm.org/release-notes/25.4/).

Oracle Labs has also [released](https://github.com/oracle/graal-dev-kit/releases/tag/5.1.5) version 5.1.5 of the [Graal Development Kit for Micronaut](https://graal.cloud/gdk/) featuring alignment with Micronaut 5.1.5. [Formerly known as Graal Cloud Native](https://blogs.oracle.com/java/post/announcing-graal-development-kit-437), the Graal Development Kit for Micronaut provides a curated set of Micronaut framework modules that simplify cloud application development. These are designed to compile ahead-of-time with GraalVM Native Image and fully supported by Oracle. More details on this release may be found in the [release notes](https://github.com/oracle/graal-dev-kit/releases/tag/5.1.5).

#### TornadoVM

The [release](https://www.tornadovm.org/blogs/getting-started-with-the-tilecontext-api-in-tornadovm) of [TornadoVM](https://www.tornadovm.org/) 7.0.0 ships with bug fixes and new features such as: a new **`[TileContext](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/tile/TileContext.java)`** class to complement the existing **`[KernelContext](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/KernelContext.java)`** class and **`[@Parallel](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-api/src/main/java/uk/ac/manchester/tornado/api/annotations/Parallel.java)`** annotation for writing GPU kernels in Java; and an improvement in the **`testFloatAtomicAddOpenCL()`** method, defined in the **`[FloatAtomicFail](https://github.com/beehive-lab/TornadoVM/blob/master/tornado-unittests/src/main/java/uk/ac/manchester/tornado/unittests/fails/FloatAtomicFail.java)`** class, that guards against running the test on a CUDA backend that were plagued with intermittent failures. #### Apache Groovy

After three release candidates, the [GA release](https://www.mail-archive.com/announce@apache.org/msg12006.html) of [Apache Groovy](https://groovy-lang.org/) 6.0 provides bug fixes, dependency upgrades and one new feature that improves the performance of the lexer and parser by: flattening the number-literal fragments to character classes; splitting the ASCII identifiers onto a predicate-free Deterministic Finite Automaton (DFA) path; replacing the regular expression-based lexer predicates with direct character tests; and gating the annotation element values so **`AdaptivePredict`** does not explore assignment expressions. More details on this release may be found in the [release notes](https://issues.apache.org/jira/secure/ReleaseNote.jspa?projectId=12318123&version=12357525).

#### Open Liberty

#### Hibernate

The [second beta release](https://in.relation.to/2026/09/23/orm-80-beta2/) (along with a follow-up third beta release) of [Hibernate ORM](https://hibernate.org/orm/) 8.0 provides notable changes such as: expanded support for [Jakarta Persistence 4.0-M4](https://jakarta.ee/specifications/persistence/4.0/) that include use of the new **`[@PostCreate](https://github.com/jakartaee/persistence/blob/main/api/src/main/java/jakarta/persistence/PostCreate.java)`** and **`[@PreClose](https://github.com/jakartaee/persistence/blob/main/api/src/main/java/jakarta/persistence/PreClose.java)`** annotations that allow for listeners to observe the lifecycle of entity managers and agents; and version locking for the **`[StatelessSession](https://github.com/hibernate/hibernate-orm/blob/main/hibernate-core/src/main/java/org/hibernate/StatelessSession.java)`** and **`[EntityAgent](https://github.com/jakartaee/persistence/blob/main/api/src/main/java/jakarta/persistence/EntityAgent.java)`** interfaces for improved concurrency. More details on these releases may be found in the release notes for [version 8.0.0.Beta3](https://github.com/hibernate/hibernate-orm/releases/8.0.0.Beta3) and [version 8.0.0.Beta2](https://github.com/hibernate/hibernate-orm/releases/8.0.0.Beta2).

#### Micrometer

The *second milestone release* of [Micrometer Metrics](https://github.com/micrometer-metrics/micrometer/blob/main/README.md) 1.18.0 delivers bug fixes, documentation improvements, dependency upgrades and new features such as: improvements to the **`[MultiGauge](https://github.com/micrometer-metrics/micrometer/blob/main/micrometer-core/src/main/java/io/micrometer/core/instrument/MultiGauge.java)`** class that eliminates the need to remove and re-register an instance of the **`[Gauge](https://github.com/micrometer-metrics/micrometer/blob/main/micrometer-core/src/main/java/io/micrometer/core/instrument/Gauge.java)`** interface if there was an overwrite; and the ability to configure custom instances of the **`[JmsProcessObservationConvention](https://github.com/micrometer-metrics/micrometer/blob/main/micrometer-jakarta9/src/main/java/io/micrometer/jakarta9/instrument/jms/JmsProcessObservationConvention.java)`** and **`[JmsPublishObservationConvention](https://github.com/micrometer-metrics/micrometer/blob/main/micrometer-jakarta9/src/main/java/io/micrometer/jakarta9/instrument/jms/JmsPublishObservationConvention.java)`** interfaces. Further details on this release may be found in the [release notes](https://github.com/micrometer-metrics/micrometer/releases/tag/v1.18.0-M2).

The *second milestone release* of [Micrometer Tracing](https://github.com/micrometer-metrics/tracing/blob/main/README.md) 1.8.0 ships with documentation improvements, dependency upgrades and one new feature that optimizes the baggage propagation from [OpenTelemetry](https://opentelemetry.io/) when no remote fields are configured. There was a depreciation of support for the [Zipkin Exporter](https://central.sonatype.com/artifact/io.opentelemetry/opentelemetry-exporter-zipkin) as it was [discontinued](https://opentelemetry.io/blog/2025/deprecating-zipkin-exporters/) by OpenTelemetry with the release of version 1.65.0. More details on this release may be found in the [release notes](https://github.com/micrometer-metrics/tracing/releases/tag/v1.8.0-M2).

#### Gradle

The [release](https://github.com/gradle/gradle/releases/tag/v9.8.0) of [Gradle](https://gradle.org/) 9.8.0 provides new features such as: support for Java 27 in the Gradle daemon and Java toolchains; support for reusing the Maven [mirror repository settings](https://maven.apache.org/guides/mini/guide-mirror-settings.html) with a simple flag; improved [build authoring](https://docs.gradle.org/9.5.0-rc-1/userguide/getting_started_dev.html) by exposing the [Copy](https://docs.gradle.org/9.8.0/dsl/org.gradle.api.tasks.Copy.html) and [Sync](https://docs.gradle.org/9.8.0/dsl/org.gradle.api.tasks.Sync.html) tasks to an instance of the **`[DirectoryProperty](https://docs.gradle.org/9.8.0/javadoc/org/gradle/api/file/DirectoryProperty.html)`** interface; and a 45% performance improvement in WindowsOS. Further details on this release may be found in the [release notes](https://docs.gradle.org/9.8.0/release-notes.html).

#### Apache Maven

The [seventh release candidate](https://www.mail-archive.com/announce@apache.org/msg12005.html) of [Apache Maven](https://maven.apache.org/) 4.0 delivers numerous bug fixes from RC6, documentation improvements, dependency upgrades and new features such as: a new **`[AsyncDrainWriter](https://github.com/apache/maven/blob/master/impl/maven-core/src/main/java/org/apache/maven/logging/AsyncDrainWriter.java)`** class, containing a non-blocking **`tryLock()`** method, to wrap an instance of the **`[Consumer](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/function/Consumer.html)`** interface with a lock-free **`[ConcurrentLinkedQueue](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/concurrent/ConcurrentLinkedQueue.html)`**; and optimizations made to the **`[DefaultGraphBuilder](https://github.com/apache/maven/blob/master/impl/maven-core/src/main/java/org/apache/maven/graph/DefaultGraphBuilder.java)`** and **`[PhaseComparator](https://github.com/apache/maven/blob/master/impl/maven-core/src/main/java/org/apache/maven/lifecycle/internal/PhaseComparator.java)`** classes for improved performance. This release is expected to be the last one before the formal GA release in "*the coming weeks pending community feedback.*" More details on this release may be found in the [release notes](https://github.com/apache/maven/releases/tag/maven-4.0.0-rc-7).
